C17 - Elemente de statistică: indicatorii tendinței centrale (frecvență, medie, mediană, mod și amplitudine a unui set de date). În acest curs vom aborda indicatorii tendinței centrale ai unui set de date. O să înveți ce înseamnă frecvență, mod, amplitudine, medie și mediană și cum se calculează fiecare dintre ele.

Începem cu prima definiție. Statistica este o știință care se ocupă de culegerea, gruparea, analizarea, interpretarea unor date și înregistrarea lor, folosind calculul probabilităților.

Culegerea datelor se poate face prin observare sau prin chestionare.

Exemplu: În tabelul de mai jos sunt redate mediile obținute de elevii unei clase la matematică pe semestrul I. Mediile trecute în tabel sunt 5, 6, 7, 8, 9 și 10, iar numărul de medii este, în aceeași ordine, 7, 3, 5, 4, 3 și 2. Cu alte cuvinte, 7 elevi au avut media 5, 3 elevi au avut media 6, 5 elevi au avut media 7, 4 elevi au avut media 8, 3 elevi au avut media 9, iar 2 elevi au avut media 10.

Tabelul de mai sus reprezintă rezultatul unei culegeri de date prin observare. Când se fac sondaje de opinie, datele se culeg prin chestionare.

Frecvența. Frecvența este un număr care ne arată de câte ori se repetă o valoare numerică într-un set de date.

Exemplu: În tabelul de mai sus valoarea numerică 5, adică media 5, are frecvența 7, pentru că 7 elevi au avut media 5. Valoarea numerică 8, adică media 8, are frecvența 4, pentru că 4 elevi au avut media 8.

Modul. Modul unui set de date este valoarea numerică cu frecvența cea mai mare, dacă aceasta există.

Exemplu: În tabelul de mai sus, modul este 5, deoarece are frecvența cea mai mare. Dacă mai multe valori numerice au aceeași frecvență, spunem că setul de date are mai multe valori modale. Iar dacă toate valorile numerice au aceeași frecvență, spunem că setul de date nu conține valori modale.

Amplitudinea. Amplitudinea unui set de date este un număr care reprezintă diferența dintre cea mai mare și cea mai mică valoare numerică a setului de date.

Exemplu: În tabelul de mai sus, amplitudinea este 5, adică $7 - 2$, pentru că cea mai mare valoare este 7, iar cea mai mică este 2.

Media. Prin media unui set de date vom înțelege media aritmetică a datelor, respectiv media aritmetică ponderată în funcție de setul de date studiat.

Exemplu: În cazul tabelului de mai sus, pentru a calcula media datelor reprezentate vom calcula media aritmetică ponderată a lor: $\text{Media} = \frac{5 \cdot 7 + 6 \cdot 3 + 7 \cdot 5 + 8 \cdot 4 + 9 \cdot 3 + 10 \cdot 2}{7 + 3 + 5 + 4 + 3 + 2} = \frac{55}{24} \approx 7.29$.

Mediana. Mediana unui set de date este numărul care împarte șirul valorilor numerice în două părți egale, atunci când acestea sunt ordonate crescător. Dacă un set de date are un număr impar de valori, mediana este termenul din mijloc, atunci când valorile sunt ordonate crescător.

Exemplu: Fie setul de date 3, 2, 3, 4, 9, 5, 6, 6, 7, 6, 8. Ordonăm crescător valorile numerice și obținem 2, 3, 3, 4, 5, 6, 6, 6, 7, 8, 9. Mediana este 6, deoarece este termenul din mijloc al șirului ordonat crescător.

Fii atent însă la celălalt caz. Dacă un set de date are un număr par de valori, mediana este media aritmetică a celor doi termeni din mijloc, atunci când valorile sunt ordonate crescător.

Exemplu: Fie setul de date 2, 1, 3, 5, 6, 5, 4, 3, 1, 5. Ordonăm crescător valorile numerice și obținem 1, 1, 2, 3, 3, 4, 5, 5, 5, 6. Observăm că avem număr par de valori, deci vom calcula media aritmetică a celor doi termeni din mijloc, în cazul nostru 3 și 4: $\text{Mediana} = \frac{3 + 4}{2} = \frac{7}{2} = 3.5$.

Reține că mediana se citește abia după ce ai ordonat crescător valorile setului de date.
