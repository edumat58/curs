C14.2 - Descompuneri în factori utilizând reguli de calcul în ℝ (formule de calcul prescurtat). În acest curs vom aborda descompunerea în factori cu ajutorul formulelor de calcul prescurtat. O să înveți să recunoști într-o expresie algebrică pătratul unei sume, pătratul unei diferențe sau o diferență de pătrate, și să o scrii ca produs.

Definiție. Pornim de la un pătrat mare a cărui latură este formată dintr-o bucată de lungime <a> și una de lungime <b>. Aria lui se poate scrie în două feluri. Pe de o parte, latura măsoară $a + b$, deci aria pătratului mare este $(a + b)^2$. Pe de altă parte, pătratul mare este alcătuit din pătratul de arie $a^2$, din pătratul de arie $b^2$ și din două dreptunghiuri, fiecare de arie $ab$, deci aria pătratului mare este $a^2 + 2ab + b^2$.

Amândouă afirmațiile sunt așadar corecte: este aceeași arie, scrisă în două moduri. De aici răspunsul la a doua întrebare: da, relația $a^2 + 2ab + b^2 = (a + b)^2$ este adevărată.

Completează acum expresiile astfel încât să obții relații adevărate. La primul punct, $a^2 - 2ab + b^2$ este pătratul unei diferențe, deci $a^2 - 2ab + b^2 = (a - b)^2$. La al doilea punct, $a^2 - b^2$ se scrie ca un produs de două paranteze, și anume $a^2 - b^2 = (a - b)(a + b)$.

Reține lucrul important. O metodă de descompunere în factori este utilizarea formulelor de calcul prescurtat.

Formulele de calcul prescurtat pot fi scrise și astfel: $a^2 + 2ab + b^2 = (a + b)^2$, adică pătratul sumei; $a^2 - 2ab + b^2 = (a - b)^2$, adică pătratul diferenței; și $a^2 - b^2 = (a - b)(a + b)$, adică diferența de pătrate. Citite în sensul acesta, de la sumă către produs, ele descompun expresia în factori.

Exemplul 1. Descompune în factori expresiile algebrice: $E(x) = x^2 + 6x + 9$ și $E(x, y) = 4x^2 - 12xy + 9y^2$, $E(x, y) = 4x^2 - y^2$.

Soluție. $E(x) = x^2 + 6x + 9$ este o expresie algebraică care are trei termeni. Mă pot gândi la una dintre formulele $a^2 + 2ab + b^2 = (a + b)^2$ sau $a^2 - 2ab + b^2 = (a - b)^2$. Pentru aceasta trebuie să identific $a^2$, $b^2$ și $2ab$.

Analiza procesului: pentru că $2ab$ are semnul plus, obținem $E(x) = x^2 + 6x + 9 = (x + 3)^2$.

Iată identificarea termenilor: $a^2 = x^2 \Rightarrow a = x$, iar $b^2 = 9 \Rightarrow b = 3$. Urmează verificarea termenului dublu: $2ab = 2 \cdot x \cdot 3 = 6x$, adică exact termenul din mijloc.

Concluzie: se poate folosi formula $a^2 + 2ab + b^2 = (a + b)^2$.

Exemplul 2. $E(x, y) = 4x^2 - 12xy + 9y^2$ este o expresie algebraică care are trei termeni. Mă pot gândi la formulele $a^2 + 2ab + b^2 = (a + b)^2$ și $a^2 - 2ab + b^2 = (a - b)^2$. Pentru aceasta trebuie să identific $a^2$, $b^2$ și $2ab$.

Analiza procesului: pentru că $2ab$ are semnul minus, obținem $E(x,y) = 4x^2 - 12xy + 9y^2 = (2x - 3y)^2$.

Iată identificarea termenilor: $a^2 = 4x^2 \Rightarrow a = 2x$, iar $b^2 = 9y^2 \Rightarrow b = 3y$. Urmează verificarea termenului dublu: verific dacă $2ab = 12xy$, și într-adevăr $2ab = 2 \cdot 2x \cdot 3y = 12xy$.

Concluzie: se poate folosi formula $a^2 - 2ab + b^2 = (a - b)^2$.

Exemplul 3. $E(x, y) = 4x^2 - y^2$ este o expresie algebraică care are doi termeni și între ei semnul minus. Mă gândesc la formula $a^2 - b^2 = (a - b)(a + b)$. Pentru aceasta trebuie să identific $a^2$ și $b^2$.

Analiza procesului: obținem $E(x,y) = 4x^2 - y^2 = (2x + y)(2x - y)$.

Iată identificarea termenilor: $a^2 = 4x^2 \Rightarrow a = 2x$, iar $b^2 = y^2 \Rightarrow b = y$. Aici nu mai avem termen dublu de verificat, pentru că expresia are doar doi termeni.

Concluzie: se poate folosi formula $a^2 - b^2 = (a + b)(a - b)$.

Reține drumul: numeri termenii, identifici pe $a^2$ și pe $b^2$, verifici termenul dublu acolo unde există, apoi scrii expresia ca produs.
