C14.1 - Descompuneri în factori utilizând reguli de calcul în ℝ (factor comun). În acest curs vom aborda descompunerea în factori a expresiilor algebrice. O să înveți cum găsești factorul comun al unei expresii și cum îl scoți în față, ca să scrii expresia ca produs.

Descompunerea în factori a unei expresii algebrice înseamnă scrierea acelei expresii ca produs între două sau mai multe expresii algebrice. O metodă de descompunere în factori este utilizarea factorului comun. Această metodă se bazează pe distributivitatea înmulțirii față de adunare și scădere.

Egalitatea $a \cdot (b + c) = a \cdot b + a \cdot c$ se poate scrie $a \cdot b + a \cdot c = a \cdot (b + c)$. Observă că este aceeași egalitate, citită invers: pornim de la o sumă și ajungem la un produs.

Să luăm un exemplu, pe care îl vom duce până la capăt. Descompune în factori expresia algebrică <E> de <x>, <y>, <z>, adică $9x^2y^3z + 15x^3y^2 - 21x^2y$.

Metoda de rezolvare. Hai să vedem cum gândim, întrebare cu întrebare.

Prima întrebare: există un număr, diferit de 1, la care să se împartă exact toți coeficienții? În cazul nostru răspunsul este da; numărul căutat este 3. El va face parte din factorul comun.

A doua întrebare: există litere care apar în fiecare dintre termeni? Da, acestea sunt <x> și <y>. Aceste litere, cu cel mai mic exponent la care apar, fac parte din factorul comun. În concluzie, un factor comun este $3x^2y$.

Redactare. Iată cum se scrie rezolvarea: $9x^2y^3z + 15x^3y^2 - 21x^2y = 3x^2y(3y^2z + 5xy - 7)$.

Urmează explicația etapelor de calcul. Fiecare termen se împarte la factorul comun: $9x^2y^3z : (3x^2y) = 3y^2z$, apoi $15x^3y^2 : (3x^2y) = 5xy$, iar $21x^2y : (3x^2y) = 7$.

Model de rezolvare. Primul exercițiu cere scoaterea factorului comun, după model. Modelul este: $a(x + 1) + b(x + 1) = (x + 1)(a + b)$.

La punctul a) avem, $(x + 2)(x - 3) + 4(x + 2)$. Observăm că factorul comun este paranteza, $(x + 2)$. Scriem: $(x + 2)(x - 3) + 4(x + 2) = (x + 2)[(x - 3) + 4] = (x + 2)(x + 1)$.

La punctul b) avem, $a(x + y) + b(x + y)$. Factorul comun este paranteza, $(x + y)$. Scriem: $a(x + y) + b(x + y) = (x + y)(a + b)$.

La punctul c) avem, $(x + 3)^2 - (x + 3)$. Factorul comun este, $(x + 3)$. Reținem că, $(x + 3)^2 = (x + 3)(x + 3)$, și că, $(x + 3) = (x + 3) \cdot 1$. Scriem: $(x + 3)^2 - (x + 3) = (x + 3)[(x + 3) - 1] = (x + 3)(x + 2)$.

La punctul d) avem, $(x - 2)^2 - (x - 2)^3$. Factorul comun este, $(x - 2)^2$. Scriem: $(x - 2)^2 - (x - 2)^3 = (x - 2)^2 [1 - (x - 2)] = (x - 2)^2 (1 - x + 2) = (x - 2)^2 (3 - x)$.

Al doilea exercițiu sună așa. Știind că $xy = -7$ și $x + y = 2$, calculează $3x^2y + 3xy^2$.

Identificăm factorul comun pentru expresia $3x^2y + 3xy^2$. Acesta este $3xy$. Scoatem factorul comun: $3x^2y + 3xy^2 = 3xy(x + y)$. Înlocuim valorile date în enunț, adică $xy = -7$ și $x + y = 2$, și calculăm $3 \cdot (-7) \cdot 2 = -21 \cdot 2 = -42$. Rezultatul final este -42.

Exersează! Acum e rândul tău, cu trei exerciții.

Exercițiul 1: calculează, folosind factorul comun. La punctul a), $157\cdot 79+21\cdot 157$. La punctul b), $478\cdot 132+478\cdot 18-50\cdot 478$.

Exercițiul 2: pentru care numere naturale nenule <x> este adevărată relația $x(x-4)=0$?

Exercițiul 3: pentru câte numere reale <x> este adevărată relația: $(x+1)(x-1)(x^2+1)=0$?
