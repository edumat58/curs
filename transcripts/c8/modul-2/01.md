C10.1 - Adunarea și scăderea fracțiilor algebrice. În acest curs vom aborda adunarea și scăderea fracțiilor algebrice. O să înveți cum se adună și cum se scad două astfel de fracții, mai întâi când ele au același numitor, apoi când numitorii sunt diferiți.

Pornim de la definiție. Suma, respectiv diferența, a două fracții algebrice este tot o fracție algebrică. Adunarea, respectiv scăderea, a două fracții algebrice care au același numitor se efectuează adunând, respectiv scăzând, numărătorii și păstrând numitorul.

Scris cu litere, dacă <A>, <B> și P sunt expresii algebrice cu $P \neq 0$, atunci $\frac{A}{P} + \frac{B}{P} = \frac{A + B}{P}$, iar la scădere $\frac{A}{P} - \frac{B}{P} = \frac{A - B}{P}$.

Observă că numitorul rămâne neatins: toată socoteala se face la numărător.

Exemple. Să luăm prima situație, $\frac{5x - 3}{4} + \frac{x}{4} + \frac{x^2 + 12}{4}$. Toate trei fracțiile au același numitor, așa că adunăm numărătorii și păstrăm numitorul: $\frac{5x - 3}{4} + \frac{x}{4} + \frac{x^2 + 12}{4} = \frac{5x - 3 + x + x^2 + 12}{4}$. Reducem termenii asemenea de la numărător și obținem $\frac{x^2 + 6x + 9}{4}$. Numărătorul este pătratul unui binom, deci forma finală se scrie $\frac{(x + 3)^2}{4}$.

Al doilea exemplu, $\frac{x - 3}{x + 2} + \frac{2x - 1}{x + 2}$. Numitorul comun este $x + 2$, iar numărătorii se adună: $\frac{x - 3}{x + 2} + \frac{2x - 1}{x + 2} = \frac{x - 3 + (2x - 1)}{x + 2}$. După reducerea termenilor asemenea rămâne $\frac{3x - 4}{x + 2}$.

Al treilea exemplu este o scădere, $\frac{2x - 3}{x + 3} - \frac{x - 1}{x + 3}$. Numitorul $x + 3$ se păstrează, iar al doilea numărător se scade întreg, cu paranteză: $\frac{2x - 3}{x + 3} - \frac{x - 1}{x + 3} = \frac{2x - 3 - (x - 1)}{x + 3} = \frac{x - 2}{x + 3}$. Reține paranteza de la scădere, fiindcă ea schimbă semnele tuturor termenilor din al doilea numărător.

Metoda de Rezolvare. Dacă fracțiile algebrice nu au același numitor, pentru adunare sau scădere, se aduc la același numitor prin amplificare sau simplificare.

Pasul 1. Se descompun numitorii. Pasul 2. Se află numitorul comun. Pasul 3. Se aduc fracțiile la același numitor prin amplificare, apoi se efectuează calculele.

De reținut: dacă <A>, <B>, P și <Q> sunt expresii algebrice cu $P \neq 0$ și $Q \neq 0$, atunci $\frac{A}{P} + \frac{B}{Q} = \frac{AQ + BP}{PQ}$.

Exemple. Pornim de la $\frac{2x + 7}{3x} + \frac{x - 3}{2x^2} + \frac{4x + 5}{6}$. Amplificăm astfel încât toate să aibă același numitor, $6x^2$. Prima fracție devine $\frac{2x + 7}{3x} = \frac{2x(2x + 7)}{6x^2}$, a doua devine $\frac{x - 3}{2x^2} = \frac{3(x - 3)}{6x^2}$, iar a treia devine $\frac{4x + 5}{6} = \frac{x^2(4x + 5)}{6x^2}$.

Efectuăm adunarea și obținem $\frac{2x(2x + 7) + 3(x - 3) + x^2(4x + 5)}{6x^2}$. Se continuă dezvoltarea și simplificarea numerelor și a termenilor, după caz: $\frac{2x(2x + 7) + 3(x - 3) + x^2(4x + 5)}{6x^2} = \frac{4x^2 + 14x + 3x - 9 + 4x^3 + 5x^2}{6x^2} = \frac{4x^3 + 9x^2 + 17x - 9}{6x^2}$.

Al doilea exemplu, $\frac{x - 1}{3x + 3} + \frac{x}{x^2 - 1}$. Începem cu descompunerile: $3x + 3 = 3(x + 1)$, iar $x^2 - 1 = (x - 1)(x + 1)$. Amplificăm și adunăm: $\frac{x - 1}{3(x + 1)} + \frac{x}{(x + 1)(x - 1)} = \frac{(x - 1)^2 + 3x}{3(x + 1)(x - 1)}$. Dezvoltăm numărătorul: $(x - 1)^2 + 3x = x^2 - 2x + 1 + 3x = x^2 + x + 1$. Forma finală este $\frac{x^2 + x + 1}{3(x + 1)(x - 1)}$.
