C11 - Ecuația de gradul al doilea. În acest curs vom aborda ecuațiile de gradul al doilea. O să înveți cum arată o astfel de ecuație, cum se calculează discriminantul ei și cum afli, pornind de la el, câte soluții reale are și care sunt acelea.

Forma generală. O ecuație de gradul al doilea este o ecuație de forma $a x^2 + b x + c = 0$, unde $a, b, c \in \mathbb{R}$ și $a \ne 0$ sunt coeficienții ecuației, iar <x> este necunoscuta.

Observă condiția $a \ne 0$: ea face parte din definiție, la fel ca forma însăși.

Discriminantul ecuației. Discriminantul se notează cu $\Delta = b^2 - 4ac$ și determină numărul soluțiilor reale ale ecuației.

Așadar, înainte să cauți soluțiile, calculezi această expresie: ea îți spune câte soluții reale are ecuația.

Cazuri posibile. Să le luăm pe rând, în funcție de $\Delta$.

Dacă $\Delta > 0$, ecuația are două soluții reale distincte: $x_1 = \frac{-b + \sqrt{\Delta}}{2a}$ și $x_2 = \frac{-b - \sqrt{\Delta}}{2a}$.

Dacă $\Delta = 0$, ecuația are două soluții egale: $x_1 = x_2 = \frac{-b}{2a}$.

Iar dacă $\Delta < 0$, ecuația nu are soluții reale.

Exemple. Să vedem acum cum lucrează regula pe ecuații concrete.

Exemplul 1. Problema cere să rezolvăm ecuația $x^2 + 5x + 6 = 0$.

Identificăm coeficienții: $a = 1, \quad b = 5, \quad c = 6$.

Calculăm discriminantul: $\Delta = b^2 - 4ac = 5^2 - 4\cdot1\cdot6 = 25 - 24 = 1 > 0$.

Deci ecuația are două soluții reale distincte: $x_1 = \frac{-b + \sqrt{\Delta}}{2a} = \frac{-5 + 1}{2} = -2$, apoi $x_2 = \frac{-b - \sqrt{\Delta}}{2a} = \frac{-5 - 1}{2} = -3$.

Răspunsul este $S = \{-3, -2\}$.

Exemplul 2. Problema cere să rezolvăm ecuația $x^2 - 10x + 25 = 0$.

Identificăm coeficienții: $a = 1, \quad b = -10, \quad c = 25$.

Calculăm discriminantul: $\Delta = (-10)^2 - 4\cdot1\cdot25 = 100 - 100 = 0$.

Deci ecuația are două soluții egale: $x_1 = x_2 = \frac{-b}{2a} = \frac{10}{2} = 5$.

Răspunsul este $S = \{5\}$.

Exemplul 3. Problema cere să rezolvăm ecuația $-2x^2 + x - 1 = 0$.

Identificăm coeficienții: $a = -2, \quad b = 1, \quad c = -1$.

Calculăm discriminantul: $\Delta = b^2 - 4ac = 1^2 - 4\cdot(-2)\cdot(-1) = 1 - 8 = -7 < 0$.

Deci ecuația nu are soluții reale.

Răspunsul este $S = \varnothing$.

5. Observație. Uneori, ecuațiile de gradul al doilea nu sunt scrise în forma canonică $a x^2 + b x + c = 0$. În acest caz, se efectuează calcule algebrice pentru a le aduce la această formă.

Exemplul 4. Problema cere să aducem ecuația la forma canonică și să o rezolvăm: $(x - 1)^2 + 2(x - 3)^2 - 8 = 0$.

Rezolvarea pornește de la $(x - 1)^2 + 2(x - 3)^2 - 8 = 0$.

Dezvoltăm parantezele: $x^2 - 2x + 1 + 2(x^2 - 6x + 9) - 8 = 0$, adică $x^2 - 2x + 1 + 2x^2 - 12x + 18 - 8 = 0$.

Reducem termenii asemenea și obținem $3x^2 - 14x + 11 = 0$.

Identificăm coeficienții: $a = 3, \quad b = -14, \quad c = 11$.

Calculăm discriminantul: $\Delta = b^2 - 4ac = (-14)^2 - 4\cdot3\cdot11 = 196 - 132 = 64 > 0$.

Deci ecuația are două soluții reale distincte: $x_1 = \frac{-b + \sqrt{\Delta}}{2a} = \frac{14 + 8}{6} = \frac{22}{6} = \frac{11}{3}$, apoi $x_2 = \frac{-b - \sqrt{\Delta}}{2a} = \frac{14 - 8}{6} = \frac{6}{6} = 1$.

Răspunsul este $S = \left\{1, \frac{11}{3}\right\}$.

Reține pasul în plus: mai întâi aduci ecuația la forma canonică, apoi calculezi discriminantul și aplici formulele ca de obicei.
