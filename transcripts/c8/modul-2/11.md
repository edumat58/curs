C2* | EXTRA - Triunghiul dreptunghic. Teorema lui Pitagora. În acest curs vom aborda triunghiul dreptunghic și legătura dintre laturile lui. O să înveți cum îl recunoști și cum verifici, doar cu numere, dacă un triunghi chiar are un unghi drept.

Să pornim de la ce înseamnă cuvântul. Un triunghi dreptunghic are un unghi drept, adică un unghi de $90^\circ$, iar latura, cateta opusă unghiului de $90^\circ$, se numește ipotenuză.

Proprietăți. Prima proprietate. Un triunghi este dreptunghic dacă unghiurile ascuțite sunt complementare. Iar două unghiuri sunt complementare dacă suma lor este $90^\circ$.

A doua proprietate. Dacă un triunghi este dreptunghic, diametrul cercului circumscris este egal cu ipotenuza. Amintește-ți ce înseamnă asta: un cerc de centru <O> are o rază <r> trasată din centru până la un punct de pe marginea lui, iar diametrul este $2 \times r$.

Să vedem cum arată lucrurile pe un triunghi ABC. Laturile lui sunt segmentele AB, BC și AC, iar vârfurile sunt punctele A, B și C. Două dintre laturi sunt catetele, cateta 1 și cateta 2, iar a treia latură este ipotenuza. Cercul circumscris are centrul în punctul <O>, raza lui este $r = AO = OB$, iar diametrul este $D = 2 \times r = AB$, adică exact ipotenuza triunghiului.

Teorema lui Pitagora. Iată ce trebuie reținut. Dacă un triunghi este dreptunghic, atunci pătratul ipotenuzei este egal cu suma pătratelor catetelor.

Scrisă cu litere, teorema arată așa: $a^2 + b^2 = c^2$, unde <a> este cateta 1, adică segmentul AB, <b> este cateta 2, adică segmentul BC, iar c este ipotenuza, adică segmentul AC.

Recunoașterea unui triunghi dreptunghic. Reține următoarele lucruri importante. Dacă un triunghi are un unghi drept, atunci este dreptunghic. Dacă un triunghi are două unghiuri complementare, atunci este dreptunghic. Și dacă suma pătratelor a două laturi este egală cu pătratul celei de-a treia laturi, atunci triunghiul este dreptunghic.

Exemplu curs. Se dă următorul triunghi $\triangle ABC$ cu laturile $AB = 24mm$, $BC = 4cm$ și $AC = 32mm$. Verificați dacă triunghiul este dreptunghic.

Începem prin a transforma toate unitățile de măsură în milimetri: $4cm = 40mm$.

Rezultă că avem $AC = 32mm$, $AB = 24mm$ și $BC = 40mm$.

Verificăm acum dacă $AB^2 + AC^2 = BC^2$.

Pe de o parte, $BC^2 = 40^2 = 1600mm$. Pe de altă parte, $AB^2 + AC^2 = 24^2 + 32^2 = 576 + 1024 = 1600mm$.

Cum cele două expresii sunt egale, triunghiul este dreptunghic.
