C6 – Raționalizarea numitorului folosind conjugata. În acest curs vom aborda fracțiile care au la numitor sume sau diferențe cu radicali. O să înveți ce este conjugatul unui număr și cum îl folosești ca să scapi de radicalul de la numitor.

Introducere. De ce raționalizăm numitorul? Raționalizarea numitorului înseamnă transformarea unei fracții care are un radical în numitor într-o fracție echivalentă, fără radical în numitor. Facem acest lucru pentru a simplifica calculele și pentru a obține forme mai ușor de lucrat.

Pentru numitori care sunt sume sau diferențe de termeni cu radicali, folosim metoda conjugatului.

Conjugatul unui număr. Iată definiția. Conjugatul unui număr de forma $a + b\sqrt{c}$, unde <a> și <b> sunt numere raționale, iar <c> este un număr natural care nu este pătrat perfect, este $a - b\sqrt{c}$. Similar, conjugatul lui $a - b\sqrt{c}$ este $a + b\sqrt{c}$. Cu alte cuvinte, conjugatul se obține schimbând semnul din fața radicalului.

Observă un lucru esențial: produsul unui număr cu conjugatul său este întotdeauna un număr rațional, pentru că $(a + b\sqrt{c})(a - b\sqrt{c}) = a^2 - b^2 c$. Radicalul dispare, și tocmai pe asta se sprijină toată metoda.

Metoda de raționalizare pentru numitor de forma a + b√c. Pentru a raționaliza un numitor de forma $a + b\sqrt{c}$, unde <a> și <b> sunt numere raționale, iar <c> este un număr natural care nu este pătrat perfect, urmezi doi pași.

Primul pas: înmulțești numărătorul și numitorul cu conjugatul numitorului, adică $a - b\sqrt{c}$.

Al doilea pas: simplifici expresia rezultată folosind identitatea remarcabilă $(a + b\sqrt{c})(a - b\sqrt{c}) = a^2 - (b\sqrt{c})^2 = a^2 - b^2 c$.

Formula generală este $\dfrac{p}{a + b\sqrt{c}} = \dfrac{p(a - b\sqrt{c})}{(a + b\sqrt{c})(a - b\sqrt{c})} = \dfrac{p(a - b\sqrt{c})}{a^2 - b^2 c}$. Reține că fracția nu se schimbă, pentru că am înmulțit și sus, și jos cu același număr.

Exemple. Primul exemplu: să raționalizăm $\dfrac{1}{2 + \sqrt{3}}$. Înmulțim cu conjugatul $2 - \sqrt{3}$ și obținem $\dfrac{1}{2 + \sqrt{3}} \cdot \dfrac{2 - \sqrt{3}}{2 - \sqrt{3}} = \dfrac{2 - \sqrt{3}}{(2 + \sqrt{3})(2 - \sqrt{3})} = \dfrac{2 - \sqrt{3}}{4 - 3} = \dfrac{2 - \sqrt{3}}{1} = 2 - \sqrt{3}$. Numitorul a devenit 1, așa că rezultatul este chiar $2 - \sqrt{3}$.

Al doilea exemplu: să raționalizăm $\dfrac{5}{3 + 2\sqrt{2}}$. Înmulțim cu conjugatul $3 - 2\sqrt{2}$ și obținem $\dfrac{5}{3 + 2\sqrt{2}} \cdot \dfrac{3 - 2\sqrt{2}}{3 - 2\sqrt{2}} = \dfrac{5(3 - 2\sqrt{2})}{(3 + 2\sqrt{2})(3 - 2\sqrt{2})} = \dfrac{5(3 - 2\sqrt{2})}{9 - 8} = \dfrac{5(3 - 2\sqrt{2})}{1} = 15 - 10\sqrt{2}$.

Al treilea exemplu: să raționalizăm $\dfrac{\sqrt{5}}{1 + \sqrt{5}}$. Înmulțim cu conjugatul $1 - \sqrt{5}$ și obținem $\dfrac{\sqrt{5}}{1 + \sqrt{5}} \cdot \dfrac{1 - \sqrt{5}}{1 - \sqrt{5}} = \dfrac{\sqrt{5}(1 - \sqrt{5})}{(1 + \sqrt{5})(1 - \sqrt{5})} = \dfrac{\sqrt{5} - 5}{1 - 5} = \dfrac{\sqrt{5} - 5}{-4} = \dfrac{5 - \sqrt{5}}{4}$. Aici numitorul a ieșit negativ, așa că am schimbat semnele ca să scriem rezultatul cu numitor pozitiv.

Metoda de raționalizare pentru numitor de forma a - b√c. Pentru un numitor de forma $a - b\sqrt{c}$, procedeul este similar: înmulțim numărătorul și numitorul cu conjugatul $a + b\sqrt{c}$.

Formula generală este $\dfrac{p}{a - b\sqrt{c}} = \dfrac{p(a + b\sqrt{c})}{(a - b\sqrt{c})(a + b\sqrt{c})} = \dfrac{p(a + b\sqrt{c})}{a^2 - b^2 c}$. Observă că numitorul final este același, $a^2 - b^2 c$, indiferent de semnul cu care începem.

Exemple. Primul exemplu: să raționalizăm $\dfrac{1}{2 - \sqrt{3}}$. Înmulțim cu conjugatul $2 + \sqrt{3}$ și obținem $\dfrac{1}{2 - \sqrt{3}} \cdot \dfrac{2 + \sqrt{3}}{2 + \sqrt{3}} = \dfrac{2 + \sqrt{3}}{4 - 3} = 2 + \sqrt{3}$.

Al doilea exemplu: să raționalizăm $\dfrac{4}{5 - 3\sqrt{2}}$. Înmulțim cu conjugatul $5 + 3\sqrt{2}$ și obținem $\dfrac{4}{5 - 3\sqrt{2}} \cdot \dfrac{5 + 3\sqrt{2}}{5 + 3\sqrt{2}} = \dfrac{4(5 + 3\sqrt{2})}{25 - 18} = \dfrac{4(5 + 3\sqrt{2})}{7} = \dfrac{20 + 12\sqrt{2}}{7}$.

Proprietăți și observații. Să punem cap la cap ce am aflat. Prima proprietate: conjugatul unui număr de forma $a + b\sqrt{c}$ este $a - b\sqrt{c}$, și invers.

A doua proprietate: produsul unui număr cu conjugatul său este întotdeauna un număr rațional, adică $(a + b\sqrt{c})(a - b\sqrt{c}) = a^2 - b^2 c$.

A treia observație: dacă numitorul conține doar un radical simplu, fără sumă sau diferență, folosim metodele anterioare, adică înmulțirea cu radicalul.

Și a patra observație: raționalizarea ajută la compararea, adunarea sau înmulțirea fracțiilor cu radicali în numitor.

Exemplu de aplicare. Să calculăm $\dfrac{1}{1 + \sqrt{2}} + \dfrac{1}{1 - \sqrt{2}}$. Raționalizăm fiecare fracție în parte.

Pentru prima fracție obținem $\dfrac{1}{1 + \sqrt{2}} = 1 - \sqrt{2}$. Pentru a doua fracție obținem $\dfrac{1}{1 - \sqrt{2}} = 1 + \sqrt{2}$.

Acum le adunăm. Suma este $(1 - \sqrt{2}) + (1 + \sqrt{2}) = 2$. Radicalii s-au redus între ei și a rămas un număr întreg.

Metoda de raționalizare pentru numitor de forma √a ± √b. Mai întâi, definiția. Pentru expresii de forma $\sqrt{a} \pm \sqrt{b}$, conjugatul este $\sqrt{a} \mp \sqrt{b}$, adică aceeași expresie cu semnul din mijloc schimbat. Produsul lor este $(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b}) = a - b$.

Pentru a raționaliza un numitor de forma $\sqrt{a} + \sqrt{b}$ sau $\sqrt{a} - \sqrt{b}$, urmezi aceiași doi pași.

Primul pas: înmulțești numărătorul și numitorul cu conjugatul; pentru $\sqrt{a} + \sqrt{b}$, conjugatul este $\sqrt{a} - \sqrt{b}$, și invers.

Al doilea pas: simplifici folosind identitatea $(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b}) = a - b$.

Formula generală este $\dfrac{p}{\sqrt{a} + \sqrt{b}} = \dfrac{p(\sqrt{a} - \sqrt{b})}{(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b})} = \dfrac{p(\sqrt{a} - \sqrt{b})}{a - b}$.

Exemple. Primul exemplu: să raționalizăm $\dfrac{1}{\sqrt{3} + \sqrt{2}}$. Înmulțim cu conjugatul $\sqrt{3} - \sqrt{2}$ și obținem $\dfrac{1}{\sqrt{3} + \sqrt{2}} \cdot \dfrac{\sqrt{3} - \sqrt{2}}{\sqrt{3} - \sqrt{2}} = \dfrac{\sqrt{3} - \sqrt{2}}{3 - 2} = \sqrt{3} - \sqrt{2}$.

Al doilea exemplu: să raționalizăm $\dfrac{5}{\sqrt{5} - \sqrt{3}}$. Înmulțim cu conjugatul $\sqrt{5} + \sqrt{3}$ și obținem $\dfrac{5}{\sqrt{5} - \sqrt{3}} \cdot \dfrac{\sqrt{5} + \sqrt{3}}{\sqrt{5} + \sqrt{3}} = \dfrac{5(\sqrt{5} + \sqrt{3})}{5 - 3} = \dfrac{5(\sqrt{5} + \sqrt{3})}{2}$.

Reține ideea întregii lecții: când numitorul e o sumă sau o diferență cu radicali, îl înmulțești cu conjugatul lui, iar produsul devine un număr rațional.
