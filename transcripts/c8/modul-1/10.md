C8.1 - Calcul literar: expresii algebrice. În acest curs vom aborda calculul cu litere. O să înveți ce este o expresie algebrică, cum se reduce o sumă algebrică și cum se adună, se scad și se înmulțesc două sume algebrice.

Expresii algebrice. Să vorbim mai întâi despre valoarea numerică a unei expresii algebrice. Într-o expresie algebrică, unele numere pot fi reprezentate de litere. Tocmai de aceea o numim și expresie literală.

Să luăm câteva exemple: $3x + 7$, apoi $x^2 - 5x + 8$, apoi $(3x + 3)(2x - 1)$. Acestea sunt expresii algebrice în care litera <x> este o variabilă.

Dacă îi atribuim variabilei <x> un număr, obținem valoarea numerică a expresiei. Să vedem ce se întâmplă dacă $x = 10$. Prima expresie devine $3x + 7 = 3 \cdot 10 + 7 = 37$. A doua devine $x^2 - 5x + 8 = 10^2 - 5 \cdot 10 + 8 = 58$.

Reducerea unei sume algebrice. Fie suma $S = 2x^2 - 4x + 5 + 3x - 2$. Putem rescrie această serie de sume și scăderi într-o singură serie de sume, astfel: $S = 2x^2 + (-4x) + 5 + 3x + (-2)$.

Observă că <S> este o sumă algebrică de cinci termeni: $+2x^2$, $-4x$, $+5$, $+3x$ și $-2$. Ordinea termenilor se poate modifica și putem grupa termenii asemenea, ceea ce permite reducerea sumei algebrice.

Grupăm termenii asemenea și reducem: $S = 2x^2 + (-4x) + 5 + 3x + (-2) = 2x^2 + (-4x + 3x) + (5 - 2) = 2x^2 - x + 3$.

Așadar <S> a fost redusă la o sumă algebrică de trei termeni: $+2x^2$, $-x$ și $+3$.

Adunarea a două sume algebrice. Fie <A> și <B> două sume algebrice deja reduse: $A = 2x^2 - x + 7$ și $B = -5x^2 + 4x$. Prin adunare obținem $A + B = 2x^2 + (-x) + 7 + (-5x^2) + 4x$.

Grupăm termenii asemenea și reducem: $A + B = 2x^2 + (-5x^2) + (-x) + 4x + 7 = (2x^2 - 5x^2) + (-x + 4x) + 7 = -3x^2 + 3x + 7$.

Scăderea a două sume algebrice. Fie din nou <A> și <B> două sume algebrice deja reduse: $A = 2x^2 - x + 7$ și $B = -5x^2 + 4x$. Pentru a rescrie o scădere algebrică, adăugăm al doilea termen cu semn schimbat.

Să vedem mai întâi cum arată opusul lui <B>: $-B = -(-5x^2 + 4x) = 5x^2 - 4x$. Obținem astfel $A - B = A + (-B)$. De aici putem folosi proprietățile adunării a două sume algebrice și, la final, reducerea unei sume algebrice.

Prin scădere și reducere: $A - B = A + (-B) = 2x^2 + (-x) + 7 + 5x^2 + (-4x) = (2x^2 + 5x^2) + (-x - 4x) + 7 = 7x^2 - 5x + 7$.

Înmulțirea a două sume algebrice. Ca să înmulțim două sume algebrice, avem nevoie mai întâi de ceva de reținut despre semne.

REGULI DE SEMN. Regulile sunt patru: $(+a) \cdot (+b) = +ab$, apoi $(-a) \cdot (-b) = +ab$, apoi $(+a) \cdot (-b) = -ab$ și $(-a) \cdot (+b) = -ab$.

La înmulțirea a două sume algebrice, fiecare termen se înmulțește cu fiecare termen, aplicând regulile semnelor. Apoi se reduce suma algebrică obținută.

Să luăm un exemplu. Fie $A = 3x + 7$ și $B = -x + 2$. Prin înmulțire: $A \cdot B = (3x + 7)(-x + 2) = 3x \cdot (-x) + 3x \cdot 2 + 7 \cdot (-x) + 7 \cdot 2 = -3x^2 + 6x - 7x + 14 = -3x^2 - x + 14$.

Reține că la înmulțire fiecare termen se înmulțește cu fiecare termen, cu tot cu semnul lui, iar la final suma algebrică obținută se reduce.
