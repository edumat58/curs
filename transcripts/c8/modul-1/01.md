C1 - Notații și simboluri matematice. În acest curs vom aborda limbajul simbolic în care se scrie matematica. O să înveți ce înseamnă fiecare notație — pentru numere, pentru puncte, pentru funcții și pentru raționamente — ca să o citești și să o folosești corect.

Cu numere. Începem cu mulțimile de numere. Simbolul $\mathbb{R}$ înseamnă mulțimea numerelor reale, adică $\mathbb{R} = ]-\infty ; +\infty[$. Dacă vrem toate numerele reale în afară de unul singur, scriem $\mathbb{R}\setminus\{a\}$, adică mulțimea numerelor reale fără <a>. Simbolul $\mathbb{N}$ înseamnă mulțimea numerelor naturale, $\mathbb{N} = \{0 ; 1 ; 2 ; \dots\}$, iar simbolul $\mathbb{Z}$ înseamnă mulțimea numerelor întregi.

Mai departe, $\mathbb{R}^+$, scris și $[0 ; +\infty)$, este mulțimea numerelor reale pozitive, adică a numerelor <x> cu $x \ge 0$. La fel, $\mathbb{R}^-$, scris și $(-\infty ; 0]$, este mulțimea numerelor reale negative, cu $x \le 0$.

Urmează intervalele. Notația $[-3 ; 5]$ este un interval: mulțimea numerelor reale dintre $-3$ și $5$, cu capetele incluse. Notația $(-3 ; 5)$ este tot un interval cu numerele reale dintre $-3$ și $5$, dar cu capetele excluse. Iar $[-3 ; 5)$ este intervalul numerelor reale dintre $-3$ și $5$ care îl include pe $-3$, dar nu și pe $5$. Atenție la deosebire: $\{-3 ; 5\}$, cu acolade, este mulțimea care conține doar numerele $-3$ și $5$, nimic între ele. Iar notația $(3 ; 5)$ poate însemna și altceva: coordonatele unui punct sau ale unui vector.

La numerele zecimale, scrierea $0{,}24535\dots$ înseamnă o dezvoltare zecimală infinită. Iar $0,(245)$ este un număr zecimal cu perioada 245, adică grupul de cifre 245 se repetă.

În sfârșit, $\overline{abc}$ este un număr compus din cifre necunoscute: <a> este cifra ordinului sutelor, <b> a zecilor și <c> a unităților. De aici vine scrierea $\overline{abc} = 100\cdot a + 10\cdot b + c$.

Cu puncte. Acum notațiile geometrice, construite cu două puncte, <A> și <B>. Scrierea $AB$, simplă, fără nicio paranteză, înseamnă o distanță: lungimea dintre punctele <A> și <B>. Cu paranteze drepte, $[AB]$ este segmentul cu extremitățile <A> și <B>. Cu paranteze rotunde, $(AB)$ este dreapta care trece prin punctele <A> și <B>. Combinația $[AB)$ este semidreapta cu originea în <A> și trecând prin <B>. Cu o săgeată deasupra, $\overrightarrow{AB}$ este vectorul cu originea în <A> și extremitatea în <B>. Iar $(A ; B)$ este un reper al dreptei $(AB)$, cu originea în <A> și cu $AB = 1$.

Despre funcții. Scrierea $f : x \to y$ înseamnă o funcție care asociază fiecărui <x> valoarea <y>. Scrierea $f(x)$ se citește imaginea lui <x> prin funcția <f>. Iar $D_f$ înseamnă domeniul de definiție al funcției <f>.

Pentru relații, mulțimi și raționamente. Semnul $\in$ se citește „aparține”. De exemplu, $3 \in [1 ; 5]$. Semnul $\subset$ se citește „este inclus în”. De exemplu, $\{2 ; 3\} \subset [1 ; 5]$. Semnul $\cap$ înseamnă „intersecție”. De exemplu, $[0 ; 2] \cap [1 ; 5] = [1 ; 2]$. Semnul $\cup$ înseamnă „reuniune”. De exemplu, $[0 ; 2] \cup [1 ; 5] = [0 ; 5]$. Notația $\overline{A}$ înseamnă complementara mulțimii <A>. De exemplu, $[2 ; +\infty)$ este complementara lui $(-\infty ; 2)$ în $\mathbb{R}$.

Urmează semnele de comparație. Semnul $=$ se citește „este egal cu”. Semnul $\le$ se citește „este mai mic sau egal cu”. Semnul $\ge$ se citește „este mai mare sau egal cu”.

La final, semnele folosite în raționamente. Semnul $\Rightarrow$ se citește „implică” sau „deci”. Semnul $\Leftrightarrow$ se citește „echivalează” sau „dacă și numai dacă”. Simbolul $\forall$ se citește „pentru orice”, iar simbolul $\exists$ se citește „există”. Reține că fiecare dintre aceste simboluri este o prescurtare: în spatele lui stă o propoziție întreagă, pe care acum știi să o citești.
