C2 - Mulțimea nr. reale R. În acest curs vom aborda mulțimea numerelor reale. O să înveți cum se așază numerele reale pe dreapta gradată, ce sunt intervalele, ce înseamnă valoarea absolută și distanța dintre două numere, și cum se leagă între ele mulțimile de numere pe care le cunoști.

Manipularea numerelor reale. Începem cu felul în care lucrăm cu numerele reale și cu locul lor pe dreapta gradată.

Mulțimea $\mathbb{R}$ și dreapta numerică. Fiecărui punct de pe o dreaptă gradată îi asociem un unic număr real, și reciproc: un număr real este abscisa unui punct pe dreapta gradată. Așadar dreapta gradată și mulțimea numerelor reale se corespund punct cu punct.

Pe dreapta numerelor reale, numerele <x> cu $x \leq 0$ sunt numerele reale negative, numărul <x> cu $x = 0$ este realul nul, iar numerele <x> cu $x \geq 0$ sunt numerele reale pozitive.

Intervalele din $\mathbb{R}$. Un interval este o bucată a dreptei numerelor reale sau poate să reprezinte în întregime mulțimea. Mulțimea numerelor reale întreagă se scrie ca interval astfel: $\mathbb{R} = ( -\infty ; +\infty )$.

Intervale mărginite: acestea prind numerele între două capete. Dacă $a \leq x \leq b$, atunci <x> aparține intervalului $[a ; b]$, scris cu paranteze pătrate, pentru că aici și capetele <a> și <b> sunt cuprinse. Dacă $a < x < b$, atunci <x> aparține intervalului $(a ; b)$, scris cu paranteze rotunde, pentru că de data aceasta capetele nu mai sunt cuprinse.

Intervale nemărginite: acestea se întind la nesfârșit într-o parte. Dacă $x \leq a$, atunci <x> aparține intervalului $(-\infty ; a]$. Dacă $x \geq a$, atunci <x> aparține intervalului $[a ; +\infty)$.

Valoarea absolută a unui număr real. Valoarea absolută a numărului real <a> este distanța dintre <a> și 0 pe dreapta gradată. Dacă <O> este originea dreptei gradate, <I> este punctul de abscisă 1 și <M> este punctul de abscisă <a>, atunci $|a| = OM$. Segmentele MM, OO și II au aceeași lungime, unghiul cu vârful în <M> este drept și tot drept este și unghiul cu vârful în <O>. Concret, valoarea absolută se calculează așa: dacă $a \geq 0$, atunci $|a| = a$, iar dacă $a < 0$, atunci $|a| = -a$.

Distanța dintre două numere reale $a$ și $b$. Distanța dintre două numere reale <a> și <b> este valoarea absolută a diferenței lor: $|b-a| = AB$, unde <A> și <B> sunt punctele de abscise <a> și <b> de pe dreapta gradată. Segmentele AA, BB, OO și II au aceeași lungime, unghiul cu vârful în <A> este drept și tot drept este și unghiul cu vârful în <B>.

Intervalul $[a-r ; a+r]$. Numărul <a> este centrul acestui interval.

Condiția $|x-a| \leq r$. Toate numerele reale <x> din intervalul $[a-r ; a+r]$ sunt la o distanță mai mică sau egală cu <r> de numărul real <a>. Scris matematic: $x \in [a-r ; a+r] \Leftrightarrow |x-a| \leq r$. Reține că cele două scrieri spun exact același lucru.

Alte mulțimi de numere. Mulțimea numerelor reale cuprinde mai multe mulțimi de numere pe care le cunoști deja. Să le trecem în revistă.

Mulțimea $\mathbb{N}$ a numerelor naturale și $\mathbb{Z}$ a numerelor întregi. Mulțimea $\mathbb{N}$ include toate numerele întregi pozitive: $\mathbb{N} = \{0 ; 1 ; 2 ; 3 ; \dots\}$. Mulțimea $\mathbb{Z}$ include numerele naturale și numerele naturale scrise sub formă negativă: $\mathbb{Z} = \{\dots ; -3 ; -2 ; -1 ; 0 ; 1 ; 2 ; 3 ; \dots\}$.

Mulțimea $\mathbb{Q}$ a numerelor raționale. Un număr rațional se poate scrie sub forma $\frac{a}{b}$, unde $a \in \mathbb{Z}$ și $b \in \mathbb{N}^*$, adică <b> este un număr natural nenul.

Numere iraționale $\mathbb{R} \setminus \mathbb{Q}$. Numerele reale care nu sunt raționale sunt iraționale. Astfel de numere sunt $\sqrt{2}$, $-\cos(23^\circ)$, $\pi$ sau $24,11222333345\dots$ Reține că un număr real este fie rațional, fie irațional.
