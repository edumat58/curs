C2 - Mulțimea nr. reale R. În acest curs vom aborda mulțimea numerelor reale. O să înveți cum se așază numerele reale pe dreapta gradată, cum se scriu bucățile de dreaptă numite intervale, ce înseamnă valoarea absolută și distanța dintre două numere, și ce alte mulțimi de numere stau înăuntrul mulțimii numerelor reale.

Manipularea numerelor reale. Prima parte a lecției este despre lucrul propriu-zis cu numerele reale: unde stau ele, cum se scriu porțiunile de dreaptă pe care le ocupă și cum se măsoară depărtarea dintre două dintre ele.

Mulțimea $\mathbb{R}$ și dreapta numerică. Fiecărui punct de pe o dreaptă gradată îi asociem un unic număr real, și reciproc: un număr real este abscisa unui punct pe dreapta gradată. Așadar dreapta gradată și mulțimea numerelor reale se corespund punct cu punct, fără să rămână nimic pe dinafară nici într-o parte, nici în cealaltă.

Pe dreapta numerelor reale deosebim trei situații. Numerele <x> cu $x \leq 0$ sunt numerele reale negative. Numărul <x> pentru care $x = 0$ este realul nul. Iar numerele <x> cu $x \geq 0$ sunt numerele reale pozitive. Reține cuvântul abscisă: el este numele numărului real care etichetează un punct pe dreapta gradată.

Intervalele din $\mathbb{R}$. Un interval este o bucată a dreptei numerelor reale sau poate să reprezinte în întregime mulțimea. Chiar mulțimea numerelor reale, luată toată, se scrie ca interval: $\mathbb{R} = ( -\infty ; +\infty )$.

Intervale mărginite: sunt cele care prind numerele între două capete. Dacă <x> se află între <a> și <b>, cu capetele cuprinse și ele, scriem $a \leq x \leq b \quad \Rightarrow \quad [a ; b]$. Paranteza dreaptă arată aici că <a> și <b> fac ele însele parte din interval. Dacă în schimb capetele nu sunt cuprinse, scriem $a < x < b \quad \Rightarrow \quad (a ; b)$, iar paranteza rotundă le lasă afară. Observă că deosebirea dintre cele două intervale stă numai în felul parantezei.

Intervale nemărginite: sunt cele care se întind la nesfârșit într-o singură parte. Dacă <x> este cel mult <a>, scriem $x \leq a \quad \Rightarrow \quad (-\infty ; a]$. Dacă <x> este cel puțin <a>, scriem $x \geq a \quad \Rightarrow \quad [a ; +\infty )$. La capătul cu infinit paranteza rămâne mereu rotundă, pentru că infinitul nu este un număr care să poată fi cuprins în interval.

Valoarea absolută a unui număr real. Definiție. Valoarea absolută a numărului real <a> este distanța dintre <a> și 0 pe dreapta gradată. Pe dreapta gradată, <O> este originea, adică punctul de abscisă 0, <I> este punctul de abscisă 1, iar <M> este punctul de abscisă <a>. Valoarea absolută a lui <a> este atunci lungimea segmentului OM, care se calculează pe cazuri: $|a| = OM = \begin{cases} a & \text{daca} \quad a \geq 0 \\ - a & \text{daca} \quad a < 0 \end{cases}$. Cu alte cuvinte, dacă <a> este pozitiv sau nul, valoarea lui absolută este chiar <a>, iar dacă <a> este negativ, valoarea lui absolută este $-a$, adică opusul lui. Reține că valoarea absolută este o distanță, deci nu poate ieși niciodată negativă.

Distanța dintre două numere reale $a$ și $b$. Distanța dintre două numere reale <a> și <b> este valoarea absolută a diferenței lor: $|b-a| = AB$. Aici <A> este punctul de abscisă <a> și <B> este punctul de abscisă <b>, iar distanța dintre cele două numere este chiar lungimea segmentului dintre punctele lor. Ordinea în care scazi nu contează: valoarea absolută șterge semnul, deci de la <a> la <b> este tot atât cât de la <b> la <a>.

Intervalul $[a-r ; a+r]$. <a> este centrul acestui interval. Capătul din stânga este $a-r$, capătul din dreapta este $a+r$, iar <r> este depărtarea de la centru până la fiecare dintre cele două capete, aceeași și într-o parte, și în cealaltă.

Condiția $|x-a| \leq r$. Toate numerele reale <x> din intervalul $[a-r ; a+r]$ sunt la o distanță mai mică sau egală cu <r> de numărul real <a>. Scris pe scurt: $x \in [a-r ; a+r] \quad \Leftrightarrow \quad |x-a| \leq r$. Reține că cele două scrieri spun exact același lucru: a fi în interval și a fi la o distanță de cel mult <r> de centru înseamnă una și aceeași condiție.

Alte mulțimi de numere. Înăuntrul mulțimii numerelor reale stau alte mulțimi de numere, pe care le folosești de mult. Să le trecem în revistă pe rând.

Mulțimea $\mathbb{N}$ a numerelor naturale și $\mathbb{Z}$ a numerelor întregi. Mulțimea $\mathbb{N}$ include toate numerele întregi pozitive: $\mathbb{N} = \{0 ; 1 ; 2 ; 3 ; \dots\}$. Mulțimea $\mathbb{Z}$ include numerele naturale și numerele naturale scrise sub formă negativă: $\mathbb{Z} = \{\dots ; -3 ; -2 ; -1 ; 0 ; 1 ; 2 ; 3 ; \dots\}$.

Mulțimea $\mathbb{Q}$ a numerelor raționale. Un număr rațional se poate scrie sub forma $\frac{a}{b}$, unde $a \in \mathbb{Z}$ și $b \in \mathbb{N}^*$, adică numitorul <b> este un număr natural nenul.

Numere iraționale $\mathbb{R} \setminus \mathbb{Q}$. Numerele reale care nu sunt raționale sunt iraționale. Astfel de numere sunt $\sqrt{2}$, apoi $-\cos(23^\circ)$, apoi $\pi$ și $24,11222333345\dots$. Reține că un număr real este ori rațional, ori irațional, a treia posibilitate nu există.
