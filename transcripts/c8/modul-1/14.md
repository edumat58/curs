C9 - Existența, amplificarea și simplificarea fracțiilor algebrice. În acest curs vom aborda fracțiile algebrice. O să înveți ce este o fracție algebrică, pentru ce valori ale necunoscutei există, apoi cum se amplifică și cum se simplifică.

Introducere. Pornim de la definiție. Numim fracție algebrică raportul dintre două expresii algebrice. Iată câteva exemple de fracții algebrice: $E(x) = \frac{7x + 1}{3x - 6}$, apoi $F(x) = \frac{x^3 + 1}{2x}$ și $F(a) = \frac{3a - 1}{a^2 + a + 1}$.

Să luăm un prim exemplu. Ni se cere să calculăm valoarea numerică a fracției algebrice $F(x) = \dfrac{3x + 1}{x - 2}$ pentru $x = 3$. Înlocuim pe <x> cu 3, atât la numărător, cât și la numitor, și obținem $F(3) = \frac{3 \cdot 3 + 1}{3 - 2} = \frac{9 + 1}{1} = \frac{10}{1} = 10$. Deci valoarea numerică a fracției pentru $x = 3$ este 10.

Observație. Reține un lucru important: valoarea numerică a unei fracții algebrice nu se poate calcula pentru orice număr real. De exemplu, pentru $x = 2$ vom obține $E(2) = \frac{3 \cdot 2 + 1}{2 - 2} = \frac{6 + 1}{0} = \frac{7}{0}$. Fracția nu este definită, pentru că o fracție sau un raport nu pot avea numitorul egal cu zero.

De aici vine al doilea exemplu. Determinăm valorile lui <x> pentru care fracția algebrică $E(x)$ nu este definită, în următoarele cazuri.

a) $ E(x) = \dfrac{7x + 1}{3x - 6}$. Căutăm valorile care fac numitorul zero, pentru că exact acolo fracția nu există. Egalăm numitorul cu zero și rezolvăm: $3x - 6 = 0 \Rightarrow 3x = 6 \Rightarrow x = \frac{6}{3} = 2$. Prin urmare, $E(x)$ nu este definită pentru $x = 2$.

b) $E(x) = \dfrac{5 - x^2}{x^2 + 6x}$. Procedăm la fel: egalăm numitorul cu zero. De data aceasta dăm factor comun pe <x> și obținem $x^2 + 6x = 0 \Rightarrow x(x + 6) = 0 \Rightarrow x = 0 \ \text{sau} \ x = -6$. Un produs este zero când unul dintre factori este zero. Prin urmare $E(x)$ nu este definită pentru $x \in \{0, -6\}$.

Aici se leagă o definiție nouă. Mulțimea numerelor reale pentru care se poate calcula valoarea numerică a unei fracții algebrice se numește domeniul de definiție al fracției algebrice și se notează cu litera D. Al treilea exemplu ne cere să determinăm domeniul de definiție pentru fracția algebrică $F(x)$ în următoarele cazuri.

a) $$F(x) = \dfrac{x^3}{4x - 8}$$

Numitorul se anulează când $4x - 8 = 0 \Rightarrow 4x = 8 \Rightarrow x = \frac{8}{4} = 2$. Deci domeniul de definiție este $D = \mathbb{R} \setminus \{2\}$, adică mulțimea numerelor reale din care scoatem numărul 2.

b) $F(x) = \dfrac{x^2}{x^2 - 9}$. Egalăm numitorul cu zero: $x^2 - 9 = 0 \Rightarrow x^2 = 9 \Rightarrow x = \pm 3$. Deci domeniul de definiție este $D = \mathbb{R} \setminus \{-3, 3\}$, adică toate numerele reale în afară de $-3$ și de 3.

Operația de amplificare. Reține proprietatea: operația de amplificare a unui raport algebric constă în a înmulți atât numărătorul cât și numitorul cu o expresie algebrică nenulă. Să vedem câteva exemple.

La a), amplificăm fracția cu 4: $\dfrac{3x}{x^2 + 1} = \dfrac{4 \cdot 3x}{4 \cdot (x^2 + 1)} = \dfrac{12x}{4x^2 + 4}$.

La b), amplificăm cu $3x$: $\dfrac{2x}{3x} = \dfrac{3x \cdot 2x}{3x \cdot (x + 5)} = \dfrac{6x^2}{3x^2 + 15x}$.

La c), amplificăm cu $x + 2$: $\dfrac{x - 2}{x + 2} = \dfrac{(x + 2)(x - 2)}{(x + 2)(x + 2)} = \dfrac{x^2 - 4}{x^2 + 4x + 4}$. Observă că la numărător a apărut o diferență de pătrate.

La d), amplificăm cu $x - 1$: $\dfrac{11x - 3}{x^2 + 1} = \dfrac{(x - 1)(11x - 3)}{(x - 1)(x^2 + 1)} = \dfrac{11x^2 - 14x + 3}{x^3 - x^2 + x - 1}$.

Operația de simplificare. Acum proprietatea pereche: operația de simplificare a unui raport algebric constă în a împărți atât numărătorul, cât și numitorul prin aceeași expresie algebrică nenulă. Să luăm două exemple.

Primul: simplificăm prin <x> și obținem $\dfrac{7x^3}{2x^6} = \dfrac{7x^3 : x}{2x^6 : x} = \dfrac{7x^2}{2x^5}$.

Al doilea: simplificăm prin $2x^2$ și obținem $\dfrac{18x^2}{6x^4 + 10x^3} = \dfrac{18x^2 : 2x^2}{(6x^4 + 10x^3) : 2x^2} = \dfrac{9}{3x^2 + 5x}$.

Observație. De reținut: în general, pentru simplificarea fracțiilor algebrice este necesară descompunerea în factori a numărătorului și a numitorului. Să vedem un exemplu: $\frac{3x + 15}{x^2 - 25} = \frac{3(x + 5)}{(x - 5)(x + 5)} = \frac{3}{x - 5}$. La numărător am dat factor comun pe 3, iar la numitor am recunoscut o diferență de pătrate și am descompus-o în produs. Factorul $x + 5$ apare și sus, și jos, așa că se simplifică, iar fracția devine mult mai simplă.
