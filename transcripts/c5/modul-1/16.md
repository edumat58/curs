C14 - Media aritmetică. În acest curs vom aborda media aritmetică a numerelor naturale. O să înveți cum se calculează media pentru două, pentru trei și, în general, pentru <n> numere naturale, pornind de la situații pe care le întâlnim zi de zi.

Media aritmetică a două numere naturale. Media aritmetică a două numere naturale este un concept pe care îl întâlnim în numeroase activități cotidiene. Media aritmetică a două numere naturale <a> și <b> este numărul obținut prin împărțirea la 2 a sumei lor: $ma = \frac{a + b}{2}$.

Să luăm un exemplu. O gospodină cumpără de la piață 1 kg de prune pentru care plătește 2 lei și 1 kg de struguri pentru care plătește 4 lei. Cât plătește gospodina pentru un kilogram de fructe?

Rezolvăm pas cu pas. Pentru 2 kg de fructe, gospodina plătește $2 + 4 = 6$ lei. Pentru 1 kg de fructe, gospodina plătește $6 : 2 = 3$ lei. Deci, pentru un kilogram de fructe gospodina plătește $(2 + 4) : 2 = 3$ lei. Media aritmetică a prețului unui kilogram de fructe este de 3 lei.

Să mai facem două calcule. Media aritmetică a numerelor 7 și 11 este numărul $ma = \frac{7 + 11}{2} = \frac{18}{2} = 9$. Apoi, media aritmetică a numerelor 12 și 28 este numărul $ma = \frac{12 + 28}{2} = \frac{40}{2} = 20$.

Observă însă un lucru important: media aritmetică a două numere naturale nu este totdeauna număr natural. De exemplu, media aritmetică a numerelor 5 și 8 este $ma = \frac{5 + 8}{2} = \frac{13}{2}$, care nu este număr natural.

Media aritmetică a trei numere naturale. Media aritmetică a trei numere naturale <a>, <b> și <c> este numărul obținut prin împărțirea la 3 a sumei lor: $ma = \frac{a + b + c}{3}$.

Să luăm un exemplu. Media aritmetică a numerelor 6, 15 și 24 este numărul $ma = \frac{6 + 15 + 24}{3} = \frac{45}{3} = 15$.

Mai reține o observație. Media aritmetică a <n> numere naturale distincte este mai mare decât cel mai mic dintre numere și mai mică decât cel mai mare dintre numere. De exemplu, media aritmetică a numerelor 2, 18, 21 și 31 este $ma = \frac{2 + 18 + 21 + 31}{4} = \frac{72}{4} = 18$, iar $\min\{2, 18, 21, 31\} = 2$ și $\max\{2, 18, 21, 31\} = 31$. Se verifică relația $2 \le 18 \le 31$, adică media este cuprinsă între cel mai mic și cel mai mare dintre numere.

Media aritmetică a n numere naturale. Fiind date <n> numere naturale notate $a_1, a_2, a_3, \ldots, a_n$, se numește media aritmetică numărul obținut prin împărțirea la <n> a sumei lor: $ma = \frac{a_1 + a_2 + a_3 + \ldots + a_n}{n}$.

Să luăm un exemplu. La sfârșitul primului semestru Maria are la istorie notele: 9, 10, 7, 10, 9. Media aritmetică a notelor ei la istorie este egală cu $ma = \frac{9 + 10 + 7 + 10 + 9}{5} = \frac{45}{5} = 9$.

Reține că, oricâte numere naturale ai avea, media aritmetică se calculează la fel: aduni numerele și împarți suma la câte numere sunt.
