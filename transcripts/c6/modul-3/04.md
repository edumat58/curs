C18.2 - Opusul, modulul și compararea numerelor raționale. În acest curs vom aborda numerele raționale privite pe axa numerelor. O să înveți ce este opusul unui număr rațional, ce este modulul său și cum se compară și se ordonează numerele raționale.

<span style={{color: '#e65100', fontWeight: 'bold'}}>Reprezentarea pe axa numerelor</span>. Oricărui număr rațional <x> îi corespunde un punct <A> pe axa numerelor. Notăm $A(x)$ și spunem că punctul <A> are abscisa <x>.

Pe axa numerelor fixăm originea și o unitate de măsură. Sensul pozitiv este de la origine la dreapta, iar sensul negativ este de la origine la stânga.

<span style={{color: '#e65100', fontWeight: 'bold'}}>Opusul unui număr rațional</span>. Două numere raționale se numesc opuse dacă punctele corespunzătoare acestor numere sunt simetrice față de origine, adică se află la aceeași distanță de origine și în sensuri diferite.

Să luăm câteva exemple. Opusul lui $+\dfrac{3}{4}$ este $-\dfrac{3}{4}$, iar opusul lui $-4,67$ este $+4,67$. La fel, opusul lui $-\dfrac{9}{2}$ este $+\dfrac{9}{2}$, iar opusul lui $+0,14(6)$ este $-0,14(6)$.

În general, opusul numărului <x> se notează $-x$, iar opusul numărului $-x$ este <x>. Adică $-(-x) = x$: opusul opusului unui număr este numărul însuși.

<span style={{color: '#e65100', fontWeight: 'bold'}}>Modulul unui număr rațional</span>. Dacă $a \in \mathbb{Q}$, modulul său este dat prin definiția: $|a| = \begin{cases} a, & \text{dacă } a > 0 \\ 0, & \text{dacă } a = 0 \\ -a, & \text{dacă } a < 0 \end{cases}$

Adică modulul unui număr pozitiv este el însuși, iar modulul unui număr negativ este opusul său.

Reține și înțelesul geometric: modulul unui număr rațional înseamnă distanța de la origine până la punctul corespunzător numărului. De aceea, modulul oricărui număr rațional este un număr pozitiv: pentru orice $a \in \mathbb{Q}$ avem $|a| \ge 0$.

Să vedem exemplele. $\left|+\dfrac{2}{9}\right| = \dfrac{2}{9}$ și $\left|-\dfrac{11}{15}\right| = \dfrac{11}{15}$. La fel, $|-4,15| = 4,15$ și $|+1,(19)| = 1,(19)$.

<span style={{color: '#e65100', fontWeight: 'bold'}}>Compararea și ordonarea numerelor raționale</span>. Spunem că numărul <a> este mai mic decât numărul <b> dacă punctul $A(a)$ se găsește pe axa numerelor la stânga față de punctul $B(b)$, și vom scrie $a < b$. Cu alte cuvinte, parcurgând axa numerelor de la stânga la dreapta, numerele raționale cresc.

<span style={{color: '#1565c0', textDecoration: 'underline'}}>Observații:</span> Prima observație: orice număr pozitiv este mai mare decât orice număr negativ. A doua: dintre două numere pozitive, mai mare este cel cu modulul mai mare. A treia: dintre două numere negative, mai mare este cel cu modulul mai mic. Și a patra: orice număr pozitiv este mai mare decât 0, iar orice număr negativ este mai mic decât 0.

Să vedem exemplele. $-\dfrac{1}{2} < \dfrac{1}{2}$, pentru că un număr negativ este mai mic decât unul pozitiv. Apoi $\dfrac{3}{4} > -\dfrac{15}{2}$, din același motiv. Avem $-0,46 < -0,01$, pentru că dintre două numere negative mai mare este cel cu modulul mai mic. Și $-3,(11) < -3,11$, pentru că modulul lui $-3,(11)$ este mai mare decât modulul lui $-3,11$.
