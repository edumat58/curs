C12.1 - Adunarea și scăderea numerelor întregi. În acest curs vom aborda adunarea și scăderea numerelor întregi. O să înveți cum aduni două numere întregi în funcție de semnele lor, ce proprietăți are adunarea, cum se face scăderea și cum se desfac parantezele.

1. Adunarea numerelor întregi. Începem cu o definiție: suma a două numere întregi este tot un număr întreg. Fie $a, b \in \mathbb{Z}$, adică <a> și <b> două numere întregi. Felul în care le adunăm depinde de semnele lor, așa că împărțim adunarea pe trei cazuri.

Cazul I — $a, b \ge 0$. Suma numerelor întregi nenegative <a> și <b> este suma numerelor naturale <a> și <b>: $S = a + b$. Cu alte cuvinte, când niciunul dintre numere nu este negativ, adunăm exact ca la numerele naturale.

Să vedem câteva exemple. $(+3) + (+7) = +10 = 10$. Apoi $8 + (+73) = +81 = 81$. Și încă unul: $+145 + (+529) = +674 = 674$.

Cazul II — $a, b \lt 0$. Suma numerelor întregi negative <a> și <b> este $S = -(|a| + |b|)$. Adică adunăm modulele celor două numere, iar rezultatului îi punem semnul minus.

Să vedem cum arată asta pe exemple. $(-6) + (-8) = -(|-6| + |-8|) = -(6 + 8) = -14$. Apoi $-37 + (-20) = -(37 + 20) = -57$. Și $-853 + (-247) = -(853 + 247) = -1100$.

Cazul III — $a \ge 0, \ b \lt 0$. Suma numerelor întregi de semne contrare este numărul <S> care se calculează așa: dacă $|a| \gt |b|$, atunci $S = +(|a| - |b|)$; dacă $|a| = |b|$, atunci $S = 0$; iar dacă $|a| \lt |b|$, atunci $S = -(|b| - |a|)$. Cu alte cuvinte, scădem modulul mai mic din modulul mai mare, iar suma primește semnul numărului cu modulul mai mare. Dacă modulele sunt egale, suma este zero.

Să luăm exemplele pe rând. $12 + (-5) = +(|12| - |-5|) = +7 = 7$. Apoi $-18 + (+6) = -(|-18| - |+6|) = -12$. Și $-142 + 396 = +(|396| - |-142|) = +254$.

Reprezentare vizuală (model cu pătrățele). Există și un mod de a vedea adunarea cu ochii. Putem reprezenta $+1$ printr-un pătrățel roșu și $-1$ printr-un pătrățel albastru. Deoarece $1 + (-1) = 0$, un pătrățel roșu anulează unul albastru. Așezăm pătrățelele unele lângă altele, perechile roșu-albastru dispar, iar ce rămâne este suma.

Să verificăm cu acest model câteva adunări. $+12 + (+4) = +16$. Apoi $(-7) + (-3) = -10$. Apoi $+7 + (-5) = +2$. Și $-8 + (+5) = -3$.

2. Proprietățile adunării numerelor întregi. Fie $a, b, c \in \mathbb{Z}$, adică trei numere întregi oarecare.

Prima proprietate este asociativitatea: $(a + b) + c = a + (b + c)$. Nu contează cum grupăm termenii, suma iese la fel. Exemplu: $(-17 + 3) + (-2) = -17 + [3 + (-2)] = -17$.

A doua proprietate este comutativitatea: $a + b = b + a$. Putem schimba ordinea termenilor fără ca suma să se schimbe. Exemplu: $-32 + 45 = 45 + (-32) = 13$.

A treia proprietate este elementul neutru: $a + 0 = 0 + a = a$. Zero adunat la orice număr întreg îl lasă neschimbat. Exemplu: $+35 + 0 = 0 + (+35) = 35$.

A patra proprietate este elementul opus: fiecare număr întreg <a> are un opus $-a$ astfel încât $a + (-a) = (-a) + a = 0$. Exemplu: $35 + (-35) = -35 + 35 = 0$.

Exerciții. Să punem proprietățile la lucru. Primul exercițiu ne cere să calculăm $-8 + 12 + (-7) + (+9) + (-11) + (-4) + 6$. Rezolvarea folosește comutativitatea și asociativitatea: grupăm termenii negativi împreună și termenii pozitivi împreună. Obținem $[-8 + (-7) + (-11) + (-4)] + [12 + 9 + 6] = -30 + 27 = -3$.

Al doilea exercițiu ne cere să calculăm $-17 + 35 + (-9) + (-35) + 17$. Aici observăm perechile de numere opuse și le așezăm una lângă alta: $-17 + 17 + 35 + (-35) + (-9) = 0 + 0 + (-9) = -9$. Reține că, atunci când aduni mai multe numere întregi, merită să cauți întâi perechile de opuse, pentru că ele se anulează.

3. Scăderea numerelor întregi. Definiția este simplă: diferența numerelor întregi <a> și <b> este egală cu suma dintre <a> și opusul lui <b>: $a - b = a + (-b)$. Așadar orice scădere se transformă într-o adunare, iar de adunat știm deja.

Să vedem exemplele. $-8 - 9 = -8 + (-9) = -17$. Apoi $16 - (-7) = 16 + (+7) = 23$. Și $-18 - 4 = -18 + (-4) = -22$.

4. Reguli de desfacere a parantezelor. Când o expresie are paranteze, le putem elimina după două reguli, în funcție de semnul din fața parantezei.

Regula 1. Dacă în fața parantezei se află semnul plus sau niciun semn, se elimină paranteza, iar termenii din interior se scriu cu aceleași semne. Să vedem exemplul: $(-34 + 28 - 17) + (+53 - 25 + 17) = -34 + 28 - 17 + 53 - 25 + 17 = +22$.

Regula 2. Dacă în fața parantezei se află semnul minus, se elimină paranteza, iar toți termenii din interior își schimbă semnul. Să vedem exemplul: $24 - (+28 - 31 + 12) = 24 - 28 + 31 - 12 = 15$. Reține deosebirea: plus în fața parantezei păstrează semnele, minus în fața parantezei le schimbă pe toate.
