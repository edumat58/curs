C12.2 - Înmulțirea și împărțirea numerelor întregi. În acest curs vom aborda înmulțirea și împărțirea numerelor întregi. O să înveți regula semnelor, proprietățile înmulțirii, ce sunt multiplii și divizorii unui număr întreg și cum se face împărțirea.

Începem cu definiția produsului. Produsul a două numere întregi nenule este numărul întreg care are modulul egal cu produsul modulelor factorilor, semnul plus dacă factorii au același semn și semnul minus dacă factorii au semne contrare. Dacă cel puțin unul dintre factori este nul, atunci produsul este 0.

Regula semnelor. Regula se ține minte ușor. $(+)\cdot(+)$ dă $(+)$. $(-)\cdot(-)$ dă tot $(+)$. $(+)\cdot(-)$ dă $(-)$. Iar $(-)\cdot(+)$ dă $(-)$. Reține că factorii cu același semn dau rezultat cu plus, iar factorii cu semne contrare dau rezultat cu minus.

Exemple. Să vedem regula la lucru, mai întâi pe aceleași numere, 4 și 3, cu toate combinațiile de semne. Exemplul 1: $(+4)\cdot(+3) = +12$. Exemplul 2: $(-4)\cdot(-3) = +12$. Exemplul 3: $(+4)\cdot(-3) = -12$. Exemplul 4: $(-4)\cdot(+3) = -12$. Observă că modulul este mereu 12, doar semnul se schimbă după regulă.

Mai exersăm câteva. Exemplul 5: $(+5)\cdot(+9) = +45$. Exemplul 6: $(-6)\cdot(+7) = -42$. Exemplul 7: $(-8)\cdot(-5) = +40$. Exemplul 8: $(+10)\cdot(-6) = -60$. Exemplul 9: $(+11)\cdot(-2) = -22$.

Urmează înmulțirile în care apare zero, unde produsul este zero. Exemplul 10: $(+4)\cdot 0 = 0$. Exemplul 11: $(-4)\cdot 0 = 0$. Exemplul 12: $0\cdot(+3) = 0$. Exemplul 13: $0\cdot(-3) = 0$.

Putem înmulți și mai mult de doi factori, lucrând de la stânga la dreapta. Exemplul 14: $(+4)\cdot(-2)\cdot(+6) = -48$. Exemplul 15: $(-5)\cdot(-8)\cdot(-2) = -80$. Exemplul 16: $(+6)\cdot(-4)\cdot(-3) = +72$. Exemplul 17: $(+4)\cdot(-10)\cdot 0 = 0$. Și exemplul 18, un produs de patru factori: $(-3)\cdot(+2)\cdot(-6)\cdot(-2) = -72$.

Proprietățile înmulțirii numerelor întregi. Înmulțirea numerelor întregi are aceleași proprietăți ca și înmulțirea numerelor naturale. Prima este asociativitatea: $(a\cdot b)\cdot c = a\cdot(b\cdot c)$, oricare ar fi numerele întregi <a>, <b> și <c>. A doua este comutativitatea: $a\cdot b = b\cdot a$, oricare ar fi numerele întregi <a> și <b>. A treia spune că 1 este element neutru: $a\cdot 1 = 1\cdot a = a$, oricare ar fi numărul întreg <a>. Iar a patra este distributivitatea față de adunare și scădere: $a\cdot(b+c) = a\cdot b + a\cdot c$ și $a\cdot(b-c) = a\cdot b - a\cdot c$.

Exemple de aplicare a proprietăților. Începem cu elementul neutru. Exemplul 1: $(+2)\cdot 1 = +2$. Exemplul 2: $1\cdot(-2) = -2$. Înmulțirea cu minus unu schimbă doar semnul. Exemplul 3: $(+2)\cdot(-1) = -2$. Exemplul 4: $(-2)\cdot(-1) = +2$. Comutativitatea ne lasă să schimbăm ordinea factorilor ca să calculăm mai ușor. Exemplul 5: $(-2)\cdot(-7)\cdot(-5) = (-2)\cdot(-5)\cdot(-7) = (+10)\cdot(-7) = -70$. La fel, grupăm factorii care dau numere rotunde. Exemplul 6: $(-3)\cdot(-4)\cdot(+25) = (-3)\cdot(-100) = +300$. Exemplul 7: $(+4)\cdot(-50)\cdot(+9) = (-200)\cdot(+9) = -1800$.

Calculați în două moduri: așa sună cerința pentru exercițiile care urmează, iar cele două moduri vin chiar din distributivitate. Primul exercițiu: $(-6)\cdot(+7) + (-6)\cdot(+9) = (-42) + (-54) = -96$, sau, dând factor comun, $(-6)\cdot[(+7) + (+9)] = (-6)\cdot(+16) = -96$. Al doilea exercițiu: $(-10)\cdot(+8) - (-10)\cdot(+6) = (-80) - (-60) = -80 + 60 = -20$, sau $(-10)\cdot[(+8) - (+6)] = (-10)\cdot(+2) = -20$. Al treilea exercițiu: $-4\cdot(-8 + 12) = -4\cdot(+4) = -16$, sau, desfăcând paranteza, $-4\cdot(-8) + (-4)\cdot 12 = +32 - 48 = -16$. Observă că ambele moduri duc de fiecare dată la același rezultat.

Multiplii unui număr întreg. Fie <a> și <b> două numere întregi. Spunem că <a> este multiplul lui <b>, sau că <a> se divide cu <b>, dacă există un număr întreg <c> astfel încât $a = b \cdot c$. Scriem $a : b$ sau $b \mid a$. Numărul <b> se numește divizor al lui <a>. Mulțimea multiplilor numărului întreg <n> se notează cu $M_n = \{k\cdot n \mid k \in \mathbb{Z}\}$. Se observă că $M_n = M_{-n}$, oricare ar fi numărul întreg <n>.

Exemple. Multiplii lui 5 formează mulțimea $M_5 = \{0, \pm5, \pm10, \pm15, \pm20, \dots, \pm5n, \dots\}$. Pentru numărul $-3$ avem $M_{-3} = \{0, \pm3, \pm6, \pm9, \pm12, \pm15, \dots, \pm3n, \dots\}$. Acum o alegere: dintre numerele $10, 44, 125, -108, 253, 120, -200, -302, 624$, multiplii lui 4 sunt $44$, $-108$, $120$, $-200$ și $624$. Și încă un exercițiu: să înșirăm 11 multipli întregi ai numărului $-2$, dintre care 5 să fie negativi. Aceștia pot fi $-10, -8, -6, -4, -2, 0, 2, 4, 6, 8, 10$.

Împărțirea numerelor întregi. Fie $a, b \in \mathbb{Z}$, adică <a> și <b> numere întregi, cu $b \neq 0$ și <a> un multiplu al lui <b>. Câtul dintre <a> și <b>, notat $a : b$, este acel număr întreg <c> pentru care $a = b \cdot c$. Numărul <a> se numește deîmpărțit, iar <b> se numește împărțitor.

Observații. Regula semnelor este aceeași ca la înmulțire. Valoarea absolută a câtului este egală cu câtul valorilor absolute. Dacă deîmpărțitul este nul, atunci câtul este 0. Iar dacă împărțitorul este nul, împărțirea nu are sens.

Exemple. Mai întâi, toate combinațiile de semne pe aceleași numere. Exemplul 1: $(+20) : (+10) = +2$. Exemplul 2: $(-20) : (-10) = +2$. Exemplul 3: $(+20) : (-10) = -2$. Exemplul 4: $(-20) : (+10) = -2$. Când deîmpărțitul este zero, câtul este zero. Exemplul 5: $0 : (+5) = 0$. Exemplul 6: $0 : (-6) = 0$. Când împărțitorul este zero, împărțirea nu are sens. Exemplul 7: $(+8) : 0$ nu are sens. Exemplul 8: $(-7) : 0$ nu are sens. Exemplul 9: $0 : 0$ nu are sens.

Continuăm cu împărțirea la unu și la minus unu. Exemplul 10: $(-12) : (+1) = -12$. Exemplul 11: $(-12) : (-1) = +12$. Exemplul 12: $(-35) : (-7) = +5$. Împărțirile în lanț se fac de la stânga la dreapta. Exemplul 13: $(+144) : (-12) : (+6) = (-12) : (+6) = -2$. Exemplul 14: $(-18) : (-3) : (+6) = (+6) : (+6) = +1$. Exemplul 15: $(-100) : (+25) : (-1) = (-4) : (-1) = +4$. Exemplul 16: $(+13) : (-13) : (+1) = (-1) : (+1) = -1$. Și încă două împărțiri cu numere mai mari. Exemplul 17: $(+1024) : (-32) = -32$. Exemplul 18: $(-760) : (-10) = +76$.

Divizorii unui număr întreg. Dacă <a> este un multiplu al lui <b>, atunci <b> este un divizor al numărului <a>. Mulțimea divizorilor unui număr întreg <n> se notează cu $D_n$ și avem $D_n = D_{-n}$, oricare ar fi numărul întreg <n>.

Exemple. Divizorii lui 6 formează mulțimea $D_6 = \{\pm1, \pm2, \pm3, \pm6\}$. Pentru numărul $-15$ avem $D_{-15} = \{\pm1, \pm3, \pm5, \pm15\}$. Să găsim acum divizorii câtorva numere. Pentru $18$, divizorii naturali sunt $\{1, 2, 3, 6, 9, 18\}$, iar divizorii întregi sunt $\{\pm1, \pm2, \pm3, \pm6, \pm9, \pm18\}$. Pentru $-37$, divizorii naturali sunt $\{1, 37\}$, iar divizorii întregi sunt $\{\pm1, \pm37\}$. Iar la final, o alegere: dintre numerele $-9, +6, -12, 14, 21, -16, +24, -36, 32$, divizorii lui $144$ sunt $-9$, $+6$, $-12$, $-16$, $+24$ și $-36$. Reține că divizorii unui număr întreg vin în perechi: fiecare divizor natural, împreună cu opusul lui.
