G5 - Linia mijlocie în triunghi. În acest curs vom aborda linia mijlocie a unui triunghi. O să înveți ce este ea, ce proprietate remarcabilă are și cum te ajută să rezolvi probleme fără măsurători în plus.

Definiție. Segmentul care unește mijloacele a două laturi ale unui triunghi se numește linie mijlocie a triunghiului. Dacă <M>, <N>, <P> sunt mijloacele laturilor triunghiului $ABC$, atunci segmentele $MN$, $NP$ și $MP$ sunt liniile mijlocii ale triunghiului.

Proprietate. Linia mijlocie determinată de mijloacele a două laturi ale unui triunghi este paralelă cu a treia latură și are lungimea egală cu jumătate din lungimea acesteia.

Astfel, pentru triunghiul $ABC$ avem $MN \parallel BC$, $NP \parallel AB$ și $MP \parallel AC$. În plus, $MN = \frac{BC}{2}$, $NP = \frac{AB}{2}$ și $MP = \frac{AC}{2}$. Sau, echivalent, $BC = 2\cdot MN$, $AB = 2\cdot NP$ și $AC = 2\cdot MP$. Reține că fiecare linie mijlocie este paralelă cu latura pe care nu o atinge și măsoară jumătate din ea.

Aplicații. Să vedem acum cum folosim această proprietate în două probleme.

Exemplul 1. Fie triunghiul $ABC$ în care $MN$, $NP$, $MP$ sunt liniile mijlocii. Știind că $BC = 8\text{ cm}$, $AC = 7\text{ cm}$ și $NP = 3\text{ cm}$, să se calculeze perimetrul triunghiului $MNP$.

Rezolvare: Aplicăm proprietatea liniei mijlocii pentru fiecare latură. Mai întâi, $MN = \frac{BC}{2} = \frac{8}{2} = 4\text{ cm}$. Apoi $MP = \frac{AC}{2} = \frac{7}{2} = 3{,}5\text{ cm}$. Iar $NP = 3\text{ cm}$, direct din enunț.

Perimetrul triunghiului $MNP$ este $P_{MNP} = MN + NP + MP = 4 + 3 + 3{,}5 = 10{,}5\text{ cm}$.

De reținut că perimetrul triunghiului format de liniile mijlocii este jumătate din perimetrul triunghiului inițial, adică $P_{MNP} = \frac{P_{ABC}}{2}$.

Exemplul 2. Fie paralelogramul $ABCD$, în care <S>, <T>, <U>, <V> sunt mijloacele laturilor. Se cere să se arate că patrulaterul $STUV$ este paralelogram.

Rezolvare: În triunghiul $ABD$, punctele <V> și <S> sunt mijloacele laturilor $AD$ și $AB$, deci $SV$ este linie mijlocie. De aici, $VS \parallel BD$ și $VS = \frac{BD}{2}$.

În triunghiul $CBD$, punctele <U> și <T> sunt mijloacele laturilor $CD$ și $CB$, deci $UT$ este linie mijlocie. De aici, $UT \parallel BD$ și $UT = \frac{BD}{2}$.

Rezultă două lucruri. Din $VS \parallel BD$ și $UT \parallel BD$ obținem $VS \parallel UT$. Din $VS = \frac{BD}{2}$ și $UT = \frac{BD}{2}$ obținem $VS = UT$. Prin urmare, $STUV$ este paralelogram.
