C11 - Relația de egalitate. În acest curs vom aborda relația de egalitate și transformările care o păstrează. O să înveți cum obții egalități echivalente dintr-o egalitate dată și cum combini două egalități ca să ajungi la egalități noi.

Proprietăți ale relației de egalitate. Regula fundamentală este următoarea: pornind de la o egalitate, se pot obține egalități echivalente prin patru transformări.

Prima transformare: se adună sau se scade, din ambii membri ai egalității, același număr real.

A doua transformare: se înmulțesc sau se împart ambii membri ai egalității cu același număr real nenul.

A treia transformare: se ridică la puterea $n \in \mathbb{Z}^*$ ambii membri ai egalității, dacă ambii membri sunt numere pozitive.

A patra transformare: se extrage radicalul din ambii membri ai egalității, dacă ambii membri sunt numere pozitive.

Observă că primele două transformări cer doar ca numărul cu care înmulțim sau împărțim să fie nenul, în timp ce ultimele două cer ca ambii membri să fie numere pozitive.

Scriere matematică. Să scriem aceleași proprietăți în limbaj matematic. Fie $a, b, c \in \mathbb{R}$, cu $c \ne 0$.

Prima proprietate, cu adunarea și scăderea: $a = b \iff a + c = b + c$, pentru orice $c \in \mathbb{R}$, și la fel $a = b \iff a - c = b - c$, pentru orice $c \in \mathbb{R}$.

A doua proprietate, cu înmulțirea și împărțirea: $a = b \iff a \cdot c = b \cdot c$, pentru orice $c \in \mathbb{R}^*$, și la fel $a = b \iff a : c = b : c$, pentru orice $c \in \mathbb{R}^*$.

A treia proprietate, cu ridicarea la putere: dacă $a > 0$ și $b > 0$, atunci $a = b \iff a^n = b^n$, unde $n \in \mathbb{Z}^*$.

A patra proprietate, cu radicalul: dacă $a \ge 0$ și $b \ge 0$, atunci $a = b \iff \sqrt{a} = \sqrt{b}$.

Exemple. Să vedem aceste transformări pe egalități concrete.

Primul exemplu, cu adunarea: $x = y \iff x + 3 = y + 3$. Am adunat 3 în ambii membri.

Al doilea, cu scăderea: $z = t \iff z - 11 = t - 11$. Am scăzut 11 din ambii membri.

Al treilea, cu înmulțirea: $c = d \iff c \cdot 7 = d \cdot 7$. Am înmulțit ambii membri cu 7.

Și al patrulea, cu împărțirea: $a = b \iff \dfrac{a}{-2} = \dfrac{b}{-2}$. Am împărțit ambii membri la $-2$, care este un număr nenul.

Obținerea de noi egalități din egalități date. Până acum am pornit de la o singură egalitate. Regula de transformare este acum alta: fiind date două egalități, se pot obține noi egalități utile prin cinci operații.

Prima operație: se adună, membru cu membru, cele două egalități. A doua: se scad, membru cu membru, cele două egalități. A treia: se înmulțesc, membru cu membru, cele două egalități. A patra: se împart, membru cu membru, cele două egalități. Și a cincea: se ridică la putere, membru cu membru, cele două egalități.

Exemple. Să aplicăm aceste operații în patru probleme rezolvate.

Exemplul 1. Problema: dacă $a + b = 11$ și $c + d = 9$, determinați $a + b + c + d$. Trecem la rezolvare. Avem cele două egalități: $a + b = 11$ și $c + d = 9$. Adunăm relațiile membru cu membru și obținem $a + b + c + d = 11 + 9 = 20$. Răspunsul este $a + b + c + d = 20$.

Exemplul 2. Problema: dacă $x = 4$ și $b + c = 13$, determinați $b + c - x$. Trecem la rezolvare. Scriem cele două egalități: $b + c = 13$ și $x = 4$. Scădem relațiile membru cu membru: $b + c - x = 13 - 4 = 9$. Răspunsul este $b + c - x = 9$.

Exemplul 3. Problema: dacă $x = 4$ și $b + c = 13$, determinați $2b + 2c - 3x$. Trecem la rezolvare. De data aceasta pregătim mai întâi egalitățile. Din $b + c = 13$, înmulțim relația cu 2 și obținem $2b + 2c = 26$. Din $x = 4$, înmulțim relația cu 3 și obținem $3x = 12$. Acum scădem relațiile membru cu membru: $2b + 2c - 3x = 26 - 12 = 14$. Răspunsul este $2b + 2c - 3x = 14$.

Exemplul 4. Problema: dacă $5a - 5b = 15$ și $2a + c = 7$, determinați $3a - b + c$. Trecem la rezolvare. Din prima relație, $5a - 5b = 15$, împărțim ambii membri la 5 și obținem $a - b = 3$. Avem acum egalitățile $a - b = 3$ și $2a + c = 7$. Adunăm relațiile membru cu membru și obținem $3a - b + c = 10$. Răspunsul este $3a - b + c = 10$. Reține ideea acestor probleme: mai întâi aduci egalitățile la forma potrivită, apoi le combini membru cu membru.
