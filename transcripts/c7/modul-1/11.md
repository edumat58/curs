C8.2 – Media geometrică. În această lecție vom aborda media geometrică a două numere reale pozitive. O să înveți ce este, cum se calculează și cum se compară cu media aritmetică.

Introducere. Media geometrică, numită și media proporțională, a două numere reale pozitive este o măsură care reprezintă valoarea centrală a celor două numere. Ea se calculează ca rădăcina pătrată a produsului lor. Media geometrică este folosită în situații în care valorile se multiplică, cum ar fi ratele de creștere sau proporțiile.

Formula mediei geometrice. Pentru două numere reale pozitive <a> și <b>, media geometrică se calculează astfel: $M_g = \sqrt{a \cdot b}$. Cu alte cuvinte, înmulțim cele două numere între ele, apoi extragem rădăcina pătrată din produsul obținut.

Exemple. Să calculăm media geometrică a numerelor 4 și 9. Mai întâi facem produsul: $4 \cdot 9 = 36$. Apoi extragem rădăcina pătrată și obținem media geometrică: $\sqrt{36} = 6$.

Al doilea exemplu. Să calculăm media geometrică a numerelor 2 și 8. Produsul este $2 \cdot 8 = 16$, iar media geometrică este $\sqrt{16} = 4$.

Al treilea exemplu. Să calculăm media geometrică a numerelor $\dfrac{1}{2}$ și 2. Produsul este $\dfrac{1}{2} \cdot 2 = 1$, iar media geometrică este $\sqrt{1} = 1$.

Al patrulea exemplu. Să calculăm media geometrică a numerelor 5 și 20. Produsul este $5 \cdot 20 = 100$, iar media geometrică este $\sqrt{100} = 10$. Observă că de fiecare dată drumul este același: produsul celor două numere, apoi rădăcina pătrată.

Proprietăți ale mediei geometrice. Prima proprietate: media geometrică a două numere pozitive este întotdeauna mai mică sau egală cu media aritmetică a acelorași numere. A doua proprietate: dacă cele două numere sunt egale, media geometrică este egală cu ele. A treia proprietate: media geometrică este pozitivă pentru numere pozitive.

Exemplu de aplicare. Să comparăm media aritmetică și media geometrică pentru numerele 1 și 4. Media aritmetică este $\dfrac{1+4}{2} = 2,5$. Media geometrică este $\sqrt{1 \cdot 4} = \sqrt{4} = 2$. Reține că media geometrică, 2, a ieșit mai mică decât media aritmetică, 2,5.
