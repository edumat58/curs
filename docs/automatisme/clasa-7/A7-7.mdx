# A7.7 — Translația unui punct

Completează răspunsul în casetă și apasă **Verifică** — te corectezi pe loc. 

<Automatism id="pointTranslation" title="A7.7 · Translația unui punct" subtitle="Clasa a VII-a · Automatism" />

:::tip Cum lucrezi

:::
