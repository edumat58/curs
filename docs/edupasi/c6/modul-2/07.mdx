# G3 - Unghiul. Clasificare și măsurarea unghiurilor

---

## Definiție

:::danger Definiție
Unghiul are două **<HighlightText color="red">laturi</HighlightText>** și un **<HighlightText color="teal">vârf</HighlightText>**.

Laturile pornesc din vârf.
:::

## Clasificarea unghiurilor

<Katex>
{String.raw`
\begin{aligned}
& \text{Unghi } \color{#FF6B6B}{\text{nul}} = 0^\circ\\[6pt]
& \text{Unghi } \color{#4ECDC4}{\text{drept}} = 90^\circ\\[6pt]
& \text{Unghi } \color{#9370DB}{\text{obtuz}}: \text{ mai mare decât } 90^\circ\\[6pt]
& \text{Unghi } \color{#FF8C00}{\text{alungit}} = 180^\circ
\end{aligned}
`}
</Katex>

## Măsurarea unghiurilor

:::tip De reținut
<Katex>
{String.raw`
\begin{aligned}
& \color{#FF6B6B}{\text{Congruente}}: \text{ au măsuri egale}\\[8pt]
& \color{#4ECDC4}{\text{Complementare}}: \text{ suma } = 90^\circ\\[8pt]
& \color{#9370DB}{\text{Suplementare}}: \text{ suma } = 180^\circ
\end{aligned}
`}
</Katex>
:::

**Exemplul 1.** Un unghi are 30°. Aflăm complementul.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: suma este } \color{#4ECDC4}{90^\circ}\\[6pt]
& \text{Pasul 2: scădem } 90 - 30 = \color{#FF6B6B}{60}\\[6pt]
& \text{Complementul are } \color{#FF6B6B}{60^\circ}
\end{aligned}
`}
</Katex>

**Exemplul 2.** Un unghi are 50°. Aflăm suplementul.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: suma este } \color{#9370DB}{180^\circ}\\[6pt]
& \text{Pasul 2: scădem } 180 - 50 = \color{#FF6B6B}{130}\\[6pt]
& \text{Suplementul are } \color{#FF6B6B}{130^\circ}
\end{aligned}
`}
</Katex>
