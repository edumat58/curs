# C11 - Compararea și ordonarea numerelor întregi

---

## Compararea numerelor întregi

:::danger Definiție
Fiecare număr întreg are un punct pe **<HighlightText color="red">axa numerelor</HighlightText>**.
:::

:::tip De reținut
<Katex>
{String.raw`
\begin{aligned}
& \text{Pe axă, numărul din } \color{#4ECDC4}{\text{dreapta}} \text{ este mai mare.}\\[8pt]
& \color{#FF8C00}{\text{Orice pozitiv}} \text{ este mai mare decât } \color{#FF6B6B}{\text{orice negativ.}}
\end{aligned}
`}
</Katex>
:::

**Exemplul 1**

<Katex>
{String.raw`
\begin{aligned}
& \text{Comparăm } \color{#FF6B6B}{-3} \text{ și } \color{#4ECDC4}{1}.\\[6pt]
& \text{Pasul 1: } \color{#FF6B6B}{-3} \text{ este în stânga.}\\[6pt]
& \text{Pasul 2: } \color{#4ECDC4}{1} \text{ este în dreapta.}\\[6pt]
& \text{Pasul 3: } -3 < 1
\end{aligned}
`}
</Katex>

**Exemplul 2**

<Katex>
{String.raw`
\begin{aligned}
& \text{Comparăm } \color{#FF6B6B}{-7} \text{ și } \color{#9370DB}{-2}.\\[6pt]
& \text{Pasul 1: } \color{#FF6B6B}{-7} \text{ este în stânga.}\\[6pt]
& \text{Pasul 2: } \color{#9370DB}{-2} \text{ este în dreapta.}\\[6pt]
& \text{Pasul 3: } -7 < -2
\end{aligned}
`}
</Katex>

## Aplicații

Ordonăm crescător numerele:

<Katex>
{String.raw`
\begin{aligned}
& -4,\ 2,\ 0,\ -1,\ 3\\[8pt]
& \text{Pasul 1: scriem } \color{#FF6B6B}{\text{negativele}}: -4,\ -1\\[6pt]
& \text{Pasul 2: scriem } \color{#9370DB}{\text{zeroul}}: 0\\[6pt]
& \text{Pasul 3: scriem } \color{#4ECDC4}{\text{pozitivele}}: 2,\ 3\\[8pt]
& \text{Rezultat: } -4 < -1 < 0 < 2 < 3
\end{aligned}
`}
</Katex>
