# C1 - Multiplii si divizori

---

## Vocabular

:::danger Definiție
Împărțim pe `a` la `b`. Restul este `0`.

Atunci `b` este <HighlightText color="red">divizor</HighlightText> al lui `a`.

Atunci `a` este <HighlightText color="teal">multiplu</HighlightText> al lui `b`.
:::

Observăm numărul 12 împărțit în 4 părți egale.

## Criterii de divizibilitate

:::tip De reținut
Un număr se împarte exact:

- **cu 2** dacă ultima cifră este 0, 2, 4, 6 sau 8;
- **cu 5** dacă ultima cifră este 0 sau 5;
- **cu 10** dacă ultima cifră este 0;
- **cu 3** dacă suma cifrelor se împarte la 3;
- **cu 9** dacă suma cifrelor se împarte la 9.
:::

Calculăm pas cu pas pentru numărul 45.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: ultima cifră este } \color{#FF6B6B}{5} \Rightarrow \text{se împarte la } 5\\[6pt]
& \text{Pasul 2: } 4 + 5 = \color{#4ECDC4}{9} \Rightarrow \text{se împarte la } 3 \text{ și la } 9
\end{aligned}
`}
</Katex>

Reținem: 45 este multiplu de 5, de 3 și de 9.
