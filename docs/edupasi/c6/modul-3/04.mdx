## Opusul unui număr rațional

:::danger Definiție
Două numere sunt **<HighlightText color="red">opuse</HighlightText>** dacă au același număr și semne diferite.
:::

<Katex>
{String.raw`
\text{Opusul lui } \color{#4ECDC4}{x} \text{ este } \color{#FF6B6B}{-x}
`}
</Katex>

**Exemplul 1.**

<Katex>
{String.raw`
\text{Aflăm opusul lui } +\dfrac{3}{4}
`}
</Katex>

Pasul 1: Păstrăm numărul.

<Katex>
{String.raw`
\dfrac{3}{4}
`}
</Katex>

Pasul 2: Schimbăm semnul.

<Katex>
{String.raw`
+\dfrac{3}{4} \quad \Rightarrow \quad \color{#FF6B6B}{-\dfrac{3}{4}}
`}
</Katex>

**Exemplul 2.**

<Katex>
{String.raw`
\text{Opusul lui } \color{#FF6B6B}{-2{,}5} \text{ este } \color{#4ECDC4}{+2{,}5}
`}
</Katex>

## Modulul unui număr rațional

:::tip De reținut
Modulul este distanța de la 0 până la număr. Scriem numărul fără semn.
:::

<Katex>
{String.raw`
\begin{aligned}
& \left|\color{#4ECDC4}{+\dfrac{2}{9}}\right| = \dfrac{2}{9}\\[8pt]
& \left|\color{#FF6B6B}{-\dfrac{2}{9}}\right| = \dfrac{2}{9}
\end{aligned}
`}
</Katex>

**Exemplul 3.**

<Katex>
{String.raw`
|-4{,}5| = \color{#FF8C00}{4{,}5} \qquad |+1{,}3| = \color{#FF8C00}{1{,}3}
`}
</Katex>

Observăm că modulul nu este niciodată negativ.

## Compararea numerelor raționale

Pe axă numerele cresc de la stânga la dreapta. Numărul din dreapta este mai mare.

<Katex>
{String.raw`
\begin{aligned}
& \text{1. Orice număr pozitiv este mai mare decât orice număr negativ}\\[8pt]
& \text{2. Dintre două numere negative, mai mare este cel cu modulul mai mic}
\end{aligned}
`}
</Katex>

**Exemplul 4.**

<Katex>
{String.raw`
\text{Comparăm } -0{,}7 \text{ cu } -0{,}2
`}
</Katex>

Pasul 1: Calculăm modulele.

<Katex>
{String.raw`
|-0{,}7| = 0{,}7 \qquad |-0{,}2| = 0{,}2
`}
</Katex>

Pasul 2: Modulul mai mic dă numărul mai mare.

<Katex>
{String.raw`
\color{#4ECDC4}{-0{,}2} > \color{#FF6B6B}{-0{,}7}
`}
</Katex>

**Exemplul 5.**

<Katex>
{String.raw`
\color{#4ECDC4}{\dfrac{1}{2}} > \color{#FF6B6B}{-\dfrac{9}{2}}
`}
</Katex>
