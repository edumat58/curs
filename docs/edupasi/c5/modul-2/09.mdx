# C17 - Criterii de divizibilitate

---

## 1. Criteriul de divizibilitate cu 2 și 5

:::danger Definiție
Un număr este divizibil cu **<HighlightText color="red">2</HighlightText>** dacă ultima cifră este 0, 2, 4, 6 sau 8.

Un număr este divizibil cu **<HighlightText color="teal">5</HighlightText>** dacă ultima cifră este 0 sau 5.
:::

## 2. Criteriul de divizibilitate cu 3

Un număr este divizibil cu **3** dacă suma cifrelor este divizibilă cu 3.

**Exemplu:** numărul 24.

**Pasul 1.** Adunăm cifrele.

<Katex>
{String.raw`
2 + 4 = \color{#FF8C00}{6}
`}
</Katex>

**Pasul 2.** Împărțim suma la 3.

<Katex>
{String.raw`
\color{#FF8C00}{6} : 3 = 2 \text{ rest } 0
`}
</Katex>

Deci 24 este divizibil cu 3.

---

## 3. Criteriul de divizibilitate cu 9

Un număr este divizibil cu **9** dacă suma cifrelor este divizibilă cu 9.

**Exemplu:** numărul 63.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } 6 + 3 = \color{#9370DB}{9}\\[6pt]
& \text{Pasul 2: } \color{#9370DB}{9} : 9 = 1 \text{ rest } 0\\[6pt]
& \text{Deci } 63 \text{ este divizibil cu } 9
\end{aligned}
`}
</Katex>

---

## 4. Criteriul de divizibilitate cu 10

Un număr este divizibil cu **10** dacă ultima cifră este 0.

<Katex>
{String.raw`
7\color{#4ECDC4}{0} \to \text{ultima cifră } \color{#4ECDC4}{0} \to \text{divizibil cu } 10
`}
</Katex>

:::tip De reținut

& \color{#FF8C00}{3}, \ \color{#9370DB}{9}: \text{ adunăm } \color{#FF8C00}{\text{toate cifrele}}
\end{aligned}
`}
</Katex>
:::
