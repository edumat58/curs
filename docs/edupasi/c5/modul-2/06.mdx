## Semiplanul

:::danger Definiție
O dreaptă împarte planul în două părți.
Fiecare parte se numește **<HighlightText color="red">semiplan</HighlightText>**.
Dreapta se numește **<HighlightText color="teal">frontieră</HighlightText>**.
:::

<Katex>
{String.raw`
\begin{aligned}
& \color{#4ECDC4}{(d,\ A)} \text{ este semiplanul cu punctul } A\\[6pt]
& \color{#FF6B6B}{(d,\ B)} \text{ este semiplanul cu punctul } B
\end{aligned}
`}
</Katex>

---

## Semidreapta

Punctul **O** se află pe dreapta **d**.
Partea care pleacă din **O** este o **semidreaptă**.
Punctul **O** este **originea**.

<Katex>
{String.raw`
\begin{aligned}
& \color{#FF6B6B}{(OE)} \text{ nu conține punctul } O\\[6pt]
& \color{#4ECDC4}{[OE)} \text{ conține punctul } O
\end{aligned}
`}
</Katex>

---

## Segmentul de dreaptă

Punctele **A** și **B** se află pe dreapta **d**.
Partea dintre **A** și **B** este un **segment**.
Punctele **A** și **B** sunt **extremitățile**.

<Katex>
{String.raw`
\begin{aligned}
& \color{#FF6B6B}{(AB)} \text{ nu conține punctele } A \text{ și } B\\[6pt]
& \color{#4ECDC4}{[AB]} \text{ conține punctele } A \text{ și } B
\end{aligned}
`}
</Katex>

:::tip De reținut
<Katex>
{String.raw`
\begin{aligned}
& \color{#FF6B6B}{(} \text{ rotundă: punctul NU intră}\\[6pt]
& \color{#4ECDC4}{\lbrack} \text{ pătrată: punctul intră}
\end{aligned}
`}
</Katex>
:::
