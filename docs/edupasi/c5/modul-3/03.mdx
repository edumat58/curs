# C19.3 - Compararea fracțiilor cu același numitor sau numărător

---

## Proprietăți ale fracțiilor

:::danger Definiție 1
Dintre două fracții cu **<HighlightText color="teal">același numitor</HighlightText>**, mai mare este fracția care are **<HighlightText color="red">numărătorul mai mare</HighlightText>**.
:::

Cum comparăm:

1. Verificăm numitorii. Trebuie să fie egali.
2. Comparăm numărătorii.
3. Fracția cu numărătorul mai mare este fracția mai mare.

**Exemplu:** comparăm fracțiile de mai jos.

<Katex>
{String.raw`
\begin{aligned}
& \text{1. Numitorii sunt egali: } \color{#4ECDC4}{7} = \color{#4ECDC4}{7}\\[6pt]
& \text{2. Comparăm numărătorii: } \color{#FF6B6B}{5} > \color{#FF6B6B}{3}\\[6pt]
& \text{3. Scriem: } \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{7}} > \frac{\color{#FF6B6B}{3}}{\color{#4ECDC4}{7}}
\end{aligned}
`}
</Katex>

Observăm că ambele bare au 7 părți egale. Prima bară are 5 părți colorate. A doua are numai 3.

:::danger Definiție 2
Dintre două fracții cu **<HighlightText color="red">același numărător</HighlightText>**, mai mare este fracția care are **<HighlightText color="teal">numitorul mai mic</HighlightText>**.
:::

Numitorul mai mic înseamnă că întregul este împărțit în mai puține părți. Deci fiecare parte este **<HighlightText color="orange">mai mare</HighlightText>**.

Cum comparăm:

1. Verificăm numărătorii. Trebuie să fie egali.
2. Comparăm numitorii.
3. Fracția cu numitorul mai mic este fracția mai mare.

**Exemplu:** comparăm fracțiile de mai jos.

<Katex>
{String.raw`
\begin{aligned}
& \text{1. Numărătorii sunt egali: } \color{#FF6B6B}{2} = \color{#FF6B6B}{2}\\[6pt]
& \text{2. Comparăm numitorii: } \color{#4ECDC4}{5} < \color{#4ECDC4}{7}\\[6pt]
& \text{3. Scriem: } \frac{\color{#FF6B6B}{2}}{\color{#4ECDC4}{5}} > \frac{\color{#FF6B6B}{2}}{\color{#4ECDC4}{7}}
\end{aligned}
`}
</Katex>

:::tip De reținut
- Orice **<HighlightText color="red">fracție subunitară</HighlightText>** este cuprinsă între 0 și 1.
- Fracțiile se reprezintă pe **<HighlightText color="teal">axa numerelor</HighlightText>**, la fel ca numerele naturale.
:::

<Katex>
{String.raw`
0 < \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{9}} < 1
`}
</Katex>

---

## Observație

:::warning Atenție
Dintre două fracții reprezentate pe axa numerelor, mai mare este fracția din **<HighlightText color="orange">dreapta</HighlightText>**.
:::

**Exemplu:** pe axă, fracția de mai jos din stânga este mai mică.

<Katex>
{String.raw`
\frac{1}{4} \text{ este în stânga lui } \frac{3}{4}, \text{ deci } \frac{1}{4} < \frac{3}{4}
`}
</Katex>

## <span style={{backgroundColor: '#FF8C00', color: 'white', padding: '4px 8px', borderRadius: '4px'}}>Exersează!</span>

:::note Exercițiul 1
Completează casetele cu unul din semnele &lt;, &gt;, =.
:::

<Katex>
{String.raw`
\begin{aligned}
& \text{a) } \frac{2}{7} \ \square \ \frac{3}{7} \qquad \text{b) } \frac{5}{11} \ \square \ \frac{4}{11}\\[8pt]
& \text{c) } \frac{1}{4} \ \square \ \frac{1}{5} \qquad \text{d) } \frac{3}{3} \ \square \ \frac{7}{7}
\end{aligned}
`}
</Katex>

:::note Exercițiul 2
Scrie fracțiile în ordine crescătoare.
:::

<Katex>
{String.raw`
\begin{aligned}
& \text{a) } \frac{3}{5}, \ \frac{2}{5}, \ \frac{4}{5}, \ \frac{7}{5}\\[8pt]
& \text{b) } \frac{3}{2}, \ \frac{3}{7}, \ \frac{3}{5}, \ \frac{3}{10}
\end{aligned}
`}
</Katex>

:::note Exercițiul 3
Determină numerele naturale nenule n pentru care inegalitățile sunt adevărate.
:::

<Katex>
{String.raw`
\begin{aligned}
& \text{a) } \frac{n}{6} < \frac{4}{6}\\[8pt]
& \text{b) } \frac{3}{14} < \frac{n}{14} < \frac{7}{14}
\end{aligned}
`}
</Katex>
