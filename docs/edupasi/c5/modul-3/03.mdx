# C19.3 - Compararea fracțiilor cu același numitor sau numărător

---

## Proprietăți ale fracțiilor

:::danger Definiție
- Același **<HighlightText color="teal">numitor</HighlightText>**: mai mare este fracția cu numărătorul mai mare.
- Același **<HighlightText color="red">numărător</HighlightText>**: mai mare este fracția cu numitorul mai mic.
:::

**Exemplul 1.** Comparăm fracții cu același numitor.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1. Numitorii sunt egali: } \color{#4ECDC4}{7} = \color{#4ECDC4}{7}\\[6pt]
& \text{Pasul 2. Comparăm numărătorii: } \color{#FF6B6B}{5} > \color{#FF6B6B}{3}\\[6pt]
& \text{Pasul 3. Scriem: } \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{7}} > \frac{\color{#FF6B6B}{3}}{\color{#4ECDC4}{7}}
\end{aligned}
`}
</Katex>

---

## Observație

:::tip De reținut
Pe axa numerelor, mai mare este fracția din **<HighlightText color="orange">dreapta</HighlightText>**.
:::

<Katex>
{String.raw`
\frac{1}{4} < \frac{3}{4}
`}
</Katex>

---

## Exersează!

**Exercițiul 1.** Scrie în casetă semnul potrivit.

<Katex>
{String.raw`
\begin{aligned}
& \text{a) } \frac{2}{7} \ \square \ \frac{3}{7} \qquad \text{b) } \frac{5}{9} \ \square \ \frac{4}{9}\\[8pt]
& \text{c) } \frac{1}{4} \ \square \ \frac{1}{5} \qquad \text{d) } \frac{3}{5} \ \square \ \frac{3}{8}
\end{aligned}
`}
</Katex>

**Exercițiul 2.** Scrie fracțiile în ordine crescătoare.

<Katex>
{String.raw`
\begin{aligned}
& \text{a) } \frac{3}{5}, \ \frac{2}{5}, \ \frac{4}{5}\\[8pt]
& \text{b) } \frac{3}{2}, \ \frac{3}{7}, \ \frac{3}{5}
\end{aligned}
`}
</Katex>
