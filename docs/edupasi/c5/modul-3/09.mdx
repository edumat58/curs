# C21.2 - Aducerea fracțiilor la un numitor comun

---

## Definiție

:::danger Definiție
**<HighlightText color="teal">Numitorul comun</HighlightText>** este un număr care se împarte exact la ambii numitori.
:::

Numitorul comun este 6. Amplificăm fiecare fracție.

<Katex>
{String.raw`
{}^{3)}\color{#4ECDC4}{\dfrac{1}{2}} = \dfrac{3}{6} \qquad {}^{2)}\color{#FF6B6B}{\dfrac{1}{3}} = \dfrac{2}{6}
`}
</Katex>

---

## Compararea fracțiilor

Comparăm fracțiile:

<Katex>
{String.raw`\dfrac{1}{4} \qquad \dfrac{2}{5}`}
</Katex>

Calculăm pas cu pas:

**Pasul 1.** Alegem numitorul comun. Înmulțim numitorii.

<Katex>
{String.raw`4 \times 5 = \color{#9370DB}{20}`}
</Katex>

**Pasul 2.** Amplificăm fiecare fracție.

<Katex>
{String.raw`{}^{5)}\dfrac{1}{4} = \dfrac{5}{20} \qquad {}^{4)}\dfrac{2}{5} = \dfrac{8}{20}`}
</Katex>

**Pasul 3.** Comparăm numărătorii.

<Katex>
{String.raw`5 < 8 \quad \Rightarrow \quad \color{#FF8C00}{\dfrac{1}{4} < \dfrac{2}{5}}`}
</Katex>

:::tip De reținut
Comparăm **<HighlightText color="red">numărătorii</HighlightText>** doar după ce numitorii sunt egali.
:::
