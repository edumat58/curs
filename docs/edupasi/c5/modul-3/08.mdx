# C21.1 - Cel mai mic multiplu comun a două numere naturale

---

## Definiție

:::danger Definiție
**<HighlightText color="red">Cel mai mic multiplu comun</HighlightText>** a două numere naturale este cel mai mic multiplu comun al lor, diferit de 0.

Îl notăm **[a, b]**.
:::

Observăm că 12 se umple și cu bucăți de 4, și cu bucăți de 6.

<Katex>
{String.raw`
[\color{#FF6B6B}{4}, \color{#4ECDC4}{6}] = \color{#FF8C00}{12}
`}
</Katex>

---

## Algoritmul de determinare

:::tip De reținut
1. Descompunem numerele în factori primi.
2. Luăm toți factorii, o singură dată, cu exponentul cel mai mare.
3. Înmulțim factorii aleși.
:::

Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } 8 = 2^{3} \qquad 12 = 2^{2} \cdot 3\\[6pt]
& \text{Pasul 2: luăm } \color{#FF6B6B}{2^{3}} \text{ și } \color{#4ECDC4}{3}\\[6pt]
& \text{Pasul 3: } [8, 12] = 2^{3} \cdot 3 = 8 \cdot 3 = \color{#FF8C00}{24}
\end{aligned}
`}
</Katex>

## Exersează!

Numitorul comun este c.m.m.m.c. al numitorilor.

<Katex>
{String.raw`
\begin{aligned}
& \text{Model: } \frac{1}{2} \text{ și } \frac{2}{3}\\[6pt]
& \text{Pasul 1: } [2, 3] = \color{#FF8C00}{6}\\[6pt]
& \text{Pasul 2: } \frac{1}{2} = \frac{3}{6}\\[6pt]
& \text{Pasul 3: } \frac{2}{3} = \frac{4}{6}
\end{aligned}
`}
</Katex>

Aducem la un numitor comun fracțiile:

<Katex>
{String.raw`
\text{a) } \frac{1}{3} \text{ și } \frac{4}{5} \qquad \text{b) } \frac{5}{8} \text{ și } \frac{1}{4}
`}
</Katex>
