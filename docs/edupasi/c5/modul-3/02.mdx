# C19.2 - Procente şi fracții echivalente

---

## Calcul procentual

:::danger Definiție
Un **<HighlightText color="red">procent</HighlightText>** este o fracție cu numitorul 100. Scriem **a %**. Citim „a la sută".
:::

## Proprietăți

<Katex>
{String.raw`
\begin{aligned}
& \text{1. } a\,\% \text{ din } b = \color{#FF6B6B}{\frac{a}{100} \times b}\\[8pt]
& \text{2. partea } p \text{ din întregul } t = \color{#4ECDC4}{\frac{p}{t} \times 100}\,\%
\end{aligned}
`}
</Katex>

---

## Metode de calcul

Din 60 de elevi, 20 % merg pe jos.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } 20\,\% = \color{#FF6B6B}{\frac{20}{100}}\\[6pt]
& \text{Pasul 2: } \frac{20}{100} \times 60 = \frac{1\,200}{100}\\[6pt]
& \text{Pasul 3: } 1\,200 \div 100 = \color{#4ECDC4}{12 \text{ elevi}}
\end{aligned}
`}
</Katex>

Un tort de 50 g are 15 g zahăr.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } 15 \div 50 = \color{#FF8C00}{0{,}3}\\[6pt]
& \text{Pasul 2: } 0{,}3 = \frac{30}{100}\\[6pt]
& \text{Pasul 3: } \frac{30}{100} = \color{#4ECDC4}{30\,\% \text{ zahăr}}
\end{aligned}
`}
</Katex>
