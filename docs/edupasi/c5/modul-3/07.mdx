# C20.2 - Amplificarea și simplificarea fracțiilor

---

## Definiție

:::danger Definiție
**<HighlightText color="teal">A amplifica</HighlightText>** o fracție înseamnă să înmulțim numărătorul și numitorul cu același număr.

**<HighlightText color="orange">A simplifica</HighlightText>** o fracție înseamnă să împărțim numărătorul și numitorul la același număr.

## Amplificarea

Amplificăm fracția cu 2. Calculăm pas cu pas:

Pasul 1: Înmulțim numărătorul cu 2.

Pasul 2: Înmulțim numitorul cu 2.

<Katex>
{String.raw`
{}^{2)}\dfrac{3}{5} = \dfrac{3 \cdot 2}{5 \cdot 2} = \dfrac{\color{#FF8C00}{6}}{\color{#FF8C00}{10}}
`}
</Katex>

---

## Simplificarea

Simplificăm fracția prin 2. Calculăm pas cu pas:

Pasul 1: Împărțim numărătorul la 2.

Pasul 2: Împărțim numitorul la 2.

<Katex>
{String.raw`
\dfrac{6}{10}^{(2} = \dfrac{6 : 2}{10 : 2} = \dfrac{\color{#4ECDC4}{3}}{\color{#4ECDC4}{5}}
`}
</Katex>

:::tip De reținut
Fracția care nu se mai poate simplifica se numește **<HighlightText color="red">fracție ireductibilă</HighlightText>**.
:::

---

## Exersează!

Amplifică fiecare fracție cu 2:

<Katex>
{String.raw`
\text{a) } \dfrac{1}{4} \qquad \text{b) } \dfrac{2}{3} \qquad \text{c) } \dfrac{5}{6}
`}
</Katex>

Simplifică fiecare fracție prin 2:

<Katex>
{String.raw`
\text{a) } \dfrac{4}{8} \qquad \text{b) } \dfrac{6}{8} \qquad \text{c) } \dfrac{2}{10}
`}
</Katex>
