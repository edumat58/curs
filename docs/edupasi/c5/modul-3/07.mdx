# C20.2 - Amplificarea și simplificarea fracțiilor

---

## Definiție

:::danger Definiție 1
**<HighlightText color="red">A amplifica</HighlightText>** o fracție înseamnă să **<HighlightText color="red">înmulțim</HighlightText>** și **<HighlightText color="teal">numărătorul</HighlightText>**, și **<HighlightText color="teal">numitorul</HighlightText>** cu același număr natural, diferit de zero.
:::

Calculăm pas cu pas. Amplificăm fracția trei supra cinci cu 4:

1. Înmulțim numărătorul: 3 × 4 = 12.
2. Înmulțim numitorul: 5 × 4 = 20.
3. Scriem fracția obținută: doisprezece supra douăzeci.

<Katex>
{String.raw`
{}^{4)}\dfrac{\color{#FF6B6B}{3}}{\color{#4ECDC4}{5}} = \dfrac{4 \cdot 3}{4 \cdot 5} = \dfrac{\color{#FF6B6B}{12}}{\color{#4ECDC4}{20}}
`}
</Katex>

Citim: „Fracția trei supra cinci se amplifică cu patru și se obține fracția doisprezece supra douăzeci".

:::danger Definiție 2
**<HighlightText color="orange">A simplifica</HighlightText>** o fracție înseamnă să **<HighlightText color="orange">împărțim</HighlightText>** și **<HighlightText color="teal">numărătorul</HighlightText>**, și **<HighlightText color="teal">numitorul</HighlightText>** la același număr, diferit de zero.
:::

Calculăm pas cu pas. Simplificăm fracția opt supra zece prin 2:

1. Verificăm: 2 împarte exact și pe 8, și pe 10.
2. Împărțim numărătorul: 8 : 2 = 4.
3. Împărțim numitorul: 10 : 2 = 5.

<Katex>
{String.raw`
\dfrac{\color{#FF6B6B}{8}}{\color{#4ECDC4}{10}}^{(2} = \dfrac{8:2}{10:2} = \dfrac{\color{#FF6B6B}{4}}{\color{#4ECDC4}{5}}
`}
</Katex>

Citim: „Fracția opt supra zece se simplifică prin doi și se obține fracția patru supra cinci".

:::warning Atenție
* Simplificăm numai printr-un **<HighlightText color="red">divizor comun</HighlightText>** al numărătorului și al numitorului, diferit de 1.
* Înmulțim sau împărțim mereu **ambele numere**: și numărătorul, și numitorul.
:::

:::tip De reținut
* Prin amplificare sau prin simplificare obținem o fracție **<HighlightText color="teal">echivalentă</HighlightText>** cu fracția dată. Cele două fracții reprezintă aceeași parte din întreg.
* Fracția care nu mai poate fi simplificată se numește **<HighlightText color="red">fracție ireductibilă</HighlightText>**.
:::

Observăm cum ajungem la o fracție ireductibilă prin simplificări succesive:

<Katex>
{String.raw`
\dfrac{12}{18}^{(2} = \dfrac{6}{9}^{(3} = \dfrac{\color{#FF6B6B}{2}}{\color{#FF6B6B}{3}}
`}
</Katex>

Fracția doi supra trei nu se mai poate simplifica. Este ireductibilă.

:::note Exercițiul 1
Simplifică fracțiile pentru a obține fracții ireductibile:

<Katex>
{String.raw`
\text{a) } \dfrac{15}{10} \qquad \text{b) } \dfrac{3}{21} \qquad \text{c) } \dfrac{4}{10} \qquad \text{d) } \dfrac{42}{30}
`}
</Katex>
:::

:::note Exercițiul 2
Amplifică fracțiile pentru a obține numitorul 100, apoi scrie-le ca procente:

<Katex>
{String.raw`
\text{a) } \dfrac{3}{10} \qquad \text{b) } \dfrac{1}{20} \qquad \text{c) } \dfrac{2}{5} \qquad \text{d) } \dfrac{3}{4}
`}
</Katex>
:::

Model de lucru: numitorul 5 devine 100 prin amplificare cu 20.

<Katex>
{String.raw`
{}^{20)}\dfrac{3}{5} = \dfrac{60}{100} = 60\%
`}
</Katex>
