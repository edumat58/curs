# C19.5 - Introducerea și scoaterea întregilor dintr-o fracție

---

## Introducere

Observăm fracția 5/3. Numărătorul 5 este mai mare decât numitorul 3. Fracția este **<HighlightText color="red">supraunitară</HighlightText>**.

Împărțim numărătorul la numitor. Deîmpărțitul este 5. Împărțitorul este 3.

<Katex>
{String.raw`
5 \div 3 = \color{#4ECDC4}{1}, \text{ rest } \color{#FF6B6B}{2}
`}
</Katex>

Câtul este 1. Restul este 2.

:::note
Completează tabelul, la fel ca pe primul rând.
:::

| Fracția | Câtul împărțirii | Restul împărțirii |
|:---:|:---:|:---:|
| 5/3 | 1 | 2 |
| 8/5 | | |
| 11/3 | | |
| 7/4 | | |
| 5/2 | | |

---

## Definiție

:::danger Definiție
**<HighlightText color="red">Scoaterea întregilor</HighlightText>** dintr-o fracție supraunitară:
- **<HighlightText color="teal">câtul</HighlightText>** împărțirii numărătorului la numitor este **numărul de întregi**;
- **<HighlightText color="red">restul</HighlightText>** este **noul numărător**;
- **numitorul** rămâne același.
:::

Calculăm pas cu pas pentru fracția 5/3:

<Katex>
{String.raw`
\begin{aligned}
& \text{1. Împărțim: } 5 \div 3 = \color{#4ECDC4}{1}, \text{ rest } \color{#FF6B6B}{2}\\[6pt]
& \text{2. Câtul } \color{#4ECDC4}{1} \text{ este numărul de întregi}\\[6pt]
& \text{3. Restul } \color{#FF6B6B}{2} \text{ este noul numărător}\\[6pt]
& \text{4. Scriem: } \frac{5}{3} = \color{#4ECDC4}{1}\frac{\color{#FF6B6B}{2}}{3}
\end{aligned}
`}
</Katex>

Citim: „un întreg și două treimi".

Încă un exemplu:

<Katex>
{String.raw`
17 \div 5 = \color{#4ECDC4}{3}, \text{ rest } \color{#FF6B6B}{2}, \text{ deci } \frac{17}{5} = \color{#4ECDC4}{3}\frac{\color{#FF6B6B}{2}}{5}
`}
</Katex>

Operația inversă se numește **<HighlightText color="teal">introducerea întregilor în fracție</HighlightText>**.

:::tip De reținut
<Katex>
{String.raw`
\color{#4ECDC4}{a}\frac{b}{c} = \frac{\color{#4ECDC4}{a} \times c + b}{c}, \quad c \neq 0
`}
</Katex>
:::

Introducem întregii înapoi în fracție. Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{1. Înmulțim întregii cu numitorul: } \color{#4ECDC4}{1} \times 3 = 3\\[6pt]
& \text{2. Adunăm numărătorul: } 3 + 2 = 5\\[6pt]
& \text{3. Scriem suma deasupra numitorului: } \color{#4ECDC4}{1}\frac{2}{3} = \frac{5}{3}
\end{aligned}
`}
</Katex>

Am obținut fracția de la care am plecat. Cele două operații se verifică una pe cealaltă.

Încă un exemplu:

<Katex>
{String.raw`
3\frac{1}{4} = \frac{3 \times 4 + 1}{4} = \frac{13}{4}
`}
</Katex>

:::warning Atenție
- Scoatem întregii numai din fracțiile **<HighlightText color="red">supraunitare</HighlightText>**.
- La introducerea întregilor, întâi **<HighlightText color="orange">înmulțim</HighlightText>** întregii cu numitorul. Abia apoi adunăm numărătorul.

<Katex>
{String.raw`
1\frac{2}{3} = \frac{1 \times 3 + 2}{3} = \frac{5}{3}, \text{ nu } \frac{1 + 2}{3}
`}
</Katex>
:::
