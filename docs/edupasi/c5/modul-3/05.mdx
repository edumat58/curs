## Definiție

:::danger Definiție
**<HighlightText color="red">Scoatem întregii</HighlightText>**: împărțim numărătorul la numitor.

- **<HighlightText color="teal">câtul</HighlightText>** este numărul de întregi;
- **<HighlightText color="red">restul</HighlightText>** este noul numărător;
- numitorul rămâne la fel.
:::

Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1. Împărțim: } 5 : 3 = \color{#4ECDC4}{1} \text{ rest } \color{#FF6B6B}{2}\\[8pt]
& \text{Pasul 2. Câtul } \color{#4ECDC4}{1} \text{ este întregul}\\[8pt]
& \text{Pasul 3. Restul } \color{#FF6B6B}{2} \text{ merge la numărător}\\[8pt]
& \text{Pasul 4. Scriem: } \frac{5}{3} = \color{#4ECDC4}{1}\frac{\color{#FF6B6B}{2}}{3}
\end{aligned}
`}
</Katex>

Facem și operația inversă.

:::tip De reținut
**<HighlightText color="orange">Introducem întregii</HighlightText>** în fracție:

<Katex>
{String.raw`
\color{#FF8C00}{a}\frac{b}{c} = \frac{\color{#FF8C00}{a} \times c + b}{c}
`}
</Katex>
:::

Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1. Înmulțim: } \color{#FF8C00}{3} \times 4 = 12\\[8pt]
& \text{Pasul 2. Adunăm numărătorul: } 12 + 1 = 13\\[8pt]
& \text{Pasul 3. Scriem: } \color{#FF8C00}{3}\frac{1}{4} = \frac{13}{4}
\end{aligned}
`}
</Katex>
