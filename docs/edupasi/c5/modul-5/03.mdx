# G7 - Tipuri de unghiuri. Măsura unghiurilor

---

## Ce este un unghi?

:::danger Definiție
Un **<HighlightText color="red">unghi</HighlightText>** este format din două semidrepte cu aceeași origine.
:::

<div style={{ display: "flex", justifyContent: "center", margin: "1.5rem 0" }}>
<svg width="380" height="230" viewBox="0 0 380 230" xmlns="http://www.w3.org/2000/svg">
  <line x1="70" y1="180" x2="340" y2="180" stroke="black" strokeWidth="4" />
  <line x1="70" y1="180" x2="300" y2="55" stroke="black" strokeWidth="4" />
  <path d="M 150 180 A 80 80 0 0 0 140 141" fill="none" stroke="#FF6B6B" strokeWidth="4" />
  <circle cx="70" cy="180" r="6" fill="black" />
  <circle cx="340" cy="180" r="6" fill="black" />
  <circle cx="300" cy="55" r="6" fill="black" />
  <text x="40" y="210" fontSize="30" fontFamily="serif" fontWeight="bold">O</text>
  <text x="345" y="210" fontSize="30" fontFamily="serif" fontWeight="bold">A</text>
  <text x="310" y="48" fontSize="30" fontFamily="serif" fontWeight="bold">B</text>
  <text x="52" y="228" fontSize="22" fontFamily="serif" fill="#FF6B6B">vârf</text>
  <text x="200" y="210" fontSize="22" fontFamily="serif" fill="#4ECDC4">latură</text>
  <text x="215" y="95" fontSize="22" fontFamily="serif" fill="#4ECDC4">latură</text>
</svg>
</div>

Scriem unghiul din desen astfel:

<Katex>
{String.raw`
\angle \color{#4ECDC4}{A}\color{#FF6B6B}{O}\color{#4ECDC4}{B}
`}
</Katex>

Litera din mijloc arată vârful.

---

## Măsura unghiurilor

Măsurăm unghiurile în grade.

<Katex>
{String.raw`
\begin{aligned}
& \text{o rotație completă} = \color{#FF6B6B}{360^\circ}\\[6pt]
& 1^\circ = \color{#4ECDC4}{60'}
\end{aligned}
`}
</Katex>

---

## Tipuri de unghiuri după măsură

| Unghiul | Măsura |
|---|---|
| ascuțit | sub <Katex>{String.raw`90^\circ`}</Katex> |
| drept | exact <Katex>{String.raw`90^\circ`}</Katex> |
| obtuz | peste <Katex>{String.raw`90^\circ`}</Katex>, sub <Katex>{String.raw`180^\circ`}</Katex> |
| alungit | exact <Katex>{String.raw`180^\circ`}</Katex> |
| complet | exact <Katex>{String.raw`360^\circ`}</Katex> |

---

## Perechi remarcabile de unghiuri

:::tip De reținut
- Suma este <Katex>{String.raw`90^\circ`}</Katex>: unghiuri **<HighlightText color="teal">complementare</HighlightText>**.
- Suma este <Katex>{String.raw`180^\circ`}</Katex>: unghiuri **<HighlightText color="orange">suplementare</HighlightText>**.
:::

<Katex>
{String.raw`
\begin{aligned}
& 30^\circ + 60^\circ = \color{#4ECDC4}{90^\circ}\\[6pt]
& 110^\circ + 70^\circ = \color{#FF8C00}{180^\circ}
\end{aligned}
`}
</Katex>

Unghiurile opuse la vârf au aceeași măsură.

---

## Calcule cu unghiuri

Aflăm complementul și suplementul unghiului de <Katex>{String.raw`35^\circ`}</Katex>.

**Pasul 1.** Pentru complement scădem din <Katex>{String.raw`90^\circ`}</Katex>.

<Katex>
{String.raw`
90^\circ - 35^\circ = \color{#4ECDC4}{55^\circ}
`}
</Katex>

**Pasul 2.** Pentru suplement scădem din <Katex>{String.raw`180^\circ`}</Katex>.

<Katex>
{String.raw`
180^\circ - 35^\circ = \color{#FF8C00}{145^\circ}
`}
</Katex>
