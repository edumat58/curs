# G7 - Tipuri de unghiuri. Măsura unghiurilor

---

## Ce este un unghi?

:::danger Definiție
Un **<HighlightText color="red">unghi</HighlightText>** este figura geometrică formată din **<HighlightText color="teal">două semidrepte</HighlightText>** care au **<HighlightText color="teal">aceeași origine</HighlightText>**.
:::

- Cele două semidrepte sunt **<HighlightText color="teal">laturile</HighlightText>** unghiului.
- Originea lor comună este **<HighlightText color="red">vârful</HighlightText>** unghiului.

  <line x1="60" y1="180" x2="290" y2="50" stroke="black" strokeWidth="4" />
  <path d="M 140 180 A 80 80 0 0 0 130 141" fill="none" stroke="#FF6B6B" strokeWidth="4" />
  <circle cx="60" cy="180" r="5" fill="black" />
  <circle cx="330" cy="180" r="5" fill="black" />
  <circle cx="290" cy="50" r="5" fill="black" />
  <text x="32" y="207" fontSize="30" fontFamily="serif" fontWeight="bold">O</text>
  <text x="335" y="207" fontSize="30" fontFamily="serif" fontWeight="bold">A</text>

Observăm figura. Vârful este punctul **O**. Laturile sunt **OA** și **OB**.

Scriem unghiul astfel:

<Katex>
{String.raw`
\angle \color{#4ECDC4}{A}\color{#FF6B6B}{O}\color{#4ECDC4}{B}
`}
</Katex>

:::warning Atenție
Când scriem un unghi cu trei litere, litera din mijloc este întotdeauna **<HighlightText color="red">vârful</HighlightText>**.
:::

---

## Măsura unghiurilor

Măsurăm unghiurile în **<HighlightText color="orange">grade</HighlightText>**. Semnul pentru grade este <Katex>{String.raw`^\circ`}</Katex>.

:::tip De reținut
<Katex>
{String.raw`
\begin{aligned}
& \text{O rotație completă} = \color{#FF6B6B}{360^\circ}\\[6pt]
& 1^\circ = \color{#4ECDC4}{60'} \quad (\text{60 de minute})\\[6pt]
& 1' = \color{#9370DB}{60''} \quad (\text{60 de secunde})
\end{aligned}
`}
</Katex>
:::

| Tipul unghiului | Măsura |
|---|---|
| Unghi nul | exact <Katex>{String.raw`0^\circ`}</Katex> |
| Unghi ascuțit | mai mare decât <Katex>{String.raw`0^\circ`}</Katex>, mai mic decât <Katex>{String.raw`90^\circ`}</Katex> |
| Unghi drept | exact <Katex>{String.raw`90^\circ`}</Katex> |
| Unghi obtuz | mai mare decât <Katex>{String.raw`90^\circ`}</Katex>, mai mic decât <Katex>{String.raw`180^\circ`}</Katex> |
| Unghi alungit | exact <Katex>{String.raw`180^\circ`}</Katex> |
| Unghi complet | exact <Katex>{String.raw`360^\circ`}</Katex> |

:::warning Atenție
Unghiul **<HighlightText color="red">drept</HighlightText>** se marchează cu un mic pătrat în vârf, nu cu un arc.
:::

## Perechi remarcabile de unghiuri

### Unghiuri complementare

:::danger Definiție
Două unghiuri sunt **<HighlightText color="red">complementare</HighlightText>** dacă suma măsurilor lor este **<HighlightText color="teal">90°</HighlightText>**.
:::

Verificăm pe un exemplu:

<Katex>
{String.raw`
30^\circ + 60^\circ = \color{#4ECDC4}{90^\circ}
`}
</Katex>

Unghiurile de <Katex>{String.raw`30^\circ`}</Katex> și <Katex>{String.raw`60^\circ`}</Katex> sunt complementare.

### Unghiuri suplementare

:::danger Definiție
Două unghiuri sunt **<HighlightText color="red">suplementare</HighlightText>** dacă suma măsurilor lor este **<HighlightText color="teal">180°</HighlightText>**.
:::

Verificăm pe un exemplu:

<Katex>
{String.raw`
110^\circ + 70^\circ = \color{#4ECDC4}{180^\circ}
`}
</Katex>

Unghiurile de <Katex>{String.raw`110^\circ`}</Katex> și <Katex>{String.raw`70^\circ`}</Katex> sunt suplementare.

### Unghiuri opuse la vârf

:::danger Definiție
Două unghiuri sunt **<HighlightText color="red">opuse la vârf</HighlightText>** dacă laturile unuia sunt **<HighlightText color="teal">prelungirile</HighlightText>** laturilor celuilalt.
:::

:::tip De reținut
Unghiurile opuse la vârf au **<HighlightText color="red">aceeași măsură</HighlightText>**.
:::

Exemplu: două drepte se intersectează. Un unghi are <Katex>{String.raw`50^\circ`}</Katex>. Unghiul opus la vârf are tot <Katex>{String.raw`50^\circ`}</Katex>.

## Calcule cu unghiuri

### Adunarea măsurilor

Calculăm pas cu pas:

<Katex>
{String.raw`
35^\circ 40' + 28^\circ 30'
`}
</Katex>

**Pasul 1.** Adunăm gradele cu gradele.

<Katex>
{String.raw`
35^\circ + 28^\circ = 63^\circ
`}
</Katex>

**Pasul 2.** Adunăm minutele cu minutele.

<Katex>
{String.raw`
40' + 30' = 70'
`}
</Katex>

**Pasul 3.** Transformăm minutele. Reținem: <Katex>{String.raw`60' = 1^\circ`}</Katex>.

<Katex>
{String.raw`
70' = 60' + 10' = \color{#FF6B6B}{1^\circ 10'}
`}
</Katex>

**Pasul 4.** Adunăm tot.

<Katex>
{String.raw`
63^\circ + 1^\circ 10' = \color{#4ECDC4}{64^\circ 10'}
`}
</Katex>

### Aflarea complementului și a suplementului

:::tip De reținut
- **<HighlightText color="teal">Complementul</HighlightText>**: scădem unghiul din <Katex>{String.raw`90^\circ`}</Katex>.
- **<HighlightText color="orange">Suplementul</HighlightText>**: scădem unghiul din <Katex>{String.raw`180^\circ`}</Katex>.
:::

Aflăm complementul și suplementul unghiului de <Katex>{String.raw`35^\circ`}</Katex>.

**Pasul 1.** Calculăm complementul.

<Katex>
{String.raw`
90^\circ - 35^\circ = \color{#4ECDC4}{55^\circ}
`}
</Katex>

**Pasul 2.** Calculăm suplementul.

<Katex>
{String.raw`
180^\circ - 35^\circ = \color{#FF8C00}{145^\circ}
`}
</Katex>
