# C22 - Adunarea și scăderea fracțiilor ordinare

---

## Adunarea și Scăderea Fracțiilor

### Fracții cu același numitor

:::danger Definiție
Adunăm **<HighlightText color="red">numărătorii</HighlightText>**. **<HighlightText color="teal">Numitorul</HighlightText>** rămâne același.
:::

Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{Calculăm } \frac{3}{8} + \frac{2}{8}\\[8pt]
& \text{Pasul 1: numitorii sunt la fel: } \color{#4ECDC4}{8}\\[8pt]
& \text{Pasul 2: adunăm numărătorii: } 3 + 2 = \color{#FF6B6B}{5}\\[8pt]
& \text{Pasul 3: scriem rezultatul: } \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{8}}
\end{aligned}
`}
</Katex>

La scădere, scădem numărătorii:

<Katex>
{String.raw`
\frac{5}{8} - \frac{2}{8} = \frac{5-2}{8} = \frac{\color{#FF6B6B}{3}}{\color{#4ECDC4}{8}}
`}
</Katex>

### Fracții cu numitori diferiți

Aducem fracțiile la **<HighlightText color="orange">numitor comun</HighlightText>** prin amplificare.

<Katex>
{String.raw`
\begin{aligned}
& \text{Calculăm } \frac{1}{2} + \frac{1}{3}\\[8pt]
& \text{Pasul 1: numitorul comun este } \color{#FF8C00}{6}\\[8pt]
& \text{Pasul 2: amplificăm: } \frac{1}{2} = \frac{3}{6} \text{ și } \frac{1}{3} = \frac{2}{6}\\[8pt]
& \text{Pasul 3: adunăm numărătorii: } \frac{3}{6} + \frac{2}{6} = \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{6}}
\end{aligned}
`}
</Katex>

:::warning Atenție
Dacă se poate, simplificăm rezultatul.

<Katex>
{String.raw`
\frac{3}{4} - \frac{1}{4} = \frac{2}{4} = \frac{\color{#FF6B6B}{1}}{\color{#4ECDC4}{2}}
`}
</Katex>
:::

## Operații între un număr natural și o fracție

Scriem numărul natural ca fracție cu numitorul 1.

<Katex>
{String.raw`
\begin{aligned}
& \text{Calculăm } 2 + \frac{3}{5}\\[8pt]
& \text{Pasul 1: } 2 = \frac{2}{1}\\[8pt]
& \text{Pasul 2: amplificăm cu 5: } \frac{2}{1} = \frac{10}{5}\\[8pt]
& \text{Pasul 3: adunăm: } \frac{10}{5} + \frac{3}{5} = \frac{\color{#FF6B6B}{13}}{\color{#4ECDC4}{5}}
\end{aligned}
`}
</Katex>

La scădere procedăm la fel:

<Katex>
{String.raw`
2 - \frac{3}{5} = \frac{10}{5} - \frac{3}{5} = \frac{\color{#FF6B6B}{7}}{\color{#4ECDC4}{5}}
`}
</Katex>

## Proprietățile adunării

Ordinea termenilor nu schimbă rezultatul.

<Katex>
{String.raw`
\frac{1}{5} + \frac{2}{5} = \frac{2}{5} + \frac{1}{5} = \frac{3}{5}
`}
</Katex>

Adunarea cu 0 nu schimbă fracția.

<Katex>
{String.raw`
\frac{4}{9} + 0 = \frac{4}{9}
`}
</Katex>

La scădere, ordinea termenilor nu se schimbă.
