# C2s - Adunarea și scăderea nr. zecimale

---
<ResurseParinti fisier="00" />

## Pasul 1: Înțeleg teoria

:::tip Definiție
Se numește:

1. **<HighlightText color="red">sumă</HighlightText>**, rezultatul unei adunări;
2. **<HighlightText color="blue">diferență</HighlightText>**, rezultatul unei scăderi;
3. **<HighlightText color="green">termeni</HighlightText>**, numerele care se adună sau care se scad.
:::

**Exemplu.** Iată două exemple:

- $4{,}7 + 2{,}03 = 6{,}73$. Aici, $6{,}73$ este **suma** termenilor $4{,}7$ și $2{,}03$.
- $23{,}1 - 5{,}8 = 17{,}3$. Aici, $17{,}3$ este **diferența** termenilor $23{,}1$ și $5{,}8$.

:::info Observație
Sunt trei feluri de a calcula o sumă sau o diferență:

- așezând operația;
- folosind calculatorul;
- socotind în minte, cu tehnici de calcul.

O **adunare se verifică printr-o scădere**: $8{,}17 + 5{,}83 = 14$, pentru că $14 - 5{,}83 = 8{,}17$.

O **scădere se verifică printr-o adunare**: $2\,000 - 177{,}5 = 1\,822{,}5$, pentru că $1\,822{,}5 + 177{,}5 = 2\,000$.
:::

## Pasul 2: Observ exemplele

:::tip De reținut
La operația așezată, cifrele se aliniază **după virgulă**, nu după capătul din dreapta.

Când unui număr îi lipsește un rang zecimal, locul rămâne gol: la $456{,}75 - 175{,}642$, sutimile stau sub sutimi, iar la miimi nu e nimic de scăzut din nimic.
:::

:::note
Observă aceste adunări și scăderi așezate una sub alta.
:::
