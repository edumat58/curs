# C4 - Împărțirea Euclidiană. Împărțirea nr. zecimale

## Împărțirea euclidiană

:::danger Definiție
La împărțirea cu **<HighlightText color="orange">rest</HighlightText>** avem patru numere.

<Katex>
{String.raw`
\color{#FF6B6B}{\text{deîmpărțit}} = \color{#4ECDC4}{\text{împărțitor}} \times \color{#9370DB}{\text{cât}} + \color{#FF8C00}{\text{rest}}
`}
</Katex>
:::

Punem 17 bomboane în grupe de câte 5.

<Katex>
{String.raw`
\underbrace{17}_{\color{#FF6B6B}{\text{deîmpărțit}}} = \underbrace{5}_{\color{#4ECDC4}{\text{împărțitor}}} \times \underbrace{3}_{\color{#9370DB}{\text{cât}}} + \underbrace{2}_{\color{#FF8C00}{\text{rest}}}
`}
</Katex>

**Exemplu:** Calculăm pas cu pas 17 : 5.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: căutăm câtul: } 5 \times \color{#9370DB}{3} = 15\\[6pt]
& \text{Pasul 2: aflăm restul: } 17 - 15 = \color{#FF8C00}{2}\\[6pt]
& \text{Pasul 3: facem proba: } 5 \times 3 + 2 = 17
\end{aligned}
`}
</Katex>

:::tip De reținut
Restul este mereu mai mic decât împărțitorul.

<Katex>
{String.raw`\color{#FF8C00}{2} \lt \color{#4ECDC4}{5}`}
</Katex>
:::

## Împărțirea unui număr zecimal la un număr natural

Împărțim ca la numerele naturale. Punem virgula la cât.

**Exemplu:** Calculăm pas cu pas 7,5 : 3.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } 7 \div 3 = 2 \text{ rest } 1\\[6pt]
& \text{Pasul 2: punem } \color{#FF6B6B}{\text{virgula}} \text{ la cât}\\[6pt]
& \text{Pasul 3: coborâm zecimala } 5 \text{ și avem } 15\\[6pt]
& \text{Pasul 4: } 15 \div 3 = 5\\[6pt]
& \text{Rezultat: } 7{,}5 \div 3 = \color{#9370DB}{2{,}5}
\end{aligned}
`}
</Katex>

Facem proba.

<Katex>
{String.raw`3 \times 2{,}5 = 7{,}5`}
</Katex>

## Împărțirea la un număr zecimal

Mutăm **<HighlightText color="red">virgula</HighlightText>** spre dreapta la amândouă numerele.

**Exemplu:** Calculăm pas cu pas 7,2 : 0,3.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: mutăm virgula: } 7{,}2 \to \color{#FF6B6B}{72} \text{ și } 0{,}3 \to \color{#4ECDC4}{3}\\[6pt]
& \text{Pasul 2: } 72 \div 3 = 24\\[6pt]
& \text{Rezultat: } 7{,}2 \div 0{,}3 = \color{#9370DB}{24}
\end{aligned}
`}
</Katex>
