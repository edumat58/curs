# C7.1 – Ilustrarea fracţiilor echiunitare, subunitare și supraunitare

---

## Introducere

:::danger Definiție
O **<HighlightText color="purple">fracție</HighlightText>** arată o parte dintr-un întreg.

- **<HighlightText color="teal">Numitorul</HighlightText>** este numărul de jos. El arată în câte **părți egale** împărțim întregul.
- **<HighlightText color="red">Numărătorul</HighlightText>** este numărul de sus. El arată câte părți **luăm**.
:::

:::tip De reținut
Comparăm **<HighlightText color="red">numărătorul</HighlightText>** cu **<HighlightText color="teal">numitorul</HighlightText>**:
<Katex>
{String.raw`
\begin{aligned}
& \color{#FF6B6B}{1} < \color{#4ECDC4}{2} \to \frac{1}{2} \text{ este } \color{#4ECDC4}{\text{subunitară}} \to \frac{1}{2} < 1\\[8pt]
& \color{#FF6B6B}{2} = \color{#4ECDC4}{2} \to \frac{2}{2} \text{ este } \color{#9370DB}{\text{echiunitară}} \to \frac{2}{2} = 1\\[8pt]
& \color{#FF6B6B}{3} > \color{#4ECDC4}{2} \to \frac{3}{2} \text{ este } \color{#FF6B6B}{\text{supraunitară}} \to \frac{3}{2} > 1
\end{aligned}
`}
</Katex>
:::

---

## Reprezentări grafice variate

### Reprezentarea circulară

1. Desenăm un cerc. Cercul este întregul.
2. Împărțim cercul în părți egale, câte arată **numitorul**.
3. Colorăm atâtea părți câte arată **numărătorul**.

:::warning Atenție
La fracția **<HighlightText color="red">supraunitară</HighlightText>** un singur întreg nu ajunge. Desenăm încă un întreg și colorăm mai departe.
:::

### Reprezentarea dreptunghiulară

1. Desenăm un dreptunghi. Dreptunghiul este întregul.
2. Numitorul este 3, deci împărțim dreptunghiul în 3 părți egale.
3. Numărătorul este 2, deci colorăm 2 părți.

<Katex>
{String.raw`
\frac{\color{#FF6B6B}{2}}{\color{#4ECDC4}{3}} \qquad \color{#FF6B6B}{2} < \color{#4ECDC4}{3} \to \text{fracție } \color{#4ECDC4}{\text{subunitară}}
`}
</Katex>

### Reprezentarea pe axa numerelor

1. Desenăm axa numerelor. Marcăm 0, 1 și 2.
2. Împărțim fiecare unitate în părți egale, câte arată **numitorul**.
3. Numărăm de la 0 atâția pași câte arată **numărătorul**. Acolo este fracția.

{String.raw`
\frac{3}{4} < 1 \to \color{#4ECDC4}{\text{subunitară}} \qquad \frac{7}{4} > 1 \to \color{#FF6B6B}{\text{supraunitară}}
`}
</Katex>

## Exemple detaliate

### Exemplul 1 – Fracție subunitară

1. Numitorul este 5, deci împărțim întregul în 5 părți egale.
2. Numărătorul este 2, deci colorăm 2 părți.
3. Comparăm: 2 este mai mic decât 5, deci fracția este subunitară.

<Katex>
{String.raw`
\frac{\color{#FF6B6B}{2}}{\color{#4ECDC4}{5}} \qquad \color{#FF6B6B}{2} < \color{#4ECDC4}{5} \to \frac{2}{5} < 1 \to \color{#4ECDC4}{\text{subunitară}}
`}
</Katex>

### Exemplul 2 – Fracție supraunitară

1. Numitorul este 3, deci un întreg are 3 părți egale.
2. Numărătorul este 4, deci un întreg nu ajunge: colorăm un întreg și încă o parte din al doilea întreg.
3. Comparăm: 4 este mai mare decât 3, deci fracția este supraunitară.

<Katex>
{String.raw`
\frac{\color{#FF6B6B}{4}}{\color{#4ECDC4}{3}} = \frac{3}{3} + \frac{1}{3} = 1 + \frac{1}{3} \qquad \color{#FF6B6B}{4} > \color{#4ECDC4}{3} \to \color{#FF6B6B}{\text{supraunitară}}
`}
</Katex>
