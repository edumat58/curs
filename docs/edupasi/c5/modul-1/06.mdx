# C6.1 - Mulțimi. Mulțimea nr. naturale

---

## Mulțimi

:::danger Definiție
O **<HighlightText color="red">mulțime</HighlightText>** este o grupă de **<HighlightText color="teal">elemente</HighlightText>**. Numele ei se scrie cu literă mare. Elementele stau între acolade.
:::

**Exemplu:** mulțimea literelor cuvântului „mama".

Pasul 1: Literele sunt m, a, m, a.

Pasul 2: Scriem fiecare literă o singură dată.

<Katex>
{String.raw`
\color{#FF6B6B}{B} = \{\color{#4ECDC4}{m;\, a}\}
`}
</Katex>

---

## Mulțimea nr. naturale

Numerele naturale sunt numerele cu care numărăm.

<Katex>
{String.raw`
\color{#9370DB}{\mathbb{N}} = \{0;\,1;\,2;\,3;\,4;\,\ldots\}
`}
</Katex>

Mulțimea este infinită. Numerele nu se termină.

---

### Definirea unei mulțimi

O mulțime se scrie și cu o condiție.

<Katex>
{String.raw`
D = \{\,\color{#FF6B6B}{x}\ \mid\ \color{#4ECDC4}{2 < x \le 6}\,\}
`}
</Katex>

Observăm că x este mai mare decât 2. Și x este cel mult 6.

Pasul 1: Pe 2 nu îl luăm.

Pasul 2: Pe 6 îl luăm.

Pasul 3: Scriem numerele colorate.

<Katex>
{String.raw`
\Rightarrow D = \{\color{#4ECDC4}{3;\,4;\,5;\,6}\}
`}
</Katex>

:::tip De reținut
Cercul **<HighlightText color="red">gol</HighlightText>** arată că numărul nu intră. Cercul **<HighlightText color="teal">plin</HighlightText>** arată că numărul intră.
:::
