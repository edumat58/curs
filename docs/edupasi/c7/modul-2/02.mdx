## Obținerea de noi egalități din egalități date

Avem două egalități. Le putem aduna sau scădea.

### Exemplul 1

Știm că <HighlightText color="red">a + b = 11</HighlightText> și <HighlightText color="teal">c + d = 9</HighlightText>. Aflăm a + b + c + d.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1. Scriem cele două egalități:} \\[8pt]
& \color{#FF6B6B}{a + b = 11} \\[8pt]
& \color{#4ECDC4}{c + d = 9} \\[8pt]
& \text{Pasul 2. Le adunăm:} \\[8pt]
& a + b + c + d = 11 + 9 \\[8pt]
& a + b + c + d = \color{#FF8C00}{20}
\end{aligned}
`}
</Katex>

### Exemplul 2

Știm că <HighlightText color="red">b + c = 13</HighlightText> și <HighlightText color="teal">x = 4</HighlightText>. Aflăm b + c - x.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1. Scriem cele două egalități:} \\[8pt]
& \color{#FF6B6B}{b + c = 13} \\[8pt]
& \color{#4ECDC4}{x = 4} \\[8pt]
& \text{Pasul 2. Le scădem:} \\[8pt]
& b + c - x = 13 - 4 \\[8pt]
& b + c - x = \color{#FF8C00}{9}
\end{aligned}
`}
</Katex>

\end{aligned}
`}
