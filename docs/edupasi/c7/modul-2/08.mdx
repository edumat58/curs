## Introducerea și scoaterea factorilor de sub radical

Scoatem factorul din radical:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } \sqrt{12} = \sqrt{\color{#FF6B6B}{4} \cdot 3} \\[8pt]
& \text{Pasul 2: } \sqrt{\color{#FF6B6B}{4}} = \color{#FF6B6B}{2} \\[8pt]
& \text{Pasul 3: } \sqrt{12} = \color{#FF6B6B}{2}\sqrt{3}
\end{aligned}
`}
</Katex>

Introducem factorul sub radical:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } \color{#9370DB}{2}\sqrt{5} \\[8pt]
& \text{Pasul 2: } \color{#9370DB}{2}^2 = \color{#9370DB}{4} \\[8pt]
& \text{Pasul 3: } \color{#9370DB}{2}\sqrt{5} = \sqrt{\color{#9370DB}{4} \cdot 5} = \sqrt{20}
\end{aligned}
`}
</Katex>

## Operații cu modulul unui număr real

Modulul este distanța până la zero. El nu este niciodată negativ.

<Katex>
{String.raw`
|a| =
\begin{cases}
a, & \text{dacă } a \ge 0 \\
-a, & \text{dacă } a \lt 0
\end{cases}
`}
</Katex>

Observăm că semnul minus dispare:

<Katex>
{String.raw`
\begin{aligned}
& \color{#FF6B6B}{|7|} = 7 \\[8pt]
& \color{#4ECDC4}{|-7|} = 7 \\[8pt]
& \sqrt{(-4)^2} = |-4| = 4
\end{aligned}
`}
</Katex>
