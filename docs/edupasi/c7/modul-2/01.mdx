# G4 - Paralelogramul

---

## Definiție

:::danger Definiție
**<HighlightText color="red">Paralelogramul</HighlightText>** este patrulaterul cu **<HighlightText color="teal">laturile opuse paralele</HighlightText>**.
:::

<Katex>
{String.raw`
\color{#4ECDC4}{AB \parallel CD} \qquad \color{#FF6B6B}{BC \parallel AD}
`}
</Katex>

---

## Proprietăți

<Katex>
{String.raw`
\begin{aligned}
& \text{1. Laturile opuse sunt } \color{#FF6B6B}{\text{egale}}: \; AB = CD, \; AD = BC\\[8pt]
& \text{2. Unghiurile opuse sunt } \color{#4ECDC4}{\text{egale}}: \; \angle A = \angle C, \; \angle B = \angle D\\[8pt]
& \text{3. Unghiurile alăturate: } \angle A + \angle B = \color{#FF8C00}{180^\circ}
\end{aligned}
`}
</Katex>

:::tip De reținut
Unghiurile **<HighlightText color="teal">opuse</HighlightText>** sunt egale. Unghiurile **<HighlightText color="orange">alăturate</HighlightText>** dau împreună 180 de grade.
:::

---

## Cum recunoaștem un paralelogram

<Katex>
{String.raw`
\begin{aligned}
& \text{a) laturile opuse sunt } \color{#4ECDC4}{\text{paralele}}\\[8pt]
& \text{b) laturile opuse sunt } \color{#FF6B6B}{\text{egale}}\\[8pt]
& \text{c) diagonalele se taie în } \color{#9370DB}{\text{două părți egale}}
\end{aligned}
`}
</Katex>

---

## Aplicații

Paralelogramul ABCD are unghiul A de 70 de grade. Aflăm celelalte unghiuri.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } \angle C = \angle A = \color{#FF6B6B}{70^\circ}\\[8pt]
& \text{Pasul 2: } \angle B = 180^\circ - 70^\circ = \color{#4ECDC4}{110^\circ}\\[8pt]
& \text{Pasul 3: } \angle D = \angle B = \color{#4ECDC4}{110^\circ}
\end{aligned}
`}
</Katex>

Paralelogramul ABCD are AB de 8 cm și AD de 5 cm. Aflăm celelalte laturi.

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } CD = AB = \color{#FF6B6B}{8 \text{ cm}}\\[8pt]
& \text{Pasul 2: } BC = AD = \color{#4ECDC4}{5 \text{ cm}}
\end{aligned}
`}
</Katex>
