# C3 – Calcul cu radicali și proprietăți

---

## Noțiuni

:::danger Definiție
**<HighlightText color="red">Rădăcina pătrată</HighlightText>** a unui număr este numărul care, înmulțit cu el însuși, dă acel număr.
:::

<Katex>
{String.raw`
\sqrt{\color{#FF6B6B}{9}} = \color{#4ECDC4}{3}
\quad \text{pentru că} \quad
\color{#4ECDC4}{3} \times \color{#4ECDC4}{3} = \color{#FF6B6B}{9}
`}
</Katex>

## Aplicații curs

:::tip De reținut
<Katex>
{String.raw`
\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}
`}
</Katex>
:::

Simplificăm radicalul. Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } 50 = \color{#FF6B6B}{25} \times 2\\[6pt]
& \text{Pasul 2: } \sqrt{50} = \sqrt{\color{#FF6B6B}{25}} \times \sqrt{2}\\[6pt]
& \text{Pasul 3: } \sqrt{\color{#FF6B6B}{25}} = 5\\[6pt]
& \text{Pasul 4: } \sqrt{50} = 5\sqrt{2}
\end{aligned}
`}
</Katex>

Încă un exemplu:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: } 72 = \color{#4ECDC4}{36} \times 2\\[6pt]
& \text{Pasul 2: } \sqrt{72} = \sqrt{\color{#4ECDC4}{36}} \times \sqrt{2}\\[6pt]
& \text{Pasul 3: } \sqrt{\color{#4ECDC4}{36}} = 6\\[6pt]
& \text{Pasul 4: } \sqrt{72} = 6\sqrt{2}
\end{aligned}
`}
</Katex>

Reținem: căutăm mereu un pătrat perfect.
