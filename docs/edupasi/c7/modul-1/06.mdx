\begin{aligned}
& \color{#FF6B6B}{\mathbb{N}} = \{0;1;2;3;\dots\} \\[6pt]

\end{aligned}
`}
</Katex>

Reținem: orice număr zecimal este rațional.

---

## Cea mai mică mulțime

<Katex>
{String.raw`
\begin{aligned}
& x \in A \;\text{: } x \text{ aparține lui } A \\[6pt]
& x \notin A \;\text{: } x \text{ nu aparține lui } A
\end{aligned}
`}
</Katex>

Aflăm cea mai mică mulțime a fracției. Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: împărțim } 12 : 5 = 2 \text{ rest } 2 \\[6pt]
& \text{Pasul 2: nu este întreg, deci este fracție} \\[6pt]
& \text{Pasul 3: } \frac{12}{5} \in \color{#4ECDC4}{\mathbb{Q}}
\end{aligned}
`}
</Katex>

## Proprietatea lui radical din 2

<Katex>
{String.raw`
\sqrt{2} = 1{,}41421\dots
`}
</Katex>

Zecimalele nu se termină. Nu se repetă. Deci nu este fracție.

:::warning Atenție
<Katex>
{String.raw`
\sqrt{2} \notin \color{#4ECDC4}{\mathbb{Q}} \qquad \sqrt{2} \in \color{#9370DB}{\mathbb{R}}
`}
</Katex>

Numim <HighlightText color="purple">irațional</HighlightText> un astfel de număr.
:::
