## Mulțimi speciale

<Katex>
{String.raw`
\begin{aligned}
& \mathbb{N} = \{\color{#FF6B6B}{0};1;2;3;\dots\} \\[6pt]
& \mathbb{N}^{*} = \{1;2;3;\dots\}
\end{aligned}
`}
</Katex>

Steluța scoate pe <HighlightText color="red">0</HighlightText> din mulțime.

<Katex>
{String.raw`
\Large \varnothing
`}
</Katex>

Mulțimea vidă nu are niciun element.

## Incluziunea a două mulțimi

:::danger Definiție
<Katex>
{String.raw`
\Large A \subset B
`}
</Katex>

Toate elementele lui A sunt și în B.
:::

\end{aligned}

## Paritate

:::tip De reținut
Un număr <HighlightText color="teal">par</HighlightText> se împarte exact la 2. Restul este 0.
:::

<Katex>
{String.raw`
\begin{aligned}
& \color{#4ECDC4}{\text{Pare: }} 0;2;4;6;8 \\[6pt]
& \color{#FF8C00}{\text{Impare: }} 1;3;5;7;9
\end{aligned}
`}
</Katex>

Verificăm dacă 14 este par. Calculăm pas cu pas:

<Katex>
{String.raw`
\begin{aligned}
& \text{Pasul 1: împărțim } 14 : 2 = 7 \text{ rest } 0 \\[6pt]
& \text{Pasul 2: restul este } 0 \\[6pt]
& \text{Pasul 3: deci } 14 \text{ este } \color{#4ECDC4}{\text{par}}
\end{aligned}
`}
</Katex>
