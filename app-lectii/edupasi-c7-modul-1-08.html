C6 – Modulul, compararea și ordonarea numerelor reale

Modulul unui număr real​

Definiție

Modulul unui număr este distanța de la număr până la zero.

∣3∣=3∣−3∣=3 \begin{aligned} & |\color{#4ECDC4}{3}| = 3\\[8pt] & |\color{#FF6B6B}{-3}| = 3 \end{aligned} ​∣3∣=3∣−3∣=3​

Reținem: modulul nu este niciodată negativ.

Exemplu: Calculăm modulul lui -7.

Pasul 1: Numărul este negativ.

Pasul 2: Îi schimbăm semnul.

Pasul 3: Scriem rezultatul.

∣−7∣=−(−7)=7 |-7| = -(-7) = \color{#FF8C00}{7} ∣−7∣=−(−7)=7

Compararea numerelor reale​

Numa˘rul din dreapta este mai mareNuma˘rul din staˆnga este mai mic \begin{aligned} & \text{Numărul din } \color{#4ECDC4}{\text{dreapta}} \text{ este mai mare}\\[8pt] & \text{Numărul din } \color{#FF6B6B}{\text{stânga}} \text{ este mai mic} \end{aligned} ​Numa˘rul din dreapta este mai mareNuma˘rul din staˆnga este mai mic​

Exemplu: Comparăm 5 cu -3.

Pasul 1: Le căutăm pe axă.

Pasul 2: 5 stă în dreapta lui -3.

5>−3 \color{#4ECDC4}{5} > \color{#FF6B6B}{-3} 5>−3

Ordonarea numerelor reale​

De reținut

Ordinea crescătoare se citește de la stânga la dreapta.

Exemplu: Ordonăm crescător numerele -2,5 ; 0 ; -1 ; 4.

Pasul 1: Le punem pe axă.

Pasul 2: Le citim de la stânga la dreapta.

−2,5<−1<0<4 \color{#FF8C00}{-2{,}5} < -1 < 0 < 4 −2,5<−1<0<4
