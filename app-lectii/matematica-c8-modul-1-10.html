C8.1 - Calcul literar: expresii algebrice

Expresii algebrice​

Valoarea numerică a unei expresii algebrice: Într-o expresie algebrică, unele numere pot fi reprezentate de litere (de aceea o numim EXPRESIE LITERALĂ);

Exemple:
3x+7,x2−5x+8,(3x+3)(2x−1) 3x + 7, \quad x^2 - 5x + 8, \quad (3x + 3)(2x - 1) 3x+7,x2−5x+8,(3x+3)(2x−1)

Acestea sunt expresii algebrice unde litera x este o variabilă.

  • Dacă îi atribuim variabilei x un numǎr, obținem valoarea numerică a expresiei.
    Dacă x = 10:
    3x+7=3⋅10+7=37 3x + 7 = 3 \cdot 10 + 7 = 37 3x+7=3⋅10+7=37
    x2−5x+8=102−5⋅10+8=58 x^2 - 5x + 8 = 10^2 - 5 \cdot 10 + 8 = 58 x2−5x+8=102−5⋅10+8=58

Reducerea unei sume algebrice​

Fie:

S=2x2−4x+5+3x−2\boldsymbol{S = 2x^2 - 4x + 5 + 3x - 2} S=2x2−4x+5+3x−2

Putem rescrie această serie de sume și scăderi într-o singură serie de sume astfel:

S=2x2+(−4x)+5+3x+(−2) S = 2x^2 + (-4x) + 5 + 3x + (-2) S=2x2+(−4x)+5+3x+(−2)
Observații
  • S este o sumă algebrică de 5 termeni:
    +2x2;−4x;+5;+3x;−2+2x^2; -4x; +5; +3x; -2+2x2;−4x;+5;+3x;−2
  • Ordinea termenilor se poate modifica și putem grupa termenii asemena, ceea ce permite reducerea sumei algebrice.

Grupăm termenii asemenea și reducem:

S=2x2+(−4x)+5+3x+(−2)==2x2+(−4x+3x)+(5−2)==2x2−x+3 \begin{aligned} S &= 2x^2 + (-4x) + 5 + 3x + (-2) = \\[10pt] &= 2x^2 + (-4x + 3x) + (5 - 2) = \\[10pt] &= 2x^2 - x + 3 \end{aligned} S​=2x2+(−4x)+5+3x+(−2)==2x2+(−4x+3x)+(5−2)==2x2−x+3​

S a fost redusă la o sumă algebrică de 3 termeni:

+2x2;−x;+3 +2x^2; -x; +3 +2x2;−x;+3

Adunarea a două sume algebrice​

Fie A şi B douǎ sume algebrice deja reduse:

A=2x2−x+7,B=−5x2+4x\boldsymbol{ A = 2x^2 - x + 7, \quad B = -5x^2 + 4x} A=2x2−x+7,B=−5x2+4x

Prin adunare obținem:

A+B=2x2+(−x)+7+(−5x2)+4x A + B = 2x^2 + (-x) + 7 + (-5x^2) + 4x A+B=2x2+(−x)+7+(−5x2)+4x

Grupăm termenii asemenea și reducem:

=2x2+(−5x2)+(−x)+4x+7==(2x2−5x2)+(−x+4x)+7==−3x2+3x+7\begin{aligned} &= 2x^2 + (-5x^2) + (-x) + 4x + 7 = \\[10pt] &= (2x^2 - 5x^2) + (-x + 4x) + 7 = \\[10pt] &= -3x^2 + 3x + 7 \end{aligned} ​=2x2+(−5x2)+(−x)+4x+7==(2x2−5x2)+(−x+4x)+7==−3x2+3x+7​

Scăderea a două sume algebrice​

Fie A şi B douǎ sume algebrice deja reduse:

A=2x2−x+7,B=−5x2+4x \boldsymbol{ A = 2x^2 - x + 7, \quad B = -5x^2 + 4x } A=2x2−x+7,B=−5x2+4x

Pentru a rescrie o scădere algebrică, adăugăm al doilea termen cu semn schimbat, astfel:

Pentru:
{A=2x2−x+7B=−5x2+4x \begin{aligned} &\begin{cases} &A = 2x^2 - x + 7 \\ &B = -5x^2 + 4x \end{cases} \end{aligned} ​{​A=2x2−x+7B=−5x2+4x​​
⇒−B=−(−5x2+4x)=5x2−4x \Rightarrow -B = -(-5x^2 + 4x) = 5x^2 - 4x\\[10pt] ⇒−B=−(−5x2+4x)=5x2−4x
Obținem
⇒A−B=A+(−B) \boldsymbol{\Rightarrow A - B = A + (-B)} ⇒A−B=A+(−B)

Acum putem trata ecuația folosind proprietațile adunǎrii a douǎ sume algebrice și in final reducerea unei sume algebrice

Prin scădere și reducere:

A−B=A+(−B)=2x2+(−x)+7+5x2+(−4x)==(2x2+5x2)+(−x−4x)+7=7x2−5x+7 \begin{aligned} &A - B = A + (-B) = \color{orangered}2x^2 \color{black}+ \color{olive}(-x)\color{black} +\color{black} 7 + \color{orangered} 5x^2 \color{black} + \color{olive}(-4x) =\\[10pt] &= (2x^2 + 5x^2) + (-x - 4x) + 7\\[10pt] &\boldsymbol{= 7x^2 - 5x + 7}\\[10pt] \end{aligned} ​A−B=A+(−B)=2x2+(−x)+7+5x2+(−4x)==(2x2+5x2)+(−x−4x)+7=7x2−5x+7​

Fiecare termen se înmulțește cu fiecare termen, aplicând regulile semnelor. Apoi se reduce suma algebrică obținută.

Fie

A=3x+7,B=−x+2 \boldsymbol{ A = 3x + 7,\quad B = -x + 2 } A=3x+7,B=−x+2

Prin înmulțire:

A⋅B=(3x+7)(−x+2)==3x⋅(−x)+3x⋅2+7⋅(−x)+7⋅2==−3x2+6x−7x+14==−3x2−x+14 \begin{aligned} A \cdot B &= (3x + 7)(-x + 2) = \\[10pt] &= 3x \cdot (-x) + 3x \cdot 2 + 7 \cdot (-x) + 7 \cdot 2 =\\[10pt] &= -3x^2 + 6x - 7x + 14 =\\[10pt] &\boldsymbol{= -3x^2 - x + 14} \end{aligned} A⋅B​=(3x+7)(−x+2)==3x⋅(−x)+3x⋅2+7⋅(−x)+7⋅2==−3x2+6x−7x+14==−3x2−x+14​
