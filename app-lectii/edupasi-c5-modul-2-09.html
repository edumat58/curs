C17 - Criterii de divizibilitate

1. Criteriul de divizibilitate cu 2 și 5​

Definiție

Un număr este divizibil cu 2 dacă ultima cifră este 0, 2, 4, 6 sau 8.

Un număr este divizibil cu 5 dacă ultima cifră este 0 sau 5.

34→ultima cifra˘ 4→divizibil cu 245→ultima cifra˘ 5→divizibil cu 5 \begin{aligned} & 3\color{#FF6B6B}{4} \to \text{ultima cifră } \color{#FF6B6B}{4} \to \text{divizibil cu } 2\\[6pt] & 4\color{#4ECDC4}{5} \to \text{ultima cifră } \color{#4ECDC4}{5} \to \text{divizibil cu } 5 \end{aligned} ​34→ultima cifra˘ 4→divizibil cu 245→ultima cifra˘ 5→divizibil cu 5​

2. Criteriul de divizibilitate cu 3​

Un număr este divizibil cu 3 dacă suma cifrelor este divizibilă cu 3.

Exemplu: numărul 24.

Pasul 1. Adunăm cifrele.

2+4=6 2 + 4 = \color{#FF8C00}{6} 2+4=6

Pasul 2. Împărțim suma la 3.

6:3=2 rest 0 \color{#FF8C00}{6} : 3 = 2 \text{ rest } 0 6:3=2 rest 0

Deci 24 este divizibil cu 3.

3. Criteriul de divizibilitate cu 9​

Un număr este divizibil cu 9 dacă suma cifrelor este divizibilă cu 9.

Exemplu: numărul 63.

Pasul 1: 6+3=9Pasul 2: 9:9=1 rest 0Deci 63 este divizibil cu 9 \begin{aligned} & \text{Pasul 1: } 6 + 3 = \color{#9370DB}{9}\\[6pt] & \text{Pasul 2: } \color{#9370DB}{9} : 9 = 1 \text{ rest } 0\\[6pt] & \text{Deci } 63 \text{ este divizibil cu } 9 \end{aligned} ​Pasul 1: 6+3=9Pasul 2: 9:9=1 rest 0Deci 63 este divizibil cu 9​

4. Criteriul de divizibilitate cu 10​

Un număr este divizibil cu 10 dacă ultima cifră este 0.

70→ultima cifra˘ 0→divizibil cu 10 7\color{#4ECDC4}{0} \to \text{ultima cifră } \color{#4ECDC4}{0} \to \text{divizibil cu } 10 70→ultima cifra˘ 0→divizibil cu 10
