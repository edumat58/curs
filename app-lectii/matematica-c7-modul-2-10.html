C16 - Apartenența la o mulțime

Noțiuni de bază​

Definiție 1

Un element aaa aparține unei mulțimi AAA dacă forma canonică a lui aaa este unul dintre elementele care definesc mulțimea AAA. Notăm: a∈A.a \in A.a∈A.

Definiție 2

Un element aaa nu aparține unei mulțimi AAA dacă forma canonică a lui aaa nu este unul dintre elementele care definesc mulțimea AAA. Notăm: a∉A.a \notin A.a∈/A.

Fie următoarele mulțimi de numere:

  • Mulțimea numerelor naturale: N={0,1,2,3,4,5,… }\mathbb{N} = \{0, 1, 2, 3, 4, 5, \dots\}N={0,1,2,3,4,5,…}
  • Mulțimea numerelor întregi: Z={…,−3,−2,−1,0,1,2,3,… }\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}Z={…,−3,−2,−1,0,1,2,3,…}
  • Mulțimea numerelor raționale: Q={ab∣a∈Z,b∈Z∖{0}}\mathbb{Q} = \left\{\frac{a}{b} \mid a \in \mathbb{Z}, b \in \mathbb{Z} \setminus \{0\}\right\}Q={ba​∣a∈Z,b∈Z∖{0}}
  • Mulțimea numerelor iraționale: R∖Q={2,3,π,e,… }\mathbb{R} \setminus \mathbb{Q} = \{\sqrt{2}, \sqrt{3}, \pi, e, \dots\}R∖Q={2​,3​,π,e,…}
  • Mulțimea numerelor reale: R=Q∪(R∖Q)\mathbb{R} = \mathbb{Q} \cup (\mathbb{R} \setminus \mathbb{Q})R=Q∪(R∖Q)

Exemple de apartenență la mulțimi​

  1. 5∈N5 \in \mathbb{N}5∈N, deoarece 5 este un număr natural.
  2. −3∈Z-3 \in \mathbb{Z}−3∈Z, deoarece -3 este un număr întreg.
  3. 23∈Q\frac{2}{3} \in \mathbb{Q}32​∈Q, deoarece 23\frac{2}{3}32​ este un număr rațional.
  4. 2∈R∖Q\sqrt{2} \in \mathbb{R} \setminus \mathbb{Q}2​∈R∖Q, deoarece 2\sqrt{2}2​ este un număr irațional.
  5. −1∉N-1 \notin \mathbb{N}−1∈/N, deoarece -1 nu este un număr natural.
  6. π∉Q\pi \notin \mathbb{Q}π∈/Q, deoarece π\piπ nu este un număr rațional.

Criterii de apartenență la mulțimi​

  • Un număr este în N\mathbb{N}N dacă este un număr întreg pozitiv sau zero.
  • Un număr este în Z\mathbb{Z}Z dacă este un număr întreg (pozitiv, negativ sau zero).
  • Un număr este în Q\mathbb{Q}Q dacă poate fi exprimat ca o fracție a două numere întregi, cu numitor diferit de zero.
  • Un număr este în R∖Q\mathbb{R} \setminus \mathbb{Q}R∖Q dacă nu poate fi exprimat ca o fracție a două numere întregi (are o infinitate de zecimale, care nu se repetă).
  • Un număr este în R\mathbb{R}R dacă este fie rațional, fie irațional.
