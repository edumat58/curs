C8.1 – Media aritmetică

Introducere​

CE ESTE MEDIA ARITMETICĂ?

Media aritmetică este o măsură a valorii centrale a unui set de numere reale. Ea reprezintă valoarea obținută prin împărțirea sumei tuturor valorilor la numărul de valori.

De exemplu, media aritmetică a notelor unui elev la mai multe teste sau a temperaturilor înregistrate într-o săptămână.

Media aritmetică a n numere reale​

FORMULA

Pentru n numere reale a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​, unde n≥2n \geq 2n≥2, media aritmetică se calculează astfel:

Ma=a1+a2+⋯+annM_a = \dfrac{a_1 + a_2 + \dots + a_n}{n}Ma​=na1​+a2​+⋯+an​​

Exemple​

cerințǎ
  1. Calculează media aritmetică a numerelor 4,6,84, 6, 84,6,8.

Suma numerelor: 4+6+8=184 + 6 + 8 = 184+6+8=18

Numărul de valori: 333

Media aritmetică: 183=6\dfrac{18}{3} = 6318​=6

cerințǎ
  1. Calculează media aritmetică a numerelor −2,0,2,4-2, 0, 2, 4−2,0,2,4.

Suma numerelor: −2+0+2+4=4-2 + 0 + 2 + 4 = 4−2+0+2+4=4

Numărul de valori: 444

Media aritmetică: 44=1\dfrac{4}{4} = 144​=1

cerințǎ
  1. Calculează media aritmetică a numerelor 12,34,1\dfrac{1}{2}, \dfrac{3}{4}, 121​,43​,1.

Suma numerelor: 12+34+1=24+34+44=94\dfrac{1}{2} + \dfrac{3}{4} + 1 = \dfrac{2}{4} + \dfrac{3}{4} + \dfrac{4}{4} = \dfrac{9}{4}21​+43​+1=42​+43​+44​=49​

Numărul de valori: 333

Media aritmetică: 943=912=34\dfrac{\dfrac{9}{4}}{3} = \dfrac{9}{12} = \dfrac{3}{4}349​​=129​=43​

Media aritmetică ponderată​

CE ESTE MEDIA ARITMETICĂ PONDERATĂ?

Media aritmetică ponderată este o medie în care fiecare valoare are o pondere (importanță) diferită. Ponderea arată cât de importantă este fiecare valoare în calculul mediei.

FORMULA

Pentru n valori a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​ cu ponderile corespunzătoare p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​ (numere pozitive), media aritmetică ponderată se calculează astfel:

Map=a1⋅p1+a2⋅p2+⋯+an⋅pnp1+p2+⋯+pnM_{ap} = \dfrac{a_1 \cdot p_1 + a_2 \cdot p_2 + \dots + a_n \cdot p_n}{p_1 + p_2 + \dots + p_n}Map​=p1​+p2​+⋯+pn​a1​⋅p1​+a2​⋅p2​+⋯+an​⋅pn​​

Exemple​

cerințǎ
  1. Un elev are notele: 888 (pondere 222), 777 (pondere 333), 999 (pondere 111).

Suma ponderată: 8⋅2+7⋅3+9⋅1=16+21+9=468 \cdot 2 + 7 \cdot 3 + 9 \cdot 1 = 16 + 21 + 9 = 468⋅2+7⋅3+9⋅1=16+21+9=46

Suma ponderilor: 2+3+1=62 + 3 + 1 = 62+3+1=6

Media ponderată: 466=233≈7,67\dfrac{46}{6} = \dfrac{23}{3} \approx 7,67646​=323​≈7,67

cerințǎ
  1. Într-un concurs, punctajele sunt: proba A: 858585 puncte (pondere 333), proba B: 909090 puncte (pondere 222), proba C: 808080 puncte (pondere 111).

Suma ponderată: 85⋅3+90⋅2+80⋅1=255+180+80=51585 \cdot 3 + 90 \cdot 2 + 80 \cdot 1 = 255 + 180 + 80 = 51585⋅3+90⋅2+80⋅1=255+180+80=515

Suma ponderilor: 3+2+1=63 + 2 + 1 = 63+2+1=6

Media ponderată: 5156≈85,83\dfrac{515}{6} \approx 85,836515​≈85,83
