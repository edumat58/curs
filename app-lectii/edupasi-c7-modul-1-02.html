C2 – Reguli de calcul cu puteri

Noțiuni de bază​

Definiție

Puterea este o înmulțire repetată. Baza este numărul care se înmulțește. Exponentul arată de câte ori.

Observăm desenul:

24=2×2×2×2=16 \color{#FF6B6B}{2}^{\color{#4ECDC4}{4}} = 2 \times 2 \times 2 \times 2 = 16 24=2×2×2×2=16

Reguli fundamentale​

R1. Înmulțirea puterilor​

am×an=am+n a^{\color{#4ECDC4}{m}} \times a^{\color{#4ECDC4}{n}} = a^{\color{#4ECDC4}{m+n}} am×an=am+n

Calculăm pas cu pas:

Pasul 1: baza este 2Pasul 2: aduna˘m exponenții 3+4=7Pasul 3: 23×24=27 \begin{aligned} & \text{Pasul 1: baza este } \color{#FF6B6B}{2}\\[6pt] & \text{Pasul 2: adunăm exponenții } \color{#4ECDC4}{3+4=7}\\[6pt] & \text{Pasul 3: } \color{#FF6B6B}{2}^{3} \times \color{#FF6B6B}{2}^{4} = \color{#FF6B6B}{2}^{\color{#4ECDC4}{7}} \end{aligned} ​Pasul 1: baza este 2Pasul 2: aduna˘m exponenții 3+4=7Pasul 3: 23×24=27​

R2. Împărțirea puterilor​

am:an=am−n a^{\color{#4ECDC4}{m}} : a^{\color{#4ECDC4}{n}} = a^{\color{#4ECDC4}{m-n}} am:an=am−n

Calculăm pas cu pas:

Pasul 1: baza este 5Pasul 2: sca˘dem exponenții 6−2=4Pasul 3: 56:52=54 \begin{aligned} & \text{Pasul 1: baza este } \color{#FF6B6B}{5}\\[6pt] & \text{Pasul 2: scădem exponenții } \color{#4ECDC4}{6-2=4}\\[6pt] & \text{Pasul 3: } \color{#FF6B6B}{5}^{6} : \color{#FF6B6B}{5}^{2} = \color{#FF6B6B}{5}^{\color{#4ECDC4}{4}} \end{aligned} ​Pasul 1: baza este 5Pasul 2: sca˘dem exponenții 6−2=4Pasul 3: 56:52=54​

R3. Puterea unei puteri​

(am)n=am×n \bigl(a^{\color{#4ECDC4}{m}}\bigr)^{\color{#4ECDC4}{n}} = a^{\color{#4ECDC4}{m \times n}} (am)n=am×n

Calculăm pas cu pas:

Pasul 1: baza este 3Pasul 2: ıˆnmulțim exponenții 2×4=8Pasul 3: (32)4=38 \begin{aligned} & \text{Pasul 1: baza este } \color{#FF6B6B}{3}\\[6pt] & \text{Pasul 2: înmulțim exponenții } \color{#4ECDC4}{2 \times 4 = 8}\\[6pt] & \text{Pasul 3: } \bigl(\color{#FF6B6B}{3}^{2}\bigr)^{4} = \color{#FF6B6B}{3}^{\color{#4ECDC4}{8}} \end{aligned} ​Pasul 1: baza este 3Pasul 2: ıˆnmulțim exponenții 2×4=8Pasul 3: (32)4=38​
