C19.3 - Compararea fracțiilor cu același numitor sau numărător

Proprietăți ale fracțiilor​

Definiție
  • Același numitor: mai mare este fracția cu numărătorul mai mare.
  • Același numărător: mai mare este fracția cu numitorul mai mic.

Exemplul 1. Comparăm fracții cu același numitor.

Pasul 1. Numitorii sunt egali: 7=7Pasul 2. Compara˘m numa˘ra˘torii: 5>3Pasul 3. Scriem: 57>37 \begin{aligned} & \text{Pasul 1. Numitorii sunt egali: } \color{#4ECDC4}{7} = \color{#4ECDC4}{7}\\[6pt] & \text{Pasul 2. Comparăm numărătorii: } \color{#FF6B6B}{5} > \color{#FF6B6B}{3}\\[6pt] & \text{Pasul 3. Scriem: } \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{7}} > \frac{\color{#FF6B6B}{3}}{\color{#4ECDC4}{7}} \end{aligned} ​Pasul 1. Numitorii sunt egali: 7=7Pasul 2. Compara˘m numa˘ra˘torii: 5>3Pasul 3. Scriem: 75​>73​​

Exemplul 2. Comparăm fracții cu același numărător.

Pasul 1. Numa˘ra˘torii sunt egali: 2=2Pasul 2. Compara˘m numitorii: 5<7Pasul 3. Scriem: 25>27 \begin{aligned} & \text{Pasul 1. Numărătorii sunt egali: } \color{#FF6B6B}{2} = \color{#FF6B6B}{2}\\[6pt] & \text{Pasul 2. Comparăm numitorii: } \color{#4ECDC4}{5} < \color{#4ECDC4}{7}\\[6pt] & \text{Pasul 3. Scriem: } \frac{\color{#FF6B6B}{2}}{\color{#4ECDC4}{5}} > \frac{\color{#FF6B6B}{2}}{\color{#4ECDC4}{7}} \end{aligned} ​Pasul 1. Numa˘ra˘torii sunt egali: 2=2Pasul 2. Compara˘m numitorii: 5<7Pasul 3. Scriem: 52​>72​​

Observație​

De reținut

Pe axa numerelor, mai mare este fracția din dreapta.

14<34 \frac{1}{4} < \frac{3}{4} 41​<43​
