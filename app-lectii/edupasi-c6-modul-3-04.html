C18.2 - Opusul, modulul și compararea numerelor raționale

Reprezentarea pe axa numerelor​

Fiecare număr rațional are un punct pe axă. La dreapta lui 0 stau numerele pozitive. La stânga stau cele negative.

Opusul unui număr rațional​

Definiție

Două numere sunt opuse dacă au același număr și semne diferite.

Opusul lui x este −x \text{Opusul lui } \color{#4ECDC4}{x} \text{ este } \color{#FF6B6B}{-x} Opusul lui x este −x

Exemplul 1.

Afla˘m opusul lui +34 \text{Aflăm opusul lui } +\dfrac{3}{4} Afla˘m opusul lui +43​

Pasul 1: Păstrăm numărul.

34 \dfrac{3}{4} 43​

Pasul 2: Schimbăm semnul.

+34⇒−34 +\dfrac{3}{4} \quad \Rightarrow \quad \color{#FF6B6B}{-\dfrac{3}{4}} +43​⇒−43​

Exemplul 2.

Opusul lui −2,5 este +2,5 \text{Opusul lui } \color{#FF6B6B}{-2{,}5} \text{ este } \color{#4ECDC4}{+2{,}5} Opusul lui −2,5 este +2,5

Modulul unui număr rațional​

De reținut

Modulul este distanța de la 0 până la număr. Scriem numărul fără semn.

∣+29∣=29∣−29∣=29 \begin{aligned} & \left|\color{#4ECDC4}{+\dfrac{2}{9}}\right| = \dfrac{2}{9}\\[8pt] & \left|\color{#FF6B6B}{-\dfrac{2}{9}}\right| = \dfrac{2}{9} \end{aligned} ​​+92​​=92​​−92​​=92​​

Exemplul 3.

∣−4,5∣=4,5∣+1,3∣=1,3 |-4{,}5| = \color{#FF8C00}{4{,}5} \qquad |+1{,}3| = \color{#FF8C00}{1{,}3} ∣−4,5∣=4,5∣+1,3∣=1,3

Observăm că modulul nu este niciodată negativ.

Compararea numerelor raționale​

Pe axă numerele cresc de la stânga la dreapta. Numărul din dreapta este mai mare.

1. Orice numa˘r pozitiv este mai mare decaˆt orice numa˘r negativ2. Dintre doua˘ numere negative, mai mare este cel cu modulul mai mic \begin{aligned} & \text{1. Orice număr pozitiv este mai mare decât orice număr negativ}\\[8pt] & \text{2. Dintre două numere negative, mai mare este cel cu modulul mai mic} \end{aligned} ​1. Orice numa˘r pozitiv este mai mare decaˆt orice numa˘r negativ2. Dintre doua˘ numere negative, mai mare este cel cu modulul mai mic​

Exemplul 4.

Compara˘m −0,7 cu −0,2 \text{Comparăm } -0{,}7 \text{ cu } -0{,}2 Compara˘m −0,7 cu −0,2

Pasul 1: Calculăm modulele.

∣−0,7∣=0,7∣−0,2∣=0,2 |-0{,}7| = 0{,}7 \qquad |-0{,}2| = 0{,}2 ∣−0,7∣=0,7∣−0,2∣=0,2

Pasul 2: Modulul mai mic dă numărul mai mare.

−0,2>−0,7 \color{#4ECDC4}{-0{,}2} > \color{#FF6B6B}{-0{,}7} −0,2>−0,7
