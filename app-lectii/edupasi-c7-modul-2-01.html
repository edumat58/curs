G4 - Paralelogramul

Definiție​

Definiție

Paralelogramul este patrulaterul cu laturile opuse paralele.

AB∥CDBC∥AD \color{#4ECDC4}{AB \parallel CD} \qquad \color{#FF6B6B}{BC \parallel AD} AB∥CDBC∥AD

Proprietăți​

1. Laturile opuse sunt egale:  AB=CD,  AD=BC2. Unghiurile opuse sunt egale:  ∠A=∠C,  ∠B=∠D3. Unghiurile ala˘turate: ∠A+∠B=180∘ \begin{aligned} & \text{1. Laturile opuse sunt } \color{#FF6B6B}{\text{egale}}: \; AB = CD, \; AD = BC\\[8pt] & \text{2. Unghiurile opuse sunt } \color{#4ECDC4}{\text{egale}}: \; \angle A = \angle C, \; \angle B = \angle D\\[8pt] & \text{3. Unghiurile alăturate: } \angle A + \angle B = \color{#FF8C00}{180^\circ} \end{aligned} ​1. Laturile opuse sunt egale:AB=CD,AD=BC2. Unghiurile opuse sunt egale:∠A=∠C,∠B=∠D3. Unghiurile ala˘turate: ∠A+∠B=180∘​
De reținut

Unghiurile opuse sunt egale. Unghiurile alăturate dau împreună 180 de grade.

Cum recunoaștem un paralelogram​

a) laturile opuse sunt paraleleb) laturile opuse sunt egalec) diagonalele se taie ıˆn doua˘ pa˘rți egale \begin{aligned} & \text{a) laturile opuse sunt } \color{#4ECDC4}{\text{paralele}}\\[8pt] & \text{b) laturile opuse sunt } \color{#FF6B6B}{\text{egale}}\\[8pt] & \text{c) diagonalele se taie în } \color{#9370DB}{\text{două părți egale}} \end{aligned} ​a) laturile opuse sunt paraleleb) laturile opuse sunt egalec) diagonalele se taie ıˆn doua˘ pa˘rți egale​

Aplicații​

Paralelogramul ABCD are unghiul A de 70 de grade. Aflăm celelalte unghiuri.

Pasul 1: ∠C=∠A=70∘Pasul 2: ∠B=180∘−70∘=110∘Pasul 3: ∠D=∠B=110∘ \begin{aligned} & \text{Pasul 1: } \angle C = \angle A = \color{#FF6B6B}{70^\circ}\\[8pt] & \text{Pasul 2: } \angle B = 180^\circ - 70^\circ = \color{#4ECDC4}{110^\circ}\\[8pt] & \text{Pasul 3: } \angle D = \angle B = \color{#4ECDC4}{110^\circ} \end{aligned} ​Pasul 1: ∠C=∠A=70∘Pasul 2: ∠B=180∘−70∘=110∘Pasul 3: ∠D=∠B=110∘​
