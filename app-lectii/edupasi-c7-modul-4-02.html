C18.2 - Funcții trigonometrice (proprietăți)

Funcția sinus​

Definiție

Funcția sinus duce fiecare număr real x în valoarea sin x.

Perioada: 2πsin⁡(x+2π)=sin⁡xImpara˘: sin⁡(−x)=−sin⁡xMa˘rginita˘: −1≤sin⁡x≤1 \begin{aligned} & \text{Perioada: } \color{#FF6B6B}{2\pi} \\[6pt] & \sin(x + 2\pi) = \sin x \\[6pt] & \text{Impară: } \color{#4ECDC4}{\sin(-x) = -\sin x} \\[6pt] & \text{Mărginită: } -1 \le \sin x \le 1 \end{aligned} ​Perioada: 2πsin(x+2π)=sinxImpara˘: sin(−x)=−sinxMa˘rginita˘: −1≤sinx≤1​

Calculăm pas cu pas:

Pasul 1: 13π6=2π+π6Pasul 2: sin⁡13π6=sin⁡π6Pasul 3: sin⁡π6=12 \begin{aligned} & \text{Pasul 1: } \frac{13\pi}{6} = 2\pi + \frac{\pi}{6} \\[6pt] & \text{Pasul 2: } \sin\frac{13\pi}{6} = \sin\frac{\pi}{6} \\[6pt] & \text{Pasul 3: } \sin\frac{\pi}{6} = \color{#FF8C00}{\frac{1}{2}} \end{aligned} ​Pasul 1: 613π​=2π+6π​Pasul 2: sin613π​=sin6π​Pasul 3: sin6π​=21​​

Funcția cosinus​

Funcția cosinus se scrie cos x.

Perioada: 2πcos⁡(x+2π)=cos⁡xPara˘: cos⁡(−x)=cos⁡xMa˘rginita˘: −1≤cos⁡x≤1 \begin{aligned} & \text{Perioada: } \color{#FF6B6B}{2\pi} \\[6pt] & \cos(x + 2\pi) = \cos x \\[6pt] & \text{Pară: } \color{#4ECDC4}{\cos(-x) = \cos x} \\[6pt] & \text{Mărginită: } -1 \le \cos x \le 1 \end{aligned} ​Perioada: 2πcos(x+2π)=cosxPara˘: cos(−x)=cosxMa˘rginita˘: −1≤cosx≤1​

Calculăm pas cu pas:

Pasul 1: cos⁡(−π3)=cos⁡π3Pasul 2: cos⁡π3=12 \begin{aligned} & \text{Pasul 1: } \cos\left(-\frac{\pi}{3}\right) = \cos\frac{\pi}{3} \\[6pt] & \text{Pasul 2: } \cos\frac{\pi}{3} = \color{#FF8C00}{\frac{1}{2}} \end{aligned} ​Pasul 1: cos(−3π​)=cos3π​Pasul 2: cos3π​=21​​

Funcția tangentă​

Funcția tangentă se scrie tg x.

Perioada: πtg⁡(x+π)=tg⁡xImpara˘: tg⁡(−x)=−tg⁡xNu este ma˘rginita˘. \begin{aligned} & \text{Perioada: } \color{#9370DB}{\pi} \\[6pt] & \tg(x + \pi) = \tg x \\[6pt] & \text{Impară: } \color{#4ECDC4}{\tg(-x) = -\tg x} \\[6pt] & \text{Nu este mărginită.} \end{aligned} ​Perioada: πtg(x+π)=tgxImpara˘: tg(−x)=−tgxNu este ma˘rginita˘.​

Calculăm pas cu pas:

Pasul 1: 5π4=π+π4Pasul 2: tg⁡5π4=tg⁡π4Pasul 3: tg⁡π4=1 \begin{aligned} & \text{Pasul 1: } \frac{5\pi}{4} = \pi + \frac{\pi}{4} \\[6pt] & \text{Pasul 2: } \tg\frac{5\pi}{4} = \tg\frac{\pi}{4} \\[6pt] & \text{Pasul 3: } \tg\frac{\pi}{4} = \color{#FF8C00}{1} \end{aligned} ​Pasul 1: 45π​=π+4π​Pasul 2: tg45π​=tg4π​Pasul 3: tg4π​=1​

Funcția cotangentă​

Funcția cotangentă se scrie ctg x.

Perioada: πctg⁡(x+π)=ctg⁡xImpara˘: ctg⁡(−x)=−ctg⁡xNu este ma˘rginita˘. \begin{aligned} & \text{Perioada: } \color{#9370DB}{\pi} \\[6pt] & \ctg(x + \pi) = \ctg x \\[6pt] & \text{Impară: } \color{#4ECDC4}{\ctg(-x) = -\ctg x} \\[6pt] & \text{Nu este mărginită.} \end{aligned} ​Perioada: πctg(x+π)=ctgxImpara˘: ctg(−x)=−ctgxNu este ma˘rginita˘.​

Calculăm pas cu pas:

Pasul 1: 5π4=π+π4Pasul 2: ctg⁡5π4=ctg⁡π4Pasul 3: ctg⁡π4=1 \begin{aligned} & \text{Pasul 1: } \frac{5\pi}{4} = \pi + \frac{\pi}{4} \\[6pt] & \text{Pasul 2: } \ctg\frac{5\pi}{4} = \ctg\frac{\pi}{4} \\[6pt] & \text{Pasul 3: } \ctg\frac{\pi}{4} = \color{#FF8C00}{1} \end{aligned} ​Pasul 1: 45π​=π+4π​Pasul 2: ctg45π​=ctg4π​Pasul 3: ctg4π​=1​
De reținut
sin⁡ și cos⁡ se repeta˘ din 2πtg⁡ și ctg⁡ se repeta˘ din π \begin{aligned} & \color{#FF6B6B}{\sin} \text{ și } \color{#FF6B6B}{\cos} \text{ se repetă din } 2\pi \\[8pt] & \color{#9370DB}{\tg} \text{ și } \color{#9370DB}{\ctg} \text{ se repetă din } \pi \end{aligned} ​sin și cos se repeta˘ din 2πtg și ctg se repeta˘ din π​
