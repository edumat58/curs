C22 - Adunarea și scăderea fracțiilor ordinare

Adunarea și Scăderea Fracțiilor​

Fracții cu același numitor​

Definiție

Adunăm numărătorii. Numitorul rămâne același.

Calculăm pas cu pas:

Calcula˘m 38+28Pasul 1: numitorii sunt la fel: 8Pasul 2: aduna˘m numa˘ra˘torii: 3+2=5Pasul 3: scriem rezultatul: 58 \begin{aligned} & \text{Calculăm } \frac{3}{8} + \frac{2}{8}\\[8pt] & \text{Pasul 1: numitorii sunt la fel: } \color{#4ECDC4}{8}\\[8pt] & \text{Pasul 2: adunăm numărătorii: } 3 + 2 = \color{#FF6B6B}{5}\\[8pt] & \text{Pasul 3: scriem rezultatul: } \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{8}} \end{aligned} ​Calcula˘m 83​+82​Pasul 1: numitorii sunt la fel: 8Pasul 2: aduna˘m numa˘ra˘torii: 3+2=5Pasul 3: scriem rezultatul: 85​​

La scădere, scădem numărătorii:

58−28=5−28=38 \frac{5}{8} - \frac{2}{8} = \frac{5-2}{8} = \frac{\color{#FF6B6B}{3}}{\color{#4ECDC4}{8}} 85​−82​=85−2​=83​

Fracții cu numitori diferiți​

Aducem fracțiile la numitor comun prin amplificare.

Calcula˘m 12+13Pasul 1: numitorul comun este 6Pasul 2: amplifica˘m: 12=36 și 13=26Pasul 3: aduna˘m numa˘ra˘torii: 36+26=56 \begin{aligned} & \text{Calculăm } \frac{1}{2} + \frac{1}{3}\\[8pt] & \text{Pasul 1: numitorul comun este } \color{#FF8C00}{6}\\[8pt] & \text{Pasul 2: amplificăm: } \frac{1}{2} = \frac{3}{6} \text{ și } \frac{1}{3} = \frac{2}{6}\\[8pt] & \text{Pasul 3: adunăm numărătorii: } \frac{3}{6} + \frac{2}{6} = \frac{\color{#FF6B6B}{5}}{\color{#4ECDC4}{6}} \end{aligned} ​Calcula˘m 21​+31​Pasul 1: numitorul comun este 6Pasul 2: amplifica˘m: 21​=63​ și 31​=62​Pasul 3: aduna˘m numa˘ra˘torii: 63​+62​=65​​
Atenție

Dacă se poate, simplificăm rezultatul.

34−14=24=12 \frac{3}{4} - \frac{1}{4} = \frac{2}{4} = \frac{\color{#FF6B6B}{1}}{\color{#4ECDC4}{2}} 43​−41​=42​=21​

Operații între un număr natural și o fracție​

Scriem numărul natural ca fracție cu numitorul 1.

Calcula˘m 2+35Pasul 1: 2=21Pasul 2: amplifica˘m cu 5: 21=105Pasul 3: aduna˘m: 105+35=135 \begin{aligned} & \text{Calculăm } 2 + \frac{3}{5}\\[8pt] & \text{Pasul 1: } 2 = \frac{2}{1}\\[8pt] & \text{Pasul 2: amplificăm cu 5: } \frac{2}{1} = \frac{10}{5}\\[8pt] & \text{Pasul 3: adunăm: } \frac{10}{5} + \frac{3}{5} = \frac{\color{#FF6B6B}{13}}{\color{#4ECDC4}{5}} \end{aligned} ​Calcula˘m 2+53​Pasul 1: 2=12​Pasul 2: amplifica˘m cu 5: 12​=510​Pasul 3: aduna˘m: 510​+53​=513​​

La scădere procedăm la fel:

2−35=105−35=75 2 - \frac{3}{5} = \frac{10}{5} - \frac{3}{5} = \frac{\color{#FF6B6B}{7}}{\color{#4ECDC4}{5}} 2−53​=510​−53​=57​

Proprietățile adunării​

Ordinea termenilor nu schimbă rezultatul.

15+25=25+15=35 \frac{1}{5} + \frac{2}{5} = \frac{2}{5} + \frac{1}{5} = \frac{3}{5} 51​+52​=52​+51​=53​

Adunarea cu 0 nu schimbă fracția.

49+0=49 \frac{4}{9} + 0 = \frac{4}{9} 94​+0=94​

La scădere, ordinea termenilor nu se schimbă.
