C11 - Compararea și ordonarea numerelor întregi

Compararea numerelor întregi​

Definiție

Fiecare număr întreg are un punct pe axa numerelor.

De reținut
Pe axa˘, numa˘rul din dreapta este mai mare.Orice pozitiv este mai mare decaˆt orice negativ. \begin{aligned} & \text{Pe axă, numărul din } \color{#4ECDC4}{\text{dreapta}} \text{ este mai mare.}\\[8pt] & \color{#FF8C00}{\text{Orice pozitiv}} \text{ este mai mare decât } \color{#FF6B6B}{\text{orice negativ.}} \end{aligned} ​Pe axa˘, numa˘rul din dreapta este mai mare.Orice pozitiv este mai mare decaˆt orice negativ.​

Exemplul 1

Compara˘m −3 și 1.Pasul 1: −3 este ıˆn staˆnga.Pasul 2: 1 este ıˆn dreapta.Pasul 3: −3<1 \begin{aligned} & \text{Comparăm } \color{#FF6B6B}{-3} \text{ și } \color{#4ECDC4}{1}.\\[6pt] & \text{Pasul 1: } \color{#FF6B6B}{-3} \text{ este în stânga.}\\[6pt] & \text{Pasul 2: } \color{#4ECDC4}{1} \text{ este în dreapta.}\\[6pt] & \text{Pasul 3: } -3 < 1 \end{aligned} ​Compara˘m −3 și 1.Pasul 1: −3 este ıˆn staˆnga.Pasul 2: 1 este ıˆn dreapta.Pasul 3: −3<1​

Exemplul 2

Compara˘m −7 și −2.Pasul 1: −7 este ıˆn staˆnga.Pasul 2: −2 este ıˆn dreapta.Pasul 3: −7<−2 \begin{aligned} & \text{Comparăm } \color{#FF6B6B}{-7} \text{ și } \color{#9370DB}{-2}.\\[6pt] & \text{Pasul 1: } \color{#FF6B6B}{-7} \text{ este în stânga.}\\[6pt] & \text{Pasul 2: } \color{#9370DB}{-2} \text{ este în dreapta.}\\[6pt] & \text{Pasul 3: } -7 < -2 \end{aligned} ​Compara˘m −7 și −2.Pasul 1: −7 este ıˆn staˆnga.Pasul 2: −2 este ıˆn dreapta.Pasul 3: −7<−2​

Aplicații​

Ordonăm crescător numerele:

−4, 2, 0, −1, 3Pasul 1: scriem negativele:−4, −1Pasul 2: scriem zeroul:0Pasul 3: scriem pozitivele:2, 3Rezultat: −4<−1<0<2<3 \begin{aligned} & -4,\ 2,\ 0,\ -1,\ 3\\[8pt] & \text{Pasul 1: scriem } \color{#FF6B6B}{\text{negativele}}: -4,\ -1\\[6pt] & \text{Pasul 2: scriem } \color{#9370DB}{\text{zeroul}}: 0\\[6pt] & \text{Pasul 3: scriem } \color{#4ECDC4}{\text{pozitivele}}: 2,\ 3\\[8pt] & \text{Rezultat: } -4 < -1 < 0 < 2 < 3 \end{aligned} ​−4, 2, 0, −1, 3Pasul 1: scriem negativele:−4, −1Pasul 2: scriem zeroul:0Pasul 3: scriem pozitivele:2, 3Rezultat: −4<−1<0<2<3​
