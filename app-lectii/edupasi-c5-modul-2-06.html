G2 - Semiplan, semidreaptă și segment

Semiplanul​

Definiție

O dreaptă împarte planul în două părți. Fiecare parte se numește semiplan. Dreapta se numește frontieră.

(d, A) este semiplanul cu punctul A(d, B) este semiplanul cu punctul B \begin{aligned} & \color{#4ECDC4}{(d,\ A)} \text{ este semiplanul cu punctul } A\\[6pt] & \color{#FF6B6B}{(d,\ B)} \text{ este semiplanul cu punctul } B \end{aligned} ​(d, A) este semiplanul cu punctul A(d, B) este semiplanul cu punctul B​

Semidreapta​

Punctul O se află pe dreapta d. Partea care pleacă din O este o semidreaptă. Punctul O este originea.

(OE) nu conține punctul O[OE) conține punctul O \begin{aligned} & \color{#FF6B6B}{(OE)} \text{ nu conține punctul } O\\[6pt] & \color{#4ECDC4}{[OE)} \text{ conține punctul } O \end{aligned} ​(OE) nu conține punctul O[OE) conține punctul O​

Segmentul de dreaptă​

Punctele A și B se află pe dreapta d. Partea dintre A și B este un segment. Punctele A și B sunt extremitățile.

(AB) nu conține punctele A și B[AB] conține punctele A și B \begin{aligned} & \color{#FF6B6B}{(AB)} \text{ nu conține punctele } A \text{ și } B\\[6pt] & \color{#4ECDC4}{[AB]} \text{ conține punctele } A \text{ și } B \end{aligned} ​(AB) nu conține punctele A și B[AB] conține punctele A și B​
